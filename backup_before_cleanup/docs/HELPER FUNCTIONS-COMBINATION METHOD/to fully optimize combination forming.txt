1. Main Combination Categories
Each category represents a different methodology of combination selection, ensuring maximum coverage and efficiency.

Category Name	Description	Strengths	Selection Criteria

2. Detailed Breakdown of Each Category
(A) Pattern Extractor-Based Combinations
✅ How It Works:

Extracts combinations from R2/R4/R6/R8 progressions
Identifies stable 3-digit formations that persist across multiple draws
Prioritizes patterns that appear in multiple places within the dataset
🔹 Example:

If 245 appears in R2 and R4, then it is more likely to hit.
Final combinations: {245, 254, 452}
If a pattern also appears in R6 or R8, then V-Trac is applied.
📌 Best Use Cases:

Prioritizes high-confidence patterns
Used for both straight and boxed play
Best for predicting the strongest 3-digit structures
(B) Digit Reduction-Based Combinations
✅ How It Works:

Extracts alternative patterns from digit-reduction transformations
Identifies hidden patterns that may not be caught by the main progression
Alternative to standard R2/R4/R6/R8 filtering
🔹 Example:

From longer string 45622, extract:
{456, 457, 462, 467}
Uses 4-value patterns for alternative boxed plays
📌 Best Use Cases:

Expands combination pool without excessive plays
Helps capture numbers that digit reduction reveals
Provides backup alternative plays to Pattern Extractor combinations
(C) V-Trac Transformation-Based Combinations
✅ How It Works:

Uses V-Trac number shifting and mirroring rules
Focuses on double-digit patterns and V-Trac pattern clusters
Converts strong 3-digit patterns into mirrored equivalents
🔹 Example:

If V-Trac indicates that 77 is a strong repeating digit, mirror it as:
{77 → 22}
If 456 is a strong pattern, generate:
V-Trac transformations: {456, 406, 956, 906}
Mirroring transformations: {451, 856, 851}
📌 Best Use Cases:

Adds extra transformations for straight-play potential
Enhances number rotation within strong 3-digit sets
Helps target exact digit placements for straight hits
(D) Confidence-Based Aggregation (AI-Driven Learning)
✅ How It Works:

Machine learning assigns confidence scores based on past hits
Combines results from Pattern Extractor, Digit Reduction, and V-Trac
Prioritizes the best-performing combination types over time
🔹 Example:

If Pattern Extractor-based combos hit more often, they are prioritized.
If Digit Reduction finds an alternative pattern that performs well, it is weighted higher.
If V-Trac shows diminishing returns, its weighting is reduced.
📌 Best Use Cases:

Adaptive selection based on past performance
Limits excessive plays by focusing on the most successful patterns
Balances risk vs. reward dynamically
3. Additional Combination Types
Within each main category, additional sub-strategies are used for fine-tuning combination selection.

(E) Special Double-Digit Combinations
✅ How It Works:

If one digit repeats, its mirror may appear soon.
🔹 Example:

If the pattern extractor finds 77, consider:
{77 → 22}
{778 → 228}
📌 Best Use Cases:

Enhances straight-hit potential
Detects likely mirroring trends
Used in combination with V-Trac transformations
(F) Late/Due Pair Combinations
✅ How It Works:

Tracks pairs that haven’t appeared in a while
Uses historical data to identify missing 2-digit sequences
Matches due pairs with current strong 3-digit patterns
🔹 Example:

If the pair 45 has been missing for 20+ draws, prioritize combinations including 45:
{450, 451, 452, 453, 454}
📌 Best Use Cases:

Helps identify key digits that are overdue
Balances high-probability hits with newer emerging patterns
