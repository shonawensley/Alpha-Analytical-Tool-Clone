Analyzer V2 (Unified) — 2025-09-28
---------------------------------
Entry point: from alpha_analytical.digit_reduction.analyzer_v2 import run
Usage: run(state: str, analysis_root: Path | str | None = None) -> dict

Inputs:
- Reads reducer training artifacts under data/outputs/analysis/digit_reduction/<STATE>/training/
  (expects *digit_reduction_logs.json + companion CSV written by the live module).

Outputs (all under .../<STATE>/analyzer_v2/):
- <STATE>_analyzer_v2_per_item.csv              # unified per-item features + score
- <STATE>_analyzer_v2_own_vs_combined_delta.csv # location-level diagnostics
- <STATE>_analyzer_v2_top_candidates.csv        # high-score rollup by canon
- <STATE>_analyzer_v2_meta.json                 # config snapshot + VTRAC provenance

Feature families preserved:
- Trajectory, tail, stability, permutation density, pre-reduction hints
- Cross-section consensus (Midday/Evening/Combined) with Jaccard + timing spread
- Own vs combined deltas (time-to-3, length, core agreement, missing-mode flag)
- Across-method agreement (counts + early fraction) and cross-column alignment
- Set memory/linger for Set3?2?1 continuity
- Optional VTRAC synergy via analyzer_v2.vtrac_index (predictions JSON preferred, DR-derived fallback)

Scoring:
- Config-driven weights/caps in config.yml (version 3) applied through score.score_row
- Penalties: degenerate.empty, tail.wobble, mode.only_one (zero-safe when fields missing)
- VTRAC boost keyed by weights['vtrac.v_hot'] (default 0.5; set to 0 to disable)

Smoke (from repo root, after reducer ran for the state):
