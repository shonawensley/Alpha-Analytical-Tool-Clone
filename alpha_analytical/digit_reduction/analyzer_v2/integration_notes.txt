Analyzer V2 (Unified) — 2025-09-28
---------------------------------
Entry point: from alpha_analytical.digit_reduction.analyzer_v2 import run
Usage: run(state: str, analysis_root: Path | str | None = None) -> dict

Inputs:
- Reads reducer training artifacts under data/outputs/analysis/digit_reduction/<STATE>/training/
  (expects *digit_reduction_logs.json + companion CSV written by the live module).

Outputs (all under .../<STATE>/analyzer_v2/):
- <STATE>_analyzer_v2_per_item.csv              # unified per-item features + score
- <STATE>_analyzer_v2_own_vs_combined_delta.csv # location-level diagnostics
- <STATE>_analyzer_v2_top_candidates.csv        # high-score rollup by canon
- <STATE>_analyzer_v2_meta.json                 # config snapshot + VTRAC provenance

Feature families preserved:
- Trajectory, tail, stability, permutation density, pre-reduction hints
- Cross-section consensus (Midday/Evening/Combined) with Jaccard + timing spread
- Own vs combined deltas (time-to-3, length, core agreement, missing-mode flag)
- Across-method agreement (counts + early fraction) and cross-column alignment
- Set memory/linger for Set3?2?1 continuity
- Optional VTRAC synergy via analyzer_v2.vtrac_index (predictions JSON preferred, DR-derived fallback)

Scoring:
- Config-driven weights/caps in config.yml (version 3) applied through score.score_row
- Penalties: degenerate.empty, tail.wobble, mode.only_one (zero-safe when fields missing)
- VTRAC boost keyed by weights['vtrac.v_hot'] (default 0.5; set to 0 to disable)

Smoke (from repo root, after reducer ran for the state):
python -c "from pathlib import Path; from alpha_analytical.digit_reduction.analyzer_v2 import run; print(run('Connecticut4', analysis_root=Path('data/outputs/analysis')))"

Guardrails:
- Do NOT modify src/core/module_b_digit_reduction.py or the live reducer — Analyzer V2 is read-only
- Always resolve directories through utils.path_handler (pipeline handles this by default)
- No imports from modules.vtrac_reference; rely solely on analyzer_v2.vtrac_index helpers
- Per-item rows soft-fail (0/False) when signals are absent to avoid regression in sparse data

Winners Overlay (2025-09-29)
----------------------------
Entry points:
- run_winner_overlay(state, winner_combo, variant="Combined", analysis_root=None, when=None)
- run_winner_overlay_batch(state, {"Combined": "237", ...}, analysis_root=None, when=None, mirror_to_winners=True)

Inputs:
- Requires the reducer’s stacked HTML report and latest training JSON under data/outputs/analysis/digit_reduction/<STATE>/training/.

Outputs (per variant):
- analyzer_v2/winners/<STAMP>_<VARIANT>_winner_overlay.html    # annotated stacked report copy
- analyzer_v2/winners/<STAMP>_<VARIANT>_winner_map.json        # machine-readable hits map
- analyzer_v2/winners/<STAMP>_<VARIANT>_winner_hits.csv        # location + step details
- analyzer_v2/winners/<STAMP>_<VARIANT>_winner_flags.csv       # joinable flags for analyzer rows
- analyzer_v2/winners/<STAMP>_<VARIANT>_winner_stamp.json      # summary payload
- winners/<STATE>/stamps/digit_reduction/<STAMP>_<VARIANT>_winner_stamp.json (mirrored when mirror_to_winners=True)

Highlights in overlay:
- dr-winner-exact (gold) wraps any exact permutation of the winner.
- dr-winner-vtrac (orange) wraps any member of the winner’s mirror-family.

DEV helpers:
- Streamlit expander can trigger run_winner_overlay_batch, supplying Combined/Midday/Evening winners and optional Winners logger mirroring.

Join recipe:
- Merge flags CSV onto analyzer_v2 per-item table via [area, section, set, draw, col, method, mode].
- dr_win_exact/dr_win_vtrac = 1 indicate the winner or its VTRAC family touched that location; step columns record earliest match.

Smoke (after reducer + analyzer ran once):
python -c "from pathlib import Path; from alpha_analytical.digit_reduction.analyzer_v2 import run_winner_overlay_batch; print(run_winner_overlay_batch('Connecticut4', {'Combined': '237'}, analysis_root=Path('data/outputs/analysis'), when='20250929', mirror_to_winners=True))"
