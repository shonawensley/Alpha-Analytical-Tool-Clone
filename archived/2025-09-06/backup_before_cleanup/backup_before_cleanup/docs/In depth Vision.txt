Im sure you are familiar with vtrac already but here is a quick refresher.

he term "VTracs" is comprised of "V" for variable and "Tracs" for tracking.  So when you talk about VTracs you're talking about tracking variables.

VTracs uses a system of number substitution to condense regular Pick 3 drawing results into half as many possible combinations.  The number substitution is as follows:

VTrac	Draw Numbers
1	0	5
2	1	6
3	2	7
4	3	8
5	4	9

To differentiate a VTrac 3-digit number from a regular Pick 3 combination, we add a "v" before the number.  Therefore, the VTrac 123 is represented as v123. We need less understanding of the actual naming of the vtrac combination "ex. v123" but more understanding of how the mirror relations of vtrac work very powerfully in how 3 digit or 3 value patterns form in the numerical string r2/r4/r6/r8 groupings pattern progression and string reduction. For example we might find 3 digit pattern "543" or 3 value pattern "5433" hold structure within the pattern progression and then the next winning number is "548 = 543, and 5433" or "593 = 543, 5433".

Each individual pick 3 combination (ex. 055) has vtrac STRAIGHT combination has 8 combinations:
v111	000, 005, 050, 055, 500, 505, 550, 555

This is an easy way to extract straights from the strong permutated patterns we find in the pattern progression of the strings or digit reduction of the r2 tables if we see variation 550 maintain stable structure within the r2/r4/r6/r8 boxes vertically and across the strings playing the 8 combination vtrac can be an easy way to score a straight hit. The V-TRAC (Variable Tracking) Chart Generator is a specialized tool for Pick-3 lottery analysis that creates comprehensive mappings between V-TRAC codes and their corresponding Pick-3 combinations. It handles both boxed and straight permutations according to the V-TRAC system's mirror-pair relationships.

### V-TRAC Mirror Mapping

| V-TRAC | Draw Numbers (Mirror Pairs) |
|--------|---------------------------|
| 1      | 0 ↔ 5                    |
| 2      | 1 ↔ 6                    |
| 3      | 2 ↔ 7                    |
| 4      | 3 ↔ 8                    |
| 5      | 4 ↔ 9                    |

## Core Functionality

### 1. Permutation Generation
- **Singles (3 unique digits)**: Generates 6 unique permutations
  - Example: "015" → ["015", "051", "105", "150", "501", "510"]
- **Doubles (1 repeated digit)**: Generates 3 unique permutations
  - Example: "005" → ["005", "050", "500"]

### 2. Data Structure
Each V-TRAC entry contains:
- Index (1-35)
- V-TRAC code
- Singles Boxed combinations
- Doubles Boxed combinations
- Straight Combinations (all permutations)

from collections import defaultdict

def track_persistent_permutations(draws_data):
    """
    Tracks permutations that persist across multiple R2-R8 levels.

    Parameters:
        draws_data (dict): Dictionary where keys are draw numbers, and values are lists of R2-R8 strings.

    Returns:
        dict: Dictionary of detected stable permutations across multiple draws.
    """
    stable_permutations = defaultdict(int)

    # Iterate through draws
    for draw, levels in draws_data.items():
        for level in levels:
            # Convert level to a set for pattern persistence tracking
            pattern_set = set(level)

            # Track stability across multiple draws
            for existing_pattern in stable_permutations.keys():
                if pattern_set.intersection(set(existing_pattern)):
                    stable_permutations[existing_pattern] += 1
                else:
                    stable_permutations[level] += 1

    # Filter for high-confidence stable patterns
    high_confidence_patterns = {k: v for k, v in stable_permutations.items() if v >= 3}

    return high_confidence_patterns

Expanded Scoring Logic for High-Confidence Predictions
Now that we’ve covered tracking permutation stability, let’s expand on the scoring logic that refines the final selection of combinations. The goal is to assign a weighted score to each generated combination based on:

def calculate_combination_score(permutation, stability, vtrac_match, historical_success, cross_draw_match):
    """
    Calculates a confidence score for a given permutation using weighted factors.

    Parameters:
        permutation (str): The predicted combination.
        stability (int): Score based on pattern persistence across draws.
        vtrac_match (bool): Whether the prediction aligns with a strong VTrac pattern.
        historical_success (float): Past accuracy of this pattern (0.0 - 1.0).
        cross_draw_match (bool): Whether the permutation appears across Midday/Evening draws.

    Returns:
        float: Final confidence score (0 - 1).
    """
    # Assign weights to each factor
    weight_stability = 0.4  # Stability is the most important
    weight_vtrac = 0.3  # VTrac alignment is also important
    weight_history = 0.2  # Past hits influence decision
    weight_cross_draw = 0.1  # If the number appears in both Midday/Evening

    # Convert boolean values to numerical scores
    vtrac_score = 1.0 if vtrac_match else 0.0
    cross_draw_score = 1.0 if cross_draw_match else 0.0

    # Compute weighted confidence score
    confidence_score = (
        (stability * weight_stability) +
        (vtrac_score * weight_vtrac) +
        (historical_success * weight_history) +
        (cross_draw_score * weight_cross_draw)
    )

    return confidence_score

def noise_elimination(strings, noise_threshold=2):
    """
    Reduces strings by eliminating characters considered as noise.
    
    Parameters:
        strings (list of str): List of strings to be reduced.
        noise_threshold (int): Minimum frequency required for a character to be kept.
        
    Returns:
        list: Reduced strings with noise characters removed.
    """
    from collections import Counter
    
    # Count character frequencies across all strings
    all_characters = ''.join(strings)
    char_counts = Counter(all_characters)

    # Identify characters to keep based on noise threshold
    relevant_chars = {char for char, count in char_counts.items() if count >= noise_threshold}

    # Reduce each string by removing noise characters
    reduced_strings = [''.join([char for char in string if char in relevant_chars]) for string in strings]
    
    return reduced_strings

def pattern_matching_reduction(strings, pattern):
    """
    Reduces strings by retaining only parts that match a given pattern.
    
    Parameters:
        strings (list of str): List of strings to reduce.
        pattern (str): Regex pattern to match parts to retain.

def progressive_string_reduction(strings):
    """
    Reduces strings progressively by retaining characters that persist across sequences.
    
    Parameters:
        strings (list of str): List of strings to reduce progressively.
        
    Returns:
        list: Progressively reduced strings.
    """
    if not strings:
        return []
    
    # Start with the first string as a base
    reduced_set = set(strings[0])
    
    for string in strings[1:]:
        # Retain only characters that persist
        reduced_set = reduced_set.intersection(set(string))
    
    # Create reduced strings based on persisting characters
    reduced_strings = [''.join([char for char in string if char in reduced_set]) for string in strings]
    
    return reduced_strings

def adjust_weights_based_on_hits(score_components, past_winning_patterns):
    """
    Adjusts scoring weights dynamically based on recent hit performance.
    """
    for pattern, components in score_components.items():
        if pattern in past_winning_patterns:
            # Increase weights of components that contributed to winning patterns
            for category in components:
                components[category] += 1  # Boost score dynamically

    return score_components

import pandas as pd

def load_draw_data(file_path, sheet_name, draw_type):
    """
    Loads and structures past draw data.

    Parameters:
        file_path (str): Path to the draw data file.
        sheet_name (str): Name of the sheet in Excel.
        draw_type (str): Type of draw ("Midday", "Evening", "Combined").

    Returns:
        list: List of past draw numbers.
    """
    data = pd.read_excel(file_path, sheet_name=sheet_name)
    
    if draw_type not in ["Midday", "Evening", "Combined"]:
        raise ValueError("Invalid draw type specified.")

    return data[draw_type].tail(7).tolist()  # Retrieves the last 7 draws

def update_draw_log(draw_type, new_draw_data):
    """
    Updates the internal log with new draw data.

    Parameters:
        draw_type (str): "Midday", "Evening", or "Combined".
        new_draw_data (list): List of numbers for the new draw.

    Returns:
        None: Updates the global draw log.
    """
    global draw_log
    
    if draw_type not in draw_log:

    draw_log[draw_type].append(new_draw_data)

    # Keep the log size limited to last 30 draws for efficiency
    if len(draw_log[draw_type]) > 30:

from collections import Counter

def hot_and_cold_numbers(draw_log, draw_type, period=20):
    """
    Identifies hot and cold numbers from past draws.

    Parameters:
        draw_log (dict): Dictionary containing draw history.
        draw_type (str): Draw category (Midday, Evening, Combined).
        period (int): Number of draws to analyze.

    Returns:
        dict: Lists of hot and cold numbers.
    """
    numbers = [num for draw in draw_log[draw_type][-period:] for num in draw]
    counts = Counter(numbers)

    # Define hot numbers as top 3 most frequent
    hot_numbers = [num for num, count in counts.most_common(3)]
    # Define cold numbers as least frequent (appeared only once)
    cold_numbers = [num for num, count in counts.items() if count == 1]

    return {"Hot": hot_numbers, "Cold": cold_numbers}

# Example usage:
hot_cold_results = hot_and_cold_numbers(draw_log, "Midday", period=20)
print("Hot Numbers:", hot_cold_results["Hot"])
print("Cold Numbers:", hot_cold_results["Cold"])

def positional_digit_analysis(draw_log, draw_type):
    """
    Analyzes positional digit frequency in past draws.

    Parameters:
        draw_log (dict): Draw history log.
        draw_type (str): "Midday", "Evening", or "Combined".

    Returns:
        dict: Positional digit frequencies.
    """
    position_counts = [Counter() for _ in range(3)]  # Assuming Pick 3 format

    for draw in draw_log[draw_type]:
        for i, digit in enumerate(draw):
            position_counts[i][digit] += 1

    return {f"Position {i+1}": counts for i, counts in enumerate(position_counts)}

# Example usage:
positional_data = positional_digit_analysis(draw_log, "Evening")
print(positional_data)

vtrac_map = {'0': '5', '1': '6', '2': '7', '3': '8', '4': '9',
             '5': '0', '6': '1', '7': '2', '8': '3', '9': '4'}

def vtrac_conversion_for_draws(draw_log, draw_type):
    """
    Converts past draw numbers into VTrac equivalents.

    Parameters:
        draw_log (dict): Historical draw results.
        draw_type (str): "Midday", "Evening", or "Combined".

    Returns:
        list: Converted VTrac numbers.
    """
    return [[''.join(vtrac_map[digit] for digit in draw)] for draw in draw_log[draw_type]]

# Example usage:
vtrac_results = vtrac_conversion_for_draws(draw_log, "Midday")
print("VTrac Converted Draws:", vtrac_results)

# Sample function for Pattern Progression in R2-R8 Strings
import pandas as pd

def analyze_pattern_progression(strings_df):
    """
    Analyzes the progression of patterns across R2-R8 columns and identifies repeating or 
    persistent sequences.
    
    Args:
        strings_df (pd.DataFrame): DataFrame containing R2-R8 columns for multiple draws.
        
    Returns:
        dict: A dictionary with patterns detected and persistence across columns.
    """
    # Dictionary to hold pattern progression data
    progression_results = {
        'draw_number': [],
        'pattern_progression': [],
        'persistent_patterns': [],
        'repeating_sequences': [],
    }
    
    # Iterate through each draw in the DataFrame
    for idx, row in strings_df.iterrows():
        draw_num = row['Draw #']
        pattern_progression = []
        persistent_patterns = set()
        repeating_sequences = set()

        # Check across R2-R8 columns
        previous_pattern = None
        for column in ['R2', 'R4', 'R6', 'R8']:
            current_pattern = row[column]
            
            # Capture pattern progression in sequence
            if previous_pattern and current_pattern.startswith(previous_pattern):
                pattern_progression.append(f"{previous_pattern} -> {current_pattern}")
                persistent_patterns.add(previous_pattern)
            else:
                pattern_progression.append(current_pattern)
            
            # Detect repeating sequences within the same draw (R2-R8)
            if previous_pattern and current_pattern == previous_pattern:
                repeating_sequences.add(current_pattern)
                
            previous_pattern = current_pattern  # Update the previous pattern for next iteration
            
        # Store results for this draw
        progression_results['draw_number'].append(draw_num)
        progression_results['pattern_progression'].append(pattern_progression)
        progression_results['persistent_patterns'].append(list(persistent_patterns))
        progression_results['repeating_sequences'].append(list(repeating_sequences))
    
    return pd.DataFrame(progression_results)

from collections import defaultdict

def track_persistent_permutations(draws_data):
    """
    Tracks permutations that persist across multiple R2-R8 levels.

    Parameters:
        draws_data (dict): Dictionary where keys are draw numbers, and values are lists of R2-R8 strings.

    Returns:
        dict: Dictionary of detected stable permutations across multiple draws.
    """
    stable_permutations = defaultdict(int)

    # Iterate through draws
    for draw, levels in draws_data.items():
        for level in levels:
            # Convert level to a set for pattern persistence tracking
            pattern_set = set(level)

            # Track stability across multiple draws
            for existing_pattern in stable_permutations.keys():
                if pattern_set.intersection(set(existing_pattern)):
                    stable_permutations[existing_pattern] += 1
                else:
                    stable_permutations[level] += 1

    # Filter for high-confidence stable patterns
    high_confidence_patterns = {k: v for k, v in stable_permutations.items() if v >= 3}

    return high_confidence_patterns

def calculate_combination_score(permutation, stability, vtrac_match, historical_success, cross_draw_match):
    """
    Calculates a confidence score for a given permutation using weighted factors.

    Parameters:
        permutation (str): The predicted combination.
        stability (int): Score based on pattern persistence across draws.
        vtrac_match (bool): Whether the prediction aligns with a strong VTrac pattern.
        historical_success (float): Past accuracy of this pattern (0.0 - 1.0).
        cross_draw_match (bool): Whether the permutation appears across Midday/Evening draws.

    Returns:
        float: Final confidence score (0 - 1).
    """
    # Assign weights to each factor
    weight_stability = 0.4  # Stability is the most important
    weight_vtrac = 0.3  # VTrac alignment is also important
    weight_history = 0.2  # Past hits influence decision
    weight_cross_draw = 0.1  # If the number appears in both Midday/Evening

    # Convert boolean values to numerical scores
    vtrac_score = 1.0 if vtrac_match else 0.0
    cross_draw_score = 1.0 if cross_draw_match else 0.0

    # Compute weighted confidence score
    confidence_score = (
        (stability * weight_stability) +
        (vtrac_score * weight_vtrac) +
        (historical_success * weight_history) +
        (cross_draw_score * weight_cross_draw)
    )

    return confidence_score

✅ Stability Score (40%) → Prioritizes numbers that hold their structure across multiple draws.
✅ VTrac Alignment (30%) → Boosts numbers that match a known VTrac pattern.
✅ Historical Success (20%) → Accounts for numbers that have hit frequently in past draws.
✅ Cross-Draw Match (10%) → Ensures the number appears in both Midday and Evening draws.

Each factor contributes to the final score based on how relevant it is to successful predictions.

def calculate_historical_success(prediction, historical_wins):
    """
    Assigns a historical success score based on past performance of a combination.

    Parameters:
        prediction (str): The predicted combination.
        historical_wins (list): List of past winning numbers.

    Returns:
        float: Historical success score (0 - 1).
    """
    # Assign different weight categories
    weight_exact_match = 0.2  # Low weight for direct repeats
    weight_vtrac_match = 0.5  # High weight for VTrac similarities
    weight_mirror_match = 0.3  # Medium weight for mirrored past hits

    # Convert prediction to VTrac equivalent
    vtrac_conversion = {"0": "5", "1": "6", "2": "7", "3": "8", "4": "9", "5": "0", "6": "1", "7": "2", "8": "3", "9": "4"}
    prediction_vtrac = ''.join(vtrac_conversion[digit] for digit in prediction)

    # Initialize score
    historical_score = 0

    for past_win in historical_wins:
        past_vtrac = ''.join(vtrac_conversion[digit] for digit in past_win)

        if prediction == past_win:
            historical_score += weight_exact_match  # Low weight for exact past win
        elif prediction_vtrac == past_vtrac:
            historical_score += weight_vtrac_match  # Higher weight for VTrac match
        elif any(digit in past_win for digit in prediction):  
            historical_score += weight_mirror_match  # Medium weight for mirrored relationships

    # Normalize score between 0 - 1
    return min(1, historical_score / len(historical_wins))

def calculate_combination_score(permutation, stability, vtrac_match, historical_success, cross_draw_match):
    """
    Calculates a confidence score for a given permutation.

    Parameters:
        permutation (str): The predicted combination.
        stability (int): Score based on pattern persistence.
        vtrac_match (bool): Whether the prediction aligns with a strong VTrac pattern.
        historical_success (float): Past accuracy of this pattern (0.0 - 1.0).
        cross_draw_match (bool): Whether the permutation appears across Midday/Evening draws.

    Returns:
        float: Final confidence score (0 - 1).
    """
    weight_stability = 0.4
    weight_vtrac = 0.3
    weight_history = 0.2  # Historical success influences, but does NOT dominate
    weight_cross_draw = 0.1

    vtrac_score = 1.0 if vtrac_match else 0.0
    cross_draw_score = 1.0 if cross_draw_match else 0.0

    confidence_score = (
        (stability * weight_stability) +
        (vtrac_score * weight_vtrac) +
        (historical_success * weight_history) +
        (cross_draw_score * weight_cross_draw)
    )

    return confidence_score
