This module extracts and minimally scores 3-value patterns from R2/R4/R6/R8 datasets.

def is_3_value_pattern(cluster: str) -> bool:
    """
    Check if 'cluster' is a valid 3-value pattern.
    A valid pattern has a length between 3 and 5 and contains at most 3 unique digits.
    
    Examples:
      "31166" -> True (3 unique digits: 3,1,6)
      "316"   -> True (3 unique digits)
      "066"   -> True (2 unique digits)
      "518476" -> False (more than 3 unique digits)
    """
    unique_digits = set(cluster)
    if len(cluster) < 3 or len(cluster) > 5:
        return False
    return len(unique_digits) <= 3

def extract_3_value_substrings(string: str):
    """
    Extract all distinct substrings within 'string' that qualify as a 3-value pattern.
    Only substrings of length 3 to 5 with at most 3 unique digits are returned.
    
    Returns:
        A sorted list of valid substrings.
    """
    found = set()
    n = len(string)
    for start_idx in range(n):
        for end_idx in range(start_idx + 3, min(start_idx + 6, n + 1)):
            substr = string[start_idx:end_idx]
            if is_3_value_pattern(substr):
                found.add(substr)
    return sorted(found)

def vertical_stable_structure_score(r2: str, r4: str, r6: str, r8: str) -> int:
    """
    Compute a minimal vertical stability score based on the last few digits of each row.
    A higher score indicates that the end parts of R2, R4, R6, and R8 share common digits,
    suggesting stable structure.
    
    Returns:
        An integer stability score.
    """
    score = 0
    # Use the last 4 digits (or entire string if shorter) from each row.
    short_r2 = r2[-4:] if len(r2) >= 4 else r2
    short_r4 = r4[-4:] if len(r4) >= 4 else r4
    short_r6 = r6[-4:] if len(r6) >= 4 else r6
    short_r8 = r8[-4:] if len(r8) >= 4 else r8

    # Compute intersection of digits
    common_digits = set(short_r2) & set(short_r4) & set(short_r6) & set(short_r8)
    score += len(common_digits)
    
    return score

def detect_consensus_pattern(*rows: str):
    """
    Checks if the given rows (typically R2, R4, R6, R8) have a consensus pattern.
    For simplicity, this function checks if the last row (or a designated row) is composed
    of a single repeated digit (e.g., "4444").
    
    Returns:
        Tuple (bool, digit) where bool is True if consensus is found, and digit is the repeated digit.
    """
    # We'll check the last row provided
    target = rows[-1]
    if target and len(set(target)) == 1:
        return (True, target[0])
    return (False, None)

def horizontal_3digit_repeat(strings_in_row: list) -> list:

    Detects 3-digit patterns that are repeated in adjacent columns.
    
    Parameters:
        strings_in_row: A list of string values from different columns in the same row.
        
    Returns:
        A sorted list of repeated 3-digit patterns.

    column_substrings = []
    for s in strings_in_row:
        subs = set()
        if s:
            for i in range(len(s) - 2):
                subs.add(s[i:i+3])
        column_substrings.append(subs)
    
    for i in range(len(column_substrings) - 1):
        common = column_substrings[i] & column_substrings[i+1]
        repeated_patterns.update(common)
    
    return sorted(repeated_patterns)

                "R6": r6_repeat,

digit_reduction.py

This module implements comprehensive digit reduction logic for our Pick-3 analysis system.
It incorporates:

5. Output structure that can be fed forward to our higher-level Analysis and ML modules.

# VTrac mirror mapping as defined (1↔6, 2↔7, 3↔8, 4↔9, 0↔5)
MIRROR_MAP = {
    '0': '5', '1': '6', '2': '7', '3': '8', '4': '9',
    '5': '0', '6': '1', '7': '2', '8': '3', '9': '4'
}

def mirror_digit(digit: str) -> str:
    """Return the mirror (VTrac-based) digit using the MIRROR_MAP."""
    return MIRROR_MAP.get(digit, digit)

def remove_digits_from_string(original_str: str, digits_to_remove: set, remove_mirrors: bool = False) -> str:
    """
    Removes all occurrences of characters in 'digits_to_remove' from 'original_str'.
    If remove_mirrors is True, also removes each digit's mirror equivalent.
    """
    removal_pool = set(digits_to_remove)
    if remove_mirrors:
        for d in list(digits_to_remove):
            removal_pool.add(mirror_digit(d))
    return ''.join(ch for ch in original_str if ch not in removal_pool)

def reduce_by_past_draw_single(r2_string: str, past_draw_digits: str, remove_mirror: bool = False) -> str:
    """
    For a single R2 string, remove all digits present in 'past_draw_digits'.
    Optionally, also remove the mirror equivalents.
    Example: r2_string = "55922440013867", past_draw_digits = "147".
    """
    digits_set = set(past_draw_digits)
    return remove_digits_from_string(r2_string, digits_set, remove_mirror)

def reduce_by_past_draw_all(r2_strings: list, past_draw_digits: str, remove_mirror: bool = False) -> list:
    """
    Apply reduce_by_past_draw_single to an entire list of R2 strings.
    Returns a list of reduced strings.
    """
    return [reduce_by_past_draw_single(s, past_draw_digits, remove_mirror) if s else "" for s in r2_strings]

def multi_draw_reduction(r2_strings: list, midday_digits: str, evening_digits: str,
                         strategy: str = "combined", remove_mirror: bool = False) -> list:
    """
    Applies a reduction based on a specified strategy:
      - "combined": Remove digits from both midday and evening (i.e. combined set).
      - "own_draw": Remove digits from one draw type (e.g., midday) only.
      - "all_values": Remove digits from both sets, potentially with mirror removals.
    Returns a new list of reduced R2 strings.
    """
    if strategy == "combined":
        to_remove = set(midday_digits + evening_digits)
    elif strategy == "own_draw":
        to_remove = set(midday_digits)
    elif strategy == "all_values":
        to_remove = set(midday_digits + evening_digits)
    else:
        to_remove = set(midday_digits)  # default fallback

    return [remove_digits_from_string(s, to_remove, remove_mirror) if s else "" for s in r2_strings]

def evaluate_765_strings(r2_strings: list) -> list:
    """
    Scans through R2 strings (typically longer strings from the full R2/R4/R6/R8 grouping)
    and selects those that have lengths between 5 and 7 (inclusive), which may hide a strong 3-value pattern.
    Returns a list of dictionaries with the original string, its length, and a basic category note.
    """
    results = []
    for s in r2_strings:
        if not s:
            continue
        if 5 <= len(s) <= 7:
            results.append({
                "string": s,
                "length": len(s),
                "category": "7/6/5 candidate"
            })

def progressive_reduce_765(r2_strings: list, digits_to_remove: str, remove_mirror: bool = False) -> list:
    """
    Applies a multi-step reduction on strings from the 7/6/5 category.
    First removes all occurrences of digits_to_remove (direct removal), then, if still long,
    removes the mirror equivalents. This helps reveal a condensed core pattern.
    """
    results = []
    for s in r2_strings:
        if not s:
            results.append("")
            continue
        # Step 1: Remove direct digits
        step1 = remove_digits_from_string(s, set(digits_to_remove), remove_mirror=False)
        # Step 2: If the resulting string is still longer than 5 digits, remove mirrors as well
        final = step1 if len(step1) <= 5 else remove_digits_from_string(step1, set(digits_to_remove), remove_mirror=True)
        results.append(final)
    return results

def single_digit_transit_reduction(strings_list: list, forced_digit: str = None) -> list:
    """
    Optionally removes one digit from each string—either a 'forced_digit' (if provided) or by default,
    simply removing the last digit.
    This may reveal a final 3-value cluster.
    """
    output = []
    for s in strings_list:
        if not s:
            output.append("")
        elif forced_digit and forced_digit in s:
            # Remove only one occurrence of the forced digit
            output.append(s.replace(forced_digit, "", 1))
        else:
            # Remove the last character as a fallback
            output.append(s[:-1])
    return output

def score_reduced_strings(r2_reduced_list: list) -> list:
    """
    Assigns a minimal score to each reduced string.
      - Length 3: +2 points
      - Length 2: +1 point
      - Additional bonus if the string has only 2 unique digits (indicating a double)
    Returns a list of tuples: (string, score)
    """
    scored = []
    for s in r2_reduced_list:
        base_score = 0
        if not s:
            scored.append((s, base_score))
            continue
        unique_digs = set(s)
        if len(s) == 3:
            base_score += 2
        elif len(s) == 2:
            base_score += 1
        if len(unique_digs) == 2 and len(s) > 1:
            base_score += 1
        scored.append((s, base_score))
    return scored

        single_digit_removed = single_digit_transit_reduction(r2_list)

            "single_digit_removed": single_digit_removed,
            "single_digit_scored": single_digit_scored,
            "cat765_info": cat765_info
        })
    return results

6. Producing a final sorted list of patterns for further processing.

This module assumes that the inputs follow the structured formats produced by 
your pattern_extractor.py and digit_reduction.py modules.
"""

import itertools
from collections import defaultdict
from typing import List, Dict, Any

# ---------------------------------------------------------------------------

# Mirror/V-Trac mapping (Pick 3 style)
MIRROR_MAP = {
    '0': '5', '1': '6', '2': '7', '3': '8', '4': '9',
    '5': '0', '6': '1', '7': '2', '8': '3', '9': '4'
}

def mirror_digit(d: str) -> str:
    """Return the V-Trac mirror digit."""
    return MIRROR_MAP.get(d, d)

def is_3_value_pattern(string_value: str) -> bool:
    """
    Check if a string qualifies as a "3-value pattern": its length is between 3 and 5 
    and it contains at most 3 unique digits.
    """
    if len(string_value) < 3 or len(string_value) > 5:
        return False
    return len(set(string_value)) <= 3

def vtrac_equivalent(str1: str, str2: str) -> bool:
    """
    Check if two 3-digit patterns are V-Trac equivalents.
    For simplicity, mirror str1 and compare to str2.
    """
    mirrored = ''.join(mirror_digit(d) for d in str1)
    return mirrored == str2

def aggregate_extractor_results(pattern_extractor_output: List[Dict[str, Any]]) -> List[Dict[str, Any]]:
    """
    Flatten the output from the Pattern Extractor.
    Expected input:
      [
         {"draw_type": "Midday", "patterns_found": [
             {"pattern": "41188", "stable_structure": True, "consensus": False, "hot_zone": True, "3_digit_repeat": False},
             ... ]
         },
         ...
      ]
    Returns a list of dictionaries, each with pattern details.
    """
    aggregated = []
    for draw_result in pattern_extractor_output:
        for p in draw_result.get("patterns_found", []):
            aggregated.append({
                "draw_type": draw_result["draw_type"],
                "pattern": p["pattern"],
                "stable_structure": p.get("stable_structure", False),
                "consensus": p.get("consensus", False),
                "hot_zone": p.get("hot_zone", False),
                "3_digit_repeat": p.get("3_digit_repeat", False)
            })
    return aggregated

def aggregate_digit_reduction_results(digit_reduction_output: List[Dict[str, Any]]) -> List[Dict[str, Any]]:
    """
    Flatten the digit reduction output.
    Expected input:
      [
         {"draw_type": "Midday",
          "own_scored": [("41188", 2), ("2486", 3)],
          "combined_scored": [("541", 2), ("548", 3)]
         },
         ...
      ]
    Returns a list of dictionaries with pattern info.
    """
    aggregated = []
    for draw_set in digit_reduction_output:
        draw_type = draw_set["draw_type"]
        for (reduced_str, base_score) in draw_set.get("own_scored", []):
            if is_3_value_pattern(reduced_str):
                aggregated.append({
                    "draw_type": draw_type,
                    "pattern": reduced_str,
                    "digit_reduction_match": True,
                    "base_reduction_score": base_score
                })
        for (reduced_str, base_score) in draw_set.get("combined_scored", []):
            if is_3_value_pattern(reduced_str):
                aggregated.append({
                    "draw_type": draw_type,
                    "pattern": reduced_str,
                    "digit_reduction_match": True,
                    "base_reduction_score": base_score
                })
    return aggregated

def cross_draw_check(analysis_items: List[Dict[str, Any]]) -> None:
    """
    For each pattern, mark if it appears in multiple draw types (e.g., Midday and Evening).
    """
    pattern_map = defaultdict(set)
    for item in analysis_items:
        pattern_map[item["pattern"]].add(item["draw_type"])
    for item in analysis_items:
        item["cross_draw_reinforcement"] = len(pattern_map[item["pattern"]]) > 1

def check_vtrac_across_items(analysis_items: List[Dict[str, Any]]) -> None:
    """
    Mark items as V-Trac equivalent if they are 3-digit patterns and are mirror-equivalent.
    """
    n = len(analysis_items)
    for i in range(n):
        p1 = analysis_items[i]["pattern"]
        for j in range(i+1, n):
            p2 = analysis_items[j]["pattern"]
            if len(p1) == 3 and len(p2) == 3 and vtrac_equivalent(p1, p2):
                analysis_items[i]["vtrac_equiv"] = True
                analysis_items[j]["vtrac_equiv"] = True

def identify_3_digit_repeats(analysis_items: List[Dict[str, Any]]) -> None:
    """
    Flag patterns that occur more than once.
    """
    freq_map = defaultdict(int)
    for item in analysis_items:
        freq_map[item["pattern"]] += 1
    for item in analysis_items:
        item["3_digit_repeat_scored"] = freq_map[item["pattern"]] > 1

# Example configurable scoring weights
SCORING_WEIGHTS = {
    "stable_structure": 2.0,
    "3_digit_repeat": 1.5,
    "consensus_pattern": 1.5,

    "digit_reduction_match": 1.0,
    "vtrac_equiv": 1.0

def compute_pattern_score(item: Dict[str, Any], weights=SCORING_WEIGHTS) -> float:
    """
    Compute a final score for a pattern item based on several criteria.
    """
    score = 0.0
    if item.get("stable_structure", False):
        score += weights.get("stable_structure", 2.0)
    if item.get("consensus", False):
        score += weights.get("consensus_pattern", 1.5)
    if item.get("hot_zone", False):
        score += weights.get("hot_zone", 1.2)
    if item.get("3_digit_repeat", False) or item.get("3_digit_repeat_scored", False):
        score += weights.get("3_digit_repeat", 1.5)
    if item.get("cross_draw_reinforcement", False):
        score += weights.get("cross_draw_reinforcement", 1.2)
    if item.get("digit_reduction_match", False):
        score += weights.get("digit_reduction_match", 1.0)
    if item.get("vtrac_equiv", False):
        score += weights.get("vtrac_equiv", 1.0)
    # Bonus if the pattern qualifies as a 3-value pattern (even if length > 3)
    if is_3_value_pattern(item["pattern"]):
        score += 1.0
    return score

def finalize_scoring(all_items: List[Dict[str, Any]]) -> None:
    """
    Compute and store a final score for each pattern item.
    """
    for item in all_items:
        item["final_score"] = compute_pattern_score(item)

def sort_by_score_desc(all_items: List[Dict[str, Any]]) -> List[Dict[str, Any]]:
    """Sort the list of pattern items in descending order by final_score."""
    return sorted(all_items, key=lambda x: x.get("final_score", 0), reverse=True)

def perform_analysis_and_scoring(pattern_extractor_output: List[Dict[str, Any]],

    Aggregates outputs from the pattern extractor and digit reduction modules,

"""
combination_forming.py

Module #4: Combination Forming

This module:
1. Receives a list of top-scoring patterns (with associated features such as draw_type, final_score, is_double, consensus, hot_zone, etc.)
2. Dynamically selects one of five V‑Trac combination methods for each pattern using a rule-based "Method Recommender".
3. For each pattern, produces final playable Pick‑3 combinations using the chosen method.
4. Minimizes overall expense by limiting the total number of combinations played.
5. Returns a structured dictionary summarizing final recommended combos along with metadata.

The five combination methods are:
    Method 1: Keep Pair + Mirror 3rd Digit (≈12 permutations)
    Method 2: Keep Only Primary Permutation (≈3 combos)
    Method 3: Prioritize Doubles and Mirror (≈6 combos)
    Method 4: Identify Double & Mirror Double (≈6 combos)
    Method 5: Full V-Trac Straight (exactly 8 combos)

All methods leverage V-Trac mirror mappings and permutation logic.
"""

import itertools
from typing import List, Dict, Any, Set
from collections import defaultdict

###########################################
# 1. Configuration and Helper Functions
###########################################

# V-Trac mirror mapping (Pick 3 style)
MIRROR_MAP = {
    '0': '5', '1': '6', '2': '7', '3': '8', '4': '9',
    '5': '0', '6': '1', '7': '2', '8': '3', '9': '4'
}

def mirror_digit(d: str) -> str:
    """Return the V-Trac mirror digit for d."""
    return MIRROR_MAP.get(d, d)

def mirror_string(s: str) -> str:
    """Return the V-Trac mirror of an entire string."""
    return ''.join(mirror_digit(ch) for ch in s)

def generate_3_digit_permutations(pattern: str) -> List[str]:
    """
    Generate all unique permutations of a 3-digit pattern.
    Example: '123' → ['123','132','213','231','312','321']
    """
    perms = set(itertools.permutations(pattern, 3))
    return sorted(''.join(p) for p in perms)

def is_double(pattern: str) -> bool:
    """
    Check if a 3-digit pattern has exactly 2 unique digits.
    E.g., '411' returns True.
    """
    return len(pattern) == 3 and len(set(pattern)) == 2

def is_triple(pattern: str) -> bool:
    """
    Check if a 3-digit pattern consists of the same digit.
    E.g., '555' returns True.
    """
    return len(pattern) == 3 and len(set(pattern)) == 1

###########################################
# 2. V-Trac Combination Methods
###########################################

def method1_keep_pair_mirror_third(pattern: str) -> List[str]:
    """
    Method 1: Keep Pair + Mirror the 3rd Digit.
    For a 3-digit pattern, generate three variants:
      - Variant 1: Use first two digits as-is and mirror the third.
      - Variant 2: Mirror the first digit and append the last two digits.
      - Variant 3: Keep the first digit, mirror the second, then the third.
    Then generate all permutations for each variant.
    Returns up to 12 unique combinations.
    """
    if len(pattern) != 3:
        return [pattern]  # fallback if not 3 digits

    variants = set()
    # Variant 1: first two as-is, mirror third
    variant1 = pattern[:2] + mirror_digit(pattern[2])
    # Variant 2: mirror first, then digits 2 and 3 as-is
    variant2 = mirror_digit(pattern[0]) + pattern[1:]
    # Variant 3: first as-is, mirror second, then third as-is
    variant3 = pattern[0] + mirror_digit(pattern[1]) + pattern[2]
    for variant in [variant1, variant2, variant3]:
        for perm in itertools.permutations(variant, 3):
            variants.add(''.join(perm))
    return sorted(variants)

def method2_keep_only_primary_permutation(pattern: str) -> List[str]:
    """
    Method 2: Use only the primary permutation.
    Return the pattern and its mirror as the only two options.
    Typically yields only 2–3 combinations.
    """
    results = {pattern, mirror_string(pattern)}
    return sorted(results)

def method3_prioritize_doubles_and_mirror(pattern: str) -> List[str]:
    """
    Method 3: For a double pattern (e.g., '411'), generate:
      - All unique permutations of the original pattern.
      - All unique permutations of the fully mirrored pattern.
    Returns a set (typically around 6 combos).
    If pattern is not a double, fallback to regular permutations.
    """
    combos = set()
    if not is_double(pattern):
        combos.update(generate_3_digit_permutations(pattern))
        return sorted(combos)
    # Original permutations
    combos.update(generate_3_digit_permutations(pattern))
    # Mirror the entire pattern (e.g., '411' → '466')
    mirrored = mirror_string(pattern)
    combos.update(generate_3_digit_permutations(mirrored))
    return sorted(combos)

def method4_identify_double_and_mirror_double(pattern: str) -> List[str]:
    """
    Method 4: For a double pattern, generate both the original and its mirror double.
    Example: For '422', mirror double is '977' (if 4→9, 2→7).
    Then generate permutations for both.
    """
    combos = set()
    combos.update(generate_3_digit_permutations(pattern))
    if is_double(pattern):
        mirror_dbl = mirror_string(pattern)
        combos.update(generate_3_digit_permutations(mirror_dbl))
    return sorted(combos)

def method5_full_vtrac_straight(pattern: str) -> List[str]:
    """
    Method 5: Generate all 8 V-Trac variations for a 3-digit pattern.
    For each digit, decide to use it as-is or its mirror.
    This yields 2^3 = 8 combinations.
    No further permutation is applied (i.e., treat as a straight play).
    """
    if len(pattern) != 3:
        return [pattern]
    digits = list(pattern)
    results = set()
    # For 3 digits, generate all combinations of flip (0 or 1 for each digit)
    for flips in itertools.product([0, 1], repeat=3):
        new_number = ''.join(mirror_digit(d) if flip else d for d, flip in zip(digits, flips))
        results.add(new_number)
    return sorted(results)

# 3. Expense Minimization Helper
###########################################

def limit_combinations(combos: List[str], max_plays: int = 12) -> List[str]:
    """
    Limits the number of final combinations to a maximum number (max_plays).
    This can be done by simply taking the first N unique sorted combos.
    """
    unique_combos = sorted(set(combos))
    return unique_combos[:max_plays] if len(unique_combos) > max_plays else unique_combos

# 4. Dynamic Method Recommender
###########################################

def choose_vtrac_method(pattern_info: Dict[str, Any]) -> int:
    """
    Dynamically select which V-Trac combination method to use for a given pattern,
    based on its features in pattern_info. This rule-based approach can later be
    extended with an ML model.
    
    Expected keys in pattern_info:
      - 'pattern': the 3-digit string.
      - 'is_double': bool indicating if the pattern is a double.
      - 'consensus': bool, if consensus was flagged.
      - 'final_score': numeric score from analysis.
    
    Returns:
      An integer method id (1-5).
    """
    # Example simple rules:
    if pattern_info.get("consensus", False):
        # If consensus is detected, prefer double/mirror double approach.
        return 4
    if pattern_info.get("is_double", False):
        return 3
    if pattern_info.get("final_score", 0) >= 9.0:
        return 5  # For very strong patterns, use full V-Trac straight.
    # Default:
    return 1

###########################################
# 5. Master Combination Generator Functions
###########################################

def form_combinations_for_pattern(pattern: str, method: int) -> List[str]:
    """
    Generate playable combinations for a single pattern using the chosen method.
    
    Parameters:
      - pattern: a 3-digit string (or 3-value pattern).
      - method: an integer 1-5 corresponding to the methods defined.
    
    Returns:
      A list of combination strings.
    """
    if len(pattern) < 3:
        return []
    if method == 1:
        return method1_keep_pair_mirror_third(pattern)
    elif method == 2:
        return method2_keep_only_primary_permutation(pattern)
    elif method == 3:
        return method3_prioritize_doubles_and_mirror(pattern)
    elif method == 4:
        return method4_identify_double_and_mirror_double(pattern)
    elif method == 5:
        return method5_full_vtrac_straight(pattern)
    else:
        return generate_3_digit_permutations(pattern)

def unify_and_minimize_combos(patterns_info: List[Dict[str, Any]], max_plays: int = 12) -> List[str]:
    """
    For each pattern in patterns_info (each a dict with keys including 'pattern',
    'is_double', 'final_score', etc.), use the dynamic method recommender to choose
    a combination method, generate combos, and merge them into a unified set.
    Finally, limit the total number of combinations to max_plays.
    
    Returns a final sorted list of combination strings.
    """
    all_combos = set()
    for pat_info in patterns_info:
        pat = pat_info.get("pattern", "")
        method_choice = choose_vtrac_method(pat_info)
        combos = form_combinations_for_pattern(pat, method_choice)
        all_combos.update(combos)
    return limit_combinations(list(all_combos), max_plays)

def generate_final_combinations(scored_patterns: List[Dict[str, Any]],
                                draw_type_filter: str = "Midday",
                                top_n: int = 5,
                                max_plays: int = 12) -> Dict[str, Any]:
    """
    High-level function that:
      1. Filters scored_patterns by draw_type (e.g., "Midday", "Evening", or "Combined").
      2. Sorts patterns by their final_score in descending order.
      3. Selects the top_n patterns.
      4. For each top pattern, dynamically chooses a V-Trac combination method,
         generates combinations, and unifies them.
      5. Returns a dictionary with metadata and final recommended combination list.
    
    Returns:
      {
          "draw_type": draw_type_filter,
          "top_patterns": [list of pattern strings],
          "final_combos": [final combination strings]
      }
    """
    # 1. Filter patterns by draw_type (if not "Combined", otherwise keep all)
    filtered = [p for p in scored_patterns if p.get("draw_type", "").lower() == draw_type_filter.lower() or draw_type_filter.lower() == "combined"]
    
    # 2. Sort by final_score descending
    filtered_sorted = sorted(filtered, key=lambda x: x.get("final_score", 0), reverse=True)
    
    # 3. Select top_n patterns
    top_patterns = filtered_sorted[:top_n]
    
    # 4. Gather pattern information for dynamic method selection
    final_pattern_infos = []
    for pat in top_patterns:
        # You can include additional features if available
        info = {
            "pattern": pat.get("pattern", ""),
            "is_double": is_double(pat.get("pattern", "")),
            "consensus": pat.get("consensus", False),
            "final_score": pat.get("final_score", 0)
        }
        final_pattern_infos.append(info)
    
    # 5. Unify all combos using dynamic method selection
    final_combos = unify_and_minimize_combos(final_pattern_infos, max_plays=max_plays)
    
    # 6. Structure and return final result
    result = {
        "draw_type": draw_type_filter,
        "top_patterns": [p["pattern"] for p in top_patterns],
        "final_combos": final_combos
    }
    return result

def create_feature_matrix(aggregated_data: pd.DataFrame) -> pd.DataFrame:
    """
    Given aggregated pattern data, build a feature matrix for ML training.
    
    Expected aggregated_data columns might include:
      - 'pattern' (string)
      - 'stable_structure' (bool)
      - 'consensus' (bool)
      - 'hot_zone' (bool)
      - '3_digit_repeat' (bool)
      - 'cross_draw_reinforcement' (bool)
      - 'base_reduction_score' (numeric)
      - 'final_score' (numeric) [if already computed]
    
    Additional derived features:
      - digit_sum: Sum of the digits in the pattern.
      - unique_digit_count: Number of unique digits in the pattern.
      - pattern_length: Length of the pattern.
      
    Returns a pandas DataFrame with all features.
    """
    features = []
    for idx, row in aggregated_data.iterrows():
        pattern = str(row.get("pattern", ""))
        # Convert each character to int if possible
        try:
            digits = [int(d) for d in pattern]
        except ValueError:
            digits = [0] * len(pattern)
        feature_row = {
            "pattern": pattern,
            "pattern_length": len(pattern),
            "digit_sum": sum(digits),
            "unique_digit_count": len(set(pattern)),
            "stable_structure": int(row.get("stable_structure", False)),
            "consensus": int(row.get("consensus", False)),
            "hot_zone": int(row.get("hot_zone", False)),
            "three_digit_repeat": int(row.get("3_digit_repeat", False) or row.get("3_digit_repeat_scored", False)),
            "cross_draw_reinforcement": int(row.get("cross_draw_reinforcement", False)),
            "digit_reduction_match": int(row.get("digit_reduction_match", False)),
            "vtrac_equiv": int(row.get("vtrac_equiv", False)),
            "base_reduction_score": float(row.get("base_reduction_score", 0)),
            "final_score": float(row.get("final_score", 0))
        }
        features.append(feature_row)
    return pd.DataFrame(features)

class Predictor:
    """
    Predictor class that wraps machine learning functionality.
    
    By default, it uses RandomForestClassifier, but can be extended to XGBoost.
    """
    def __init__(self, model_type: str = "random_forest", random_state: int = 42):
        self.model_type = model_type.lower()
        self.random_state = random_state
        self.model = None

    def train(self, X: pd.DataFrame, y: pd.Series):
        """
        Train the ML model on the given feature matrix X and target labels y.
        """
        if self.model_type == "random_forest":
            self.model = RandomForestClassifier(n_estimators=100, random_state=self.random_state)
            self.model.fit(X, y)
        elif self.model_type == "xgboost":
            # Uncomment if using xgboost:
            # import xgboost as xgb
            # self.model = xgb.XGBClassifier(use_label_encoder=False, eval_metric='logloss', random_state=self.random_state)
            # self.model.fit(X, y)
            pass
        else:
            raise ValueError(f"Unsupported model type: {self.model_type}")

    def predict(self, X_new: pd.DataFrame) -> np.ndarray:
        """
        Make predictions on new feature data X_new.
        Returns predicted probabilities for the positive class.
        """
        if self.model is None:
            raise Exception("Model is not trained yet!")
        return self.model.predict_proba(X_new)[:, 1]

    def evaluate(self, X_test: pd.DataFrame, y_test: pd.Series) -> dict:
        """
        Evaluate the model using accuracy, precision, recall, and F1 score.
        """
        from sklearn.metrics import accuracy_score, precision_score, recall_score, f1_score
        y_pred = self.model.predict(X_test)
        return {
            "accuracy": accuracy_score(y_test, y_pred),
            "precision": precision_score(y_test, y_pred, zero_division=0),
            "recall": recall_score(y_test, y_pred, zero_division=0),
            "f1_score": f1_score(y_test, y_pred, zero_division=0)
        }

        # Example round configuration. Adjust as needed.

        Given the number of combinations (n_combos) and current round,
        calculate the cost and potential payout.
        'play_type' determines which base payout to use.
        """
        if current_round >= len(self.rounds):
            current_round = len(self.rounds) - 1
        round_info = self.rounds[current_round]
        cost = (10 * round_info['multiplier']) * n_combos  # Example: $10 ticket multiplied
        base_payout = 500 if play_type == "straight" else 100
        potential_payout = base_payout * round_info['multiplier']
        return cost, potential_payout

def build_feature_vector(pattern_item: dict) -> dict:
    """
    Build a feature vector from a single pattern item (a dictionary produced by analysis_and_scoring).
    Expected keys in pattern_item may include:
        - pattern: str, the 3-digit or 3-value pattern.
        - final_score: numeric, the overall score from analysis.
        - stable_structure: bool
        - consensus: bool
        - hot_zone: bool
        - cross_draw_reinforcement: bool
        - digit_reduction_match: bool
        - vtrac_equiv: bool
        - 3_digit_repeat_scored: bool
    Returns a dictionary of features.
    """
    # Convert booleans to int (1 for True, 0 for False)
    features = {
        "digit_sum": sum(int(d) for d in pattern_item.get("pattern", "")),
        "length": len(pattern_item.get("pattern", "")),
        "final_score": pattern_item.get("final_score", 0),
        "stable_structure": 1 if pattern_item.get("stable_structure", False) else 0,
        "consensus": 1 if pattern_item.get("consensus", False) else 0,
        "hot_zone": 1 if pattern_item.get("hot_zone", False) else 0,
        "cross_draw": 1 if pattern_item.get("cross_draw_reinforcement", False) else 0,
        "digit_reduction": 1 if pattern_item.get("digit_reduction_match", False) else 0,
        "vtrac_equiv": 1 if pattern_item.get("vtrac_equiv", False) else 0,
        "three_digit_repeat": 1 if pattern_item.get("3_digit_repeat_scored", False) else 0,
    }
    return features

def build_feature_matrix(historical_data: list) -> pd.DataFrame:
    """
    Build a feature matrix (pandas DataFrame) from a list of pattern items.
    Each item in historical_data is a dictionary (as produced by analysis_and_scoring).
    """
    feature_list = [build_feature_vector(item) for item in historical_data]
    return pd.DataFrame(feature_list)

class Predictor:
    """
    Predictor encapsulates the machine learning model.
    Initially, we use a RandomForestClassifier to learn which combination forming method yields the best outcome.
    The model learns from historical features and the associated outcome (e.g., whether the predicted
    combination eventually led to a hit).
    """
    def __init__(self):
        self.model = RandomForestClassifier(n_estimators=100, random_state=42)
        self.features = ["digit_sum", "length", "final_score", "stable_structure", "consensus",
                         "hot_zone", "cross_draw", "digit_reduction", "vtrac_equiv", "three_digit_repeat"]

    def train(self, historical_data: list, outcomes: list):
        """
        Train the ML model using historical_data and known outcomes.
        historical_data: list of pattern item dicts.
        outcomes: list of binary labels (1 for hit, 0 for miss).
        """
        X = build_feature_matrix(historical_data)
        y = outcomes
        self.model.fit(X[self.features], y)

    def predict(self, pattern_item: dict) -> float:
        """
        Predict the probability that the given pattern (and its chosen combination method) will lead to a hit.
        Returns the probability (between 0 and 1).
        """
        X_new = pd.DataFrame([build_feature_vector(pattern_item)])
        proba = self.model.predict_proba(X_new[self.features])[0][1]
        return proba

class TimeframeAnalyzer:

        return self.average_interval() <= (1 / target_ratio)

def run_ml_pipeline(historical_patterns: list, outcomes: list, new_patterns: list) -> List[Dict[str, Any]]:
    """

    for new patterns.
    
    historical_patterns: list of pattern items (dicts) from previous draws.
    outcomes: corresponding list of outcomes (1 for hit, 0 for miss).

    Returns a list of dicts with each new pattern and its predicted success probability.
    """

    X = build_feature_matrix(historical_patterns)
    y = outcomes
    predictor.model.fit(X[predictor.features], y)
    
    # Predict for new patterns
    predictions = []

"""
advanced_pattern_extractor.py

This module focuses on 3-value patterns (3–5 length, ≤3 unique digits) but includes:
 - Straight vs. Boxed "horizontal" checks (permutation-based).
 - Vertical stability scoring.
 - Consensus detection.
 - Optionally a 'digit shifting' step to handle "hidden behind one digit" (like removing 1 digit from 4-digit substring if that yields a stable 3-digit pattern).

All advanced scoring is done here, but you can simplify if you want a smaller extractor.
"""

import itertools
from collections import defaultdict

###########################################
# Configuration Flags
###########################################
ENABLE_DIGIT_SHIFTING = True   # If True, we'll try removing 1 digit from 4-length patterns to see if that yields a stable 3-digit pattern.

###########################################
# 1. Utility Functions
###########################################

def is_3_value_pattern(cluster: str) -> bool:
    """
    A valid 3-value pattern has length 3-5 and ≤3 unique digits.
    """
    unique_digits = set(cluster)
    if len(cluster) < 3 or len(cluster) > 5:
        return False
    return len(unique_digits) <= 3

def extract_3_value_substrings(string: str):
    """
    Extract all distinct substrings of length 3-5 with ≤3 unique digits.
    Also, if ENABLE_DIGIT_SHIFTING is True, we try removing one digit from
    any 4-digit substring if that helps find a 3-digit stable pattern.
    """
    found = set()
    n = len(string)
    for start_idx in range(n):
        # normal 3-5 length
        for end_idx in range(start_idx+3, min(start_idx+6, n+1)):
            substr = string[start_idx:end_idx]
            if is_3_value_pattern(substr):
                found.add(substr)

            # optional digit shifting
            if ENABLE_DIGIT_SHIFTING and len(substr) == 4:
                # try removing each digit from the 4-length substring
                # to see if that yields a 3-digit stable pattern
                for remove_i in range(4):
                    candidate = substr[:remove_i] + substr[remove_i+1:]
                    if is_3_value_pattern(candidate):
                        found.add(candidate)

    return sorted(found)

def is_permutation_same_order(p1: str, p2: str) -> bool:
    """
    Returns True if p1 == p2 (exact same string => 'straight' match).
    """
    return p1 == p2

def is_permutation_boxed(p1: str, p2: str) -> bool:
    """
    Returns True if p1 and p2 have the same digits in a different order (≥3 length).
    For example, '613' and '361' => True (boxed).
    If p1 == p2, that is a 'straight' match, not a 'boxed' match.
    """
    if len(p1) != len(p2):
        return False
    if p1 == p2:
        return False  # exact same => 'straight'
    return sorted(p1) == sorted(p2)

###########################################
# 2. Vertical & Consensus Checks
###########################################

def vertical_stable_structure_score(r2: str, r4: str, r6: str, r8: str) -> int:
    """
    Overlapping digits in the final 3 chars => basic vertical stability.
    """
    short_r2 = r2[-3:] if len(r2) >= 3 else r2
    short_r4 = r4[-3:] if len(r4) >= 3 else r4
    short_r6 = r6[-3:] if len(r6) >= 3 else r6
    short_r8 = r8[-3:] if len(r8) >= 3 else r8

    common = set(short_r2) & set(short_r4) & set(short_r6) & set(short_r8)
    return len(common)

def detect_consensus_pattern(*rows: str):
    """
    If the last row is all one digit => (True, digit). else (False, None)
    """
    target = rows[-1]
    if target and len(set(target)) == 1:
        return True, target[0]
    return False, None

###########################################
# 3. Horizontal Checking for Straight/Boxed
###########################################

def analyze_horizontal_permutations(strings_in_row: list):
    """
    For each column i, compare to column i+1:
      - if same substring => 'straight' match
      - if permutation => 'boxed' match
    We'll store these matches in a structure.

    We'll do a dictionary: col_index -> list of { 'pattern': p, 'straight_match_next': True/False, 'boxed_match_next': True/False }
    Then we can convert that into a score increment later.
    """
    # We'll store for each col i => a set of patterns
    col_patterns_map = []
    for s in strings_in_row:
        # extract all 3-value substrings
        # we won't store them with advanced detail here; just the raw patterns
        patterns = extract_3_value_substrings(s)
        col_patterns_map.append(set(patterns))

    # Now compare col i's patterns with col i+1
    result = []
    for i in range(len(strings_in_row)):
        result.append({})  # a dictionary of pattern => some info

    for i in range(len(strings_in_row) - 1):
        col_i = col_patterns_map[i]
        col_next = col_patterns_map[i+1]
        # for each pattern in col_i, check if it or a permutation is in col_next
        for p in col_i:
            if p not in result[i]:
                result[i][p] = {"straight_match_next": False, "boxed_match_next": False}

            # check if the exact same pattern is in col_next => straight
            if p in col_next:
                result[i][p]["straight_match_next"] = True
            else:
                # check if there's a permutation match
                # we do a quick pass
                for p2 in col_next:
                    if is_permutation_boxed(p, p2):
                        result[i][p]["boxed_match_next"] = True
                        break

    return result  # result[i] is a dict: pattern => { 'straight_match_next': bool, 'boxed_match_next': bool }

# 4. The Main Extraction Function
###########################################

def extract_patterns_r2r4r6r8(all_data: list) -> list:
    """
    For each Set/Draw:
      - gather final columns for vertical stability
      - check consensus
      - do horizontal permutation analysis for R2, R4, R6, R8
      - extract patterns from each row/col
      - compute final "extractor_score" based on:
         * length-based base score
         * double/triple digits
         * vertical or horizontal stability
         * straight vs. boxed matches across columns

    Returns a list of dicts, each summarizing the patterns for that Set/Draw.
    """
    results = []

    for entry in all_data:
        set_label = entry.get("set", "")
        draw_label = entry.get("draw", "")
        r2_cols = entry.get("R2", [])
        r4_cols = entry.get("R4", [])
        r6_cols = entry.get("R6", [])
        r8_cols = entry.get("R8", [])

        # 1) vertical stability
        final_r2 = r2_cols[-1] if r2_cols else ""
        final_r4 = r4_cols[-1] if r4_cols else ""
        final_r6 = r6_cols[-1] if r6_cols else ""
        final_r8 = r8_cols[-1] if r8_cols else ""

        vertical_score = vertical_stable_structure_score(final_r2, final_r4, final_r6, final_r8)

        # 2) consensus
        consensus_found, consensus_digit = detect_consensus_pattern(final_r2, final_r4, final_r6, final_r8)

        # 3) horizontal permutation analysis => for each row
        r2_perm_info = analyze_horizontal_permutations(r2_cols)
        r4_perm_info = analyze_horizontal_permutations(r4_cols)
        r6_perm_info = analyze_horizontal_permutations(r6_cols)
        r8_perm_info = analyze_horizontal_permutations(r8_cols)

        # 4) We'll store extracted patterns with a detailed scoring
        extracted_patterns = []

        # a helper function to unify scoring
        def score_pattern(p: str, row_type: str, col_index: int, perm_info):
            sc = 0
            # length base
            if len(p) == 3:
                sc += 2
            elif len(p) == 4:
                sc += 3
            elif len(p) == 5:
                sc += 4
            # double/triple check
            unique_d = set(p)
            if len(unique_d) == 2:
                sc += 1
            elif len(unique_d) == 1:
                sc += 2

            # if there's a next col => see if we have straight or boxed
            # (the perm_info for col_index might exist if col_index < len(perm_info)-1)
            if col_index < len(perm_info) - 1:
                col_dict = perm_info[col_index]
                if p in col_dict:
                    if col_dict[p]["straight_match_next"]:
                        sc += 2  # reward for "straight" match in next col
                    elif col_dict[p]["boxed_match_next"]:
                        sc += 1  # reward for "boxed" match in next col

            return sc

        # unify row logic
        for (row_type, columns, perm_info) in [
            ("R2", r2_cols, r2_perm_info),
            ("R4", r4_cols, r4_perm_info),
            ("R6", r6_cols, r6_perm_info),
            ("R8", r8_cols, r8_perm_info),
        ]:
            for col_idx, col_str in enumerate(columns):
                if not col_str:
                    continue
                patterns = extract_3_value_substrings(col_str)
                for p in patterns:
                    sc = score_pattern(p, row_type, col_idx, perm_info)
                    extracted_patterns.append({
                        "pattern": p,
                        "row_type": row_type,
                        "col_index": col_idx,
                        "base_score": sc
                    })

        # We can add a small "global" vertical stability bonus
        # e.g. if vertical_score > 0, add +vertical_score to each pattern or to the final structure
        # Here, let's do it on each pattern as a minor boost
        for pat in extracted_patterns:
            pat["extractor_score"] = pat["base_score"] + vertical_score * 0.5
            # if there's consensus, add +2 to everything
            if consensus_found:
                pat["extractor_score"] += 2

        # collect final
        results.append({
            "set": set_label,
            "draw": draw_label,
            "vertical_stability_score": vertical_score,
            "consensus": consensus_found,
            "consensus_digit": consensus_digit if consensus_found else None,
            # not storing horizontal repeats directly; we do that via 'straight'/'boxed' logic
            "extracted_patterns": extracted_patterns
        })

    return results

def is_3_value_pattern(cluster: str) -> bool:
    """
    A valid 3-value pattern: length 3-5, <=3 unique digits.
    """
    unique_digits = set(cluster)
    if len(cluster) < 3 or len(cluster) > 5:
        return False
    return len(unique_digits) <= 3

def extract_3_value_substrings(string: str):
    """
    Extract substrings (length 3-5, <=3 unique digits).
    Optionally do digit shifting for 4-digit substrings.
    """
    found = set()
    n = len(string)
    for start_idx in range(n):
        for end_idx in range(start_idx+3, min(start_idx+6, n+1)):
            substr = string[start_idx:end_idx]
            if is_3_value_pattern(substr):
                found.add(substr)

            if ENABLE_DIGIT_SHIFTING and len(substr) == 4:
                # remove 1 digit at a time
                for remove_i in range(4):
                    candidate = substr[:remove_i] + substr[remove_i+1:]
                    if is_3_value_pattern(candidate):
                        found.add(candidate)
    return sorted(found)

def is_straight_match(p1: str, p2: str) -> bool:
    """ True if p1 == p2 (exact same order). """
    return (p1 == p2)

def is_boxed_match(p1: str, p2: str) -> bool:
    """ True if sorted(p1) == sorted(p2) but p1 != p2. """
    if len(p1) != len(p2):
        return False
    if p1 == p2:
        return False
    return sorted(p1) == sorted(p2)

def horizontal_analysis(row_of_strings: list):
    """
    row_of_strings: e.g. R2 columns [col0, col1, col2,...].
    We'll extract patterns in each col, then see if p in col i also appears in col i+1
    as "straight" or "boxed".

    Return a structure: 
       result[i][p] = {"straight_next": bool, "boxed_next": bool}

    So that we can reference it in the final scoring.
    """
    col_patterns = []
    for s in row_of_strings:
        if not s:
            col_patterns.append(set())
            continue
        col_patterns.append(set(extract_3_value_substrings(s)))

    result = []
    for i in range(len(row_of_strings)):
        result.append({})  # dictionary pattern-> match info

    for i in range(len(row_of_strings) - 1):
        this_col = col_patterns[i]
        next_col = col_patterns[i+1]
        for p in this_col:
            result[i][p] = {"straight_next": False, "boxed_next": False}
            if p in next_col:
                # same order
                result[i][p]["straight_next"] = True
            else:
                # check for box
                for p2 in next_col:
                    if is_boxed_match(p, p2):
                        result[i][p]["boxed_next"] = True
                        break
    return result

def vertical_analysis(r2_col, r4_col, r6_col, r8_col):
    """
    For a single column index j, we have 4 strings (one from R2, R4, R6, R8).
    We'll find patterns in each row's string, then see if a pattern from R2 also appears in R4, R6, R8 as straight or box, etc.

    Return a dict:
      { pattern -> { "straight_in_R4": bool, "boxed_in_R4": bool, "straight_in_R6":..., "boxed_in_R6":..., ... } }
    Then the scoring function can interpret that.

    We only do vertical checks among these 4 rows (R2->R4->R6->R8).
    """
    # extract sets of patterns
    pat_r2 = set(extract_3_value_substrings(r2_col)) if r2_col else set()
    pat_r4 = set(extract_3_value_substrings(r4_col)) if r4_col else set()
    pat_r6 = set(extract_3_value_substrings(r6_col)) if r6_col else set()
    pat_r8 = set(extract_3_value_substrings(r8_col)) if r8_col else set()

    result = defaultdict(lambda: {
        "straight_in_R4": False, "boxed_in_R4": False,
        "straight_in_R6": False, "boxed_in_R6": False,
        "straight_in_R8": False, "boxed_in_R8": False
    })

    # check R2 -> R4
    for p in pat_r2:
        if p in pat_r4:
            result[p]["straight_in_R4"] = True
        else:
            # check box
            for p4 in pat_r4:
                if is_boxed_match(p, p4):
                    result[p]["boxed_in_R4"] = True
                    break
    # check R2 -> R6
    for p in pat_r2:
        if p in pat_r6:
            result[p]["straight_in_R6"] = True
        else:
            for p6 in pat_r6:
                if is_boxed_match(p, p6):
                    result[p]["boxed_in_R6"] = True
                    break
    # check R2 -> R8
    for p in pat_r2:
        if p in pat_r8:
            result[p]["straight_in_R8"] = True
        else:
            for p8 in pat_r8:
                if is_boxed_match(p, p8):
                    result[p]["boxed_in_R8"] = True
                    break

    # You could also do R4->R6->R8 or R4->R6, etc., but let's keep it simpler for now.
    # We mostly see if R2's patterns appear in R4, R6, R8 in straight or box.

    return dict(result)

def end_of_string_3digit_check(string_list):
    """
    For each col i, see if last 3 digits of col i appear in col i+1.
    Return a structure that says for col i: the 3-digit substring => True if repeated in next col.
    """
    result = []
    for i in range(len(string_list)):
        result.append({})
    for i in range(len(string_list) - 1):
        s = string_list[i]
        nxt = string_list[i+1]
        if not s or not nxt:
            continue
        # last 3 digits
        last3 = s[-3:] if len(s) >= 3 else s
        # see if last3 in nxt
        # we can do a direct substring check or see if it is the end of nxt
        if last3 and last3 in nxt:
            result[i][last3] = True
    return result

def check_consensus_in_final_column(r2_cols, r4_cols, r6_cols, r8_cols):
    """
    If the final column of R2, R4, R6, R8 is all a single repeated digit => True, digit.
    Example: R2[-1] = '4', R4[-1] = '4', R6[-1] = '4', R8[-1] = '4' => (True, '4')
    """
    if not (r2_cols and r4_cols and r6_cols and r8_cols):
        return (False, None)
    c2 = r2_cols[-1]
    c4 = r4_cols[-1]
    c6 = r6_cols[-1]
    c8 = r8_cols[-1]
    if len(c2) == 0 or len(c4) == 0 or len(c6) == 0 or len(c8) == 0:
        return (False, None)
    # check if c2, c4, c6, c8 are each a single repeated digit AND that digit is the same across all 4
    # We'll define "consensus" as each final column is a single repeated digit of length >= 1, and that digit matches across rows
    # or you can define it differently if you want
    # We'll just check if each final column is exactly one repeated digit and see if they're all the same digit
    def single_repeated_digit(s):
        return len(s) > 0 and len(set(s)) == 1
    if single_repeated_digit(c2) and single_repeated_digit(c4) and single_repeated_digit(c6) and single_repeated_digit(c8):
        d2 = c2[0]
        d4 = c4[0]
        d6 = c6[0]
        d8 = c8[0]
        if d2 == d4 == d6 == d8:
            return (True, d2)
    return (False, None)

def extract_patterns_r2r4r6r8(all_data: list) -> list:
    """
    For each set/draw:
      1) do horizontal analysis for R2, R4, R6, R8
      2) do vertical analysis for each column j
      3) do end-of-string 3-digit repeat if enabled
      4) do final consensus check
      5) unify patterns and compute final 'extractor_score'
    """
    results = []

    for entry in all_data:
        set_label = entry.get("set", "")
        draw_label = entry.get("draw", "")
        r2_cols = entry.get("R2", [])
        r4_cols = entry.get("R4", [])
        r6_cols = entry.get("R6", [])
        r8_cols = entry.get("R8", [])

        # 1) horizontal analysis
        r2_horiz = horizontal_analysis(r2_cols)
        r4_horiz = horizontal_analysis(r4_cols)
        r6_horiz = horizontal_analysis(r6_cols)
        r8_horiz = horizontal_analysis(r8_cols)

        # 2) vertical analysis: for each column j
        # We'll store vertical info in vertical_info[j] => pattern => ...
        vertical_info = []
        max_cols = max(len(r2_cols), len(r4_cols), len(r6_cols), len(r8_cols))
        for j in range(max_cols):
            c2 = r2_cols[j] if j < len(r2_cols) else ""
            c4 = r4_cols[j] if j < len(r4_cols) else ""
            c6 = r6_cols[j] if j < len(r6_cols) else ""
            c8 = r8_cols[j] if j < len(r8_cols) else ""
            vdict = vertical_analysis(c2, c4, c6, c8)
            vertical_info.append(vdict)

        # 3) end-of-string 3-digit repeat
        r2_end3 = end_of_string_3digit_check(r2_cols) if ENABLE_END_OF_STRING_3DIGIT else []
        r4_end3 = end_of_string_3digit_check(r4_cols) if ENABLE_END_OF_STRING_3DIGIT else []
        r6_end3 = end_of_string_3digit_check(r6_cols) if ENABLE_END_OF_STRING_3DIGIT else []
        r8_end3 = end_of_string_3digit_check(r8_cols) if ENABLE_END_OF_STRING_3DIGIT else []

        # 4) consensus
        consensus_found, consensus_digit = check_consensus_in_final_column(r2_cols, r4_cols, r6_cols, r8_cols)

        # We'll gather all patterns from each row/col again, but now we will incorporate horizontal & vertical info
        extracted_patterns = []

        def score_pattern(p: str, row_type: str, col_index: int):
            sc = 0
            # base on length
            L = len(p)
            if L == 3: sc += 2
            elif L == 4: sc += 3
            elif L == 5: sc += 4

            # double/triple check
            unique_d = set(p)
            if len(unique_d) == 2: sc += 1
            elif len(unique_d) == 1: sc += 2

            # horizontal info
            if row_type == "R2":
                col_map = r2_horiz
                end3_map = r2_end3
            elif row_type == "R4":
                col_map = r4_horiz
                end3_map = r4_end3
            elif row_type == "R6":
                col_map = r6_horiz
                end3_map = r6_end3
            else:
                col_map = r8_horiz
                end3_map = r8_end3

            if col_index < len(col_map):
                if p in col_map[col_index]:
                    if col_map[col_index][p]["straight_next"]:
                        sc += 2
                    elif col_map[col_index][p]["boxed_next"]:
                        sc += 1

            # end-of-string check
            if ENABLE_END_OF_STRING_3DIGIT and col_index < len(end3_map):
                if p in end3_map[col_index]:
                    # e.g. +2
                    sc += 2

            # vertical info => vertical_info[col_index][p]
            if col_index < len(vertical_info):
                vdict = vertical_info[col_index]
                if p in vdict:
                    # check R4
                    if vdict[p]["straight_in_R4"]:
                        if row_type == "R2":
                            sc += 2  # or some weighting
                    elif vdict[p]["boxed_in_R4"]:
                        if row_type == "R2":
                            sc += 1
                    # check R6
                    if vdict[p]["straight_in_R6"]:
                        if row_type == "R2":
                            sc += 2
                    elif vdict[p]["boxed_in_R6"]:
                        if row_type == "R2":
                            sc += 1
                    # check R8
                    if vdict[p]["straight_in_R8"]:
                        if row_type == "R2":
                            sc += 2
                    elif vdict[p]["boxed_in_R8"]:
                        if row_type == "R2":
                            sc += 1
                    # If row_type is R4 or R6 or R8, you might do more advanced logic 
                    # like if p also found in R2, that might be a partial match, etc.
                    # This code just uses R2 as baseline, but you can expand it.

            # If we have a consensus, add e.g. +2
            if consensus_found:
                sc += 2

            return sc

        # gather patterns
        for (row_type, columns) in [("R2", r2_cols), ("R4", r4_cols), ("R6", r6_cols), ("R8", r8_cols)]:
            for cidx, col_str in enumerate(columns):
                if not col_str:
                    continue
                patterns = extract_3_value_substrings(col_str)
                for pat in patterns:
                    sc = score_pattern(pat, row_type, cidx)
                    extracted_patterns.append({
                        "pattern": pat,
                        "row_type": row_type,
                        "col_index": cidx,
                        "extractor_score": sc
                    })

        results.append({
            "set": set_label,
            "draw": draw_label,
            "consensus_found": consensus_found,
            "consensus_digit": consensus_digit if consensus_found else None,
            "patterns": extracted_patterns
        })

    return results

    """
    Return True if s is either a single repeated digit (e.g. '4','777')

def check_consensus_in_final_column(r2_cols, r4_cols, r6_cols, r8_cols):
    """
    If the final column of R2, R4, R6, R8 is a repeated digit string,
    and they are all the same repeated digit string across rows,
    we return (True, digit_str, type) 
      where type in {"single","double"} or something else.
    """
    if not (r2_cols and r4_cols and r6_cols and r8_cols):
        return (False, None, None)

    c2 = r2_cols[-1]
    c4 = r4_cols[-1]
    c6 = r6_cols[-1]
    c8 = r8_cols[-1]
    # must be all repeated digit strings, same digit
    # We'll reuse single_or_double_digit, but that only checks "all same digit"
    # doesn't differentiate length. Let's do a small approach:
    def all_same_digit_string(x: str) -> bool:
        return len(x) > 0 and len(set(x)) == 1

    if all_same_digit_string(c2) and all_same_digit_string(c4) and all_same_digit_string(c6) and all_same_digit_string(c8):
        # check if they are the same digit repeated
        if c2 == c4 == c6 == c8:
            # define type
            L = len(c2)
            if L == 1:
                ctype = "single"
            else:
                ctype = "double"  # or "multi" if length>2
            return (True, c2, ctype)

    return (False, None, None)
Now if the final column is e.g. “44” for R2, R4, R6, R8, we get (True, "44","double").

def detect_vertical_multi_straight(r2_col, r4_col, r6_col, r8_col):
    """
    Return a set of patterns p that appear EXACTly in R2, R4, R6, and R8 
    for the same column (straight match).
    We'll gather 3-value substrings from each row, then do intersection
    but only if the substring is the same order in each row. 
    """
    pat_r2 = set(extract_3_value_substrings(r2_col)) if r2_col else set()
    pat_r4 = set(extract_3_value_substrings(r4_col)) if r4_col else set()
    pat_r6 = set(extract_3_value_substrings(r6_col)) if r6_col else set()
    pat_r8 = set(extract_3_value_substrings(r8_col)) if r8_col else set()

    # We can do a direct intersection:
    common = pat_r2 & pat_r4 & pat_r6 & pat_r8
    return common

1) Making the Extractor More Dynamic for AI
Right now, the extractor logic is mostly hard-coded scoring (e.g., score += 2 if it’s 3 digits, score += 3 if vertical multi-straight, etc.). If you want an AI/ML system to learn and adjust these rules on its own, you generally do two things:

A. Store Each “Condition” or “Feature” Separately Instead of Summing Into One Score
Instead of computing a single integer score, you store each relevant condition as a boolean or numeric feature. For example:

feature_length3 = 1 if pattern length = 3, else 0
feature_length4 = 1 if pattern length = 4, else 0
feature_double_digits = 1 if pattern has exactly 2 unique digits, else 0
feature_consensus_found = 1 if final column is a repeated digit, else 0
feature_vertical_multistraight = 1 if pattern appears in R2/R4/R6/R8 for the same column, else 0
feature_horizontal_boxed_next = 1 if it appears in the next column in a different order, else 0
feature_horizontal_straight_next = 1 if it appears in the next column in the same order, else 0
etc.
Then your extractor might produce an output for each pattern that looks like:

python
Copy
{
  "pattern": "0067",
  "row_type": "R2",
  "col_index": 4,
  "length": 4,
  "num_unique_digits": 2,
  "vertical_multistraight": 1,
  "consensus_found": 1,
  "consensus_type": "double",
  "horizontal_straight_next": 1,
  "horizontal_boxed_next": 0,
  "end_of_string_3digit": 1,
  ...
}
No final numeric score is assigned here. We’re just storing a set of feature flags/values.

B. Let a Machine Learning Model Learn Weights for Those Features
In your “analysis” or “scoring” step, you feed these feature vectors to a model (like a random forest or logistic regression) that outputs a predicted “confidence” or “likelihood” that this pattern leads to a hit. Then the model learns that vertical_multistraight=1 might be worth +2.5 in log-odds, or that consensus_found=1 is worth +1.2, etc.

This means you’re no longer manually deciding score += 2; the ML model effectively learns the weighting. Over time, it can re‐train on real outcomes (did this pattern produce a hit or not?), so it adjusts which features are most important.

Implementation Steps
In your Extractor: Instead of (or in addition to) computing score, create a dictionary of feature flags.
In your Analysis: Collect those features into a DataFrame (like pandas). Add a label if you have historical data (e.g. “did it produce a winning number?”).
Train a model that predicts success from those features.
Next time, when new patterns come out, the model’s predict_proba gives a probability of success for each pattern. Then you can rank or filter by that probability.
That is how you can make the extractor truly “dynamic,” letting AI learn how to weigh each rule.

2) Combining Multiple Sets in the Same Table
You also asked: “Why did previous modules add up different set structures within the single table?” and “How do we unify or ‘aggregate’ the patterns from Set1, Set2, Set3 in the combined chart?”

A. Understanding “Set1,” “Set2,” “Set3”
Typically:

Set1 might be your primary current structure (like “the next day’s R2/R4/R6/R8”).
Set2 might be from the day before or an alternate chart.
Set3 might be two days prior or something else.
You want to see if a 3‐value pattern that appears in Set3 also re‐appears in Set2 or Set1. If so, that’s a big “persistence” clue.

B. Two Approaches
Single Pass, Single Data Structure

You have a single “all_data” that has entries for (Set,Draw) = (Set1,Draw1), (Set1,Draw2), (Set2,Draw1), (Set3,Draw1), etc.
The extractor just runs once, returning patterns for each (Set,Draw).
Then your aggregator or “analysis” step cross‐references the patterns. For example, if the same pattern "548" occurs in (Set3,Draw1) and (Set2,Draw1) and (Set1,Draw1), we might add an extra “persist_across_sets=3.”
Multiple Passes, Then Merge

You run the extractor for each set individually. Then you unify the results by comparing patterns across sets.
This is a bit more manual, but sometimes simpler if your code is structured in separate loops.
In both methods, the aggregator step is where you can add a “Set1–Set2–Set3” cross check. For example:

python
Copy
def cross_set_persistence(all_patterns):
    # all_patterns might be a list of dict with fields: { 'pattern':'548', 'set':'Set1','draw':'Draw1', ...}
    # We'll group by 'pattern' and see how many distinct sets it appears in.
    from collections import defaultdict
    pattern_sets = defaultdict(set)
    for pinfo in all_patterns:
        pattern_sets[pinfo['pattern']].add(pinfo['set'])

    # Now we can store something like:
    # if len(pattern_sets['548']) == 3 => it appears in Set1, Set2, Set3
    for pinfo in all_patterns:
        pinfo['persist_across_sets'] = len(pattern_sets[pinfo['pattern']])
Then, if a pattern appears in all 3 sets, persist_across_sets=3. That’s presumably a big clue, so in your final ML features, you’d store feature_persist_across_sets = 3.

3) Clarifying “Multiple Straight Permutations”
Terminology
“Vertical multi‐straight”: The same substring (e.g. “0067”) appears in R2, R4, R6, R8 in the same column with the same order. That’s what we coded in detect_vertical_multi_straight.
“Horizontal straight”: The same substring “0067” appears in column j and column j+1 for the same row R2 in the same order.
“Permutation”: Sometimes we say “boxed version.” If “0067” is in col j, but “0670” is in col j+1, that’s the same digits but different order. That might be a “horizontal box.”
So yes, “multiple straight” means “the exact same substring is repeated in the exact same order.” If you want to see “the same digits in any order,” that’s “boxed repeat.” If you want “the same digits, same order,” that’s “straight repeat.”

Hence we can store features like:

vertical_multi_straight=1 if the exact substring is in R2–R4–R6–R8.
vertical_multi_boxed=1 if the same set of digits is in R2–R4–R6–R8 but possibly in different orders. (We’d do a more advanced check.)

Dynamic approach: turn each rule into a separate feature, letting your analysis or ML decide final weighting.

2. Comparing the Old and New Pattern Extractor Designs
Old Pattern Extractor (Conceptually)
Basic Extraction:
The earlier version of the pattern extractor worked by scanning through the R2/R4/R6/R8 strings to pull out substrings that looked like “3-digit” patterns. It focused on detecting repeated clusters (for example, if the same 3-digit sequence appeared at the end of several rows, that was flagged as a strong candidate).

Direct Scoring:
It would then assign a score based on simple rules (for instance, if the pattern was exactly three digits, if it repeated exactly, etc.). The scoring was more “hard-coded” and less dynamic—meaning it directly added points for conditions like “if the substring repeats in the final column, add 2.”

Combination Generation:
The older design also included routines for generating combinations from the extracted patterns. It was built to handle a few specific scenarios (like if the pattern was a double, or if it was in a particular order). The logic was simpler and produced a set of candidate combinations that were then used in predictions.

New (Enhanced) Pattern Extractor
Richer Feature Extraction:
The new design still extracts 3‑value patterns (which can be 3–5 digits long with up to 3 unique digits) but now also calculates multiple “feature flags” or scores:

Vertical Stability Score:
It looks at the last few digits of R2, R4, R6, and R8 and scores how similar they are.
Consensus Detection:
Instead of only checking for a single repeated digit, it now can detect if the final columns in the structure contain either a single repeating digit (e.g., “4444”) or even double-digit consensus (e.g., “77,77”) that serves as a doubles indicator.
Horizontal Repeat Analysis:
It examines adjacent columns (or “boxes”) to see if the same 3-digit substring appears in multiple columns, giving extra weight if a straight repeat (same order) is found versus a boxed (any order) match.
Permutation Counting:
The module now distinguishes between a stable pattern that holds its order (a “straight permutation”) and one that appears only as a set (boxed). This distinction is important because a pattern that persists in the same order across multiple rows (vertical multi‑straight) is a much stronger indicator.
Feature-Based Output:
Instead of returning just a “score,” the new extractor returns a dictionary for each detected pattern with multiple features (such as length, vertical stability, whether it appears in consensus, etc.). This makes the output far more useful for further processing (by analysis modules or an ML system).
Dynamic and Extensible:
With these additional features, the new extractor isn’t “hard-coded” into one final number. Instead, it produces a set of features that later modules (or an ML model) can use to dynamically determine which patterns are most promising. For example, a pattern that is repeated exactly in R2, R4, R6, and R8 (vertical multi‑straight) could get an extra bonus, and that bonus can be tuned or even learned by the system over time.

Integration with Digit Shifting:
You mentioned the idea of “digit shifting” to reveal hidden patterns (for example, when a 3‑value pattern might be concealed within a 4‑digit string). The enhanced extractor design is open to integrating such functions as an additional feature. For instance, a digit-shift function might try to shift one digit out and see if a stable 3‑value pattern emerges, then add a flag if it does.

Dynamic Scoring:
