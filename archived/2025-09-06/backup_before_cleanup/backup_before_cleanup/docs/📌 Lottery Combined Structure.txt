📌 Lottery Data Structure 
1. Overview of Dataset Organization
The dataset is structured into three main categories, each corresponding to different time-based lottery results:

Midday Table – Contains only midday draw data.
Evening Table – Contains only evening draw data.
Combined Table – Merges both midday and evening data for pattern analysis across time periods.
Each of these categories follows the same internal structure.

2. Core Data Structure
Each dataset consists of three main sets:

Set3 – Contains only Draw1.
Set2 – Contains only Draw1.
Set1 – Contains Draw1 through Draw7.
This hierarchy exists across all datasets, meaning each set has a structured breakdown of data rows.

R2/R4/R6/R8 represent different levels of pattern variation, meaning they contain the same number of digits per box, but arranged differently.
These are not progressively reduced sequences, but instead randomized variations of digit arrangements.
The actual reduction in digits occurs across columns (left to right).
4. Column Mapping
Each row has 10 key columns:

Column	Description
Set	Identifies the dataset (Set1, Set2, Set3)
Draw	Identifies the draw number (Draw1–Draw7)
RowType	Type of row (DRAW_DATA, R2, R4, R6, R8)
7-1	Right-to-left progressive data
Columns 7→1 represent pattern reductions.
Patterns get progressively smaller from left to right.
💡 Key Insight:
A pattern persisting across multiple columns (e.g., 7,6,5,4) is stronger because it maintains its structure through reductions.

🔹 Purpose of the R2 Table
Digit Reduction: The R2 table is used for alternative digit reduction methods to extract hidden pattern structures.
Pattern Pairing: R2 strings are mapped back to the original R2/R4/R6/R8 boxes they come from, allowing the system to pair remaining patterns with stable patterns.
Scoring Integration: The system will score R2 patterns in conjunction with R4/R6/R8 patterns to form stronger predictive models.

This will be crucial for designing a digit reduction module that intelligently pairs reduced patterns with observed patterns in R2/R4/R6/R8.
7. How the R2 Table Integrates with Analysis Tools
The digit reduction module will:

Extract R2 strings from the R2 Table.
Track their origin in the R2/R4/R6/R8 groupings.
Perform reductions on those R2 strings.
Compare reduced outputs to strong stable patterns in the corresponding R2/R4/R6/R8 boxes.
Score and rank viable patterns for predictive analysis.
This ensures maximum coverage of potential pattern variations.
