# Auxiliary Tools Module

This module contains legacy scripts for auxiliary analysis.

- `core_legacy/`: Contains proven Python scripts from the "Working app" that run outside the main integrated application.
- `adapters_old_module/`: Contains experimental code and snippets from the "Old / deleted module".
- `integration.py`: This is the glue layer where new code will be written to adapt and integrate the legacy scripts into the main AAT9 application.
