Three simple ways to use Explorer without spawning a non‑WSL Code
A) “Send to → Open in Code (WSL)” (fast, reliable)

Create a tiny helper so any file/folder you right‑click goes to the WSL Code window.

Open Notepad and paste:

@echo off
setlocal
if "%~1"=="" exit /b
rem Convert the Windows or \\wsl$ path to Linux path
for /f "usebackq delims=" %%L in (`wsl wslpath "%~1"`) do set "LIN=%%L"
rem Reuse the existing WSL Code window and open the file/folder
wsl -d Ubuntu bash -lc "code -r \"%LIN%\""


Save as
%APPDATA%\Microsoft\Windows\SendTo\Open in Code (WSL).bat

Use it: in Explorer, right‑click any file or folder → Send to → Open in Code (WSL).
It reuses your current WSL Code window (or opens one if needed).

B) Right‑click context menu: Open in VS Code (WSL) (one‑time add)

Optional: add a permanent right‑click item for all files/folders.

Make sure you created the SendTo script above.

Create a file OpenInCodeWSL.reg with:

Windows Registry Editor Version 5.00

[HKEY_CLASSES_ROOT\*\shell\Open in VS Code (WSL)]

[HKEY_CLASSES_ROOT\Directory\shell\Open in VS Code (WSL)\command]
