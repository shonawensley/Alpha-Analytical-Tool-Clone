Key point: The scorer/exporter is post‑validator. It reads what you already emit and returns a stable, compact contract for other tools.

The compact report (what other tools should read)
For each (state, section ∈ {Combined, Midday, Evening}) row:


overlap: integer (box token intersection size)


stable_cols_count, stable_cols: column survival (weighted heavier toward 2 and 1)


consensus_col1, consensus_col2: booleans (your real fields; no more “C1/C2” shorthand)


cross_section_echo: integer (# of winners‑side tokens that appear in other sections)


hot_count, superhot_count: counts (normalized internally to 8/12 gates)


mask_drop, mirror_supported, double_hits: analyzer metrics


confidence_score: final section score (after gates, priors, and rescue multiplier)


tier: A, B+, B, C, or Z (Z appears only when rescued)


flags: includes weak_positive_rescue and/or zero_overlap where applicable


top_tokens[]: winners‑side token signatures


recommended_tokens[]: same tokens, lightly re‑ordered with the ledger bumps


top_straights[]: tie‑break info only (not a demoter in scoring)


source: file origin for auditability


👉 What’s missing for “final”? A state‑level merge that yields Top‑3 indices (normalized across sections) so an aggregator doesn’t need to recompute it. See “Finish line” below.

Code‑review: strengths, gaps, and surgical tweaks
What’s strong (keep)


Separation of concerns: Analyzer unchanged; scoring/export is a post step.


Gating logic: Overlap-first; stability required for consensus credit; Combined prior applied once (avoids double‑counting).


Rescue design: Zero‑overlap sections never dominate (0.35× cap), but still surface for audit.


Cross‑section echo: Correctly computed from per‑section token sets.


Token ledger: Global repetition (≥3 states) + local multi‑section repetition → small, explainable bumps.


Normalizations: Mask and doubles normalized over the local min/max range; mirror treated as a boolean.


Gaps / risks (recommended fixes)


State‑level picks not emitted yet.
Add a lightweight merge to output top_indices_by_state so downstream code doesn’t have to recompute section blending.


Rule (start simple): index score = max(score_Combined, score_Midday, score_Evening) with tie broken by:


higher overlap, 2) deeper right‑column stability, 3) more cross‑section echo.




Emit top‑3 indices with an explain string (section+features that won the tie).




Deterministic ordering for equals.
Where scores tie (e.g., recommended token weights), add a secondary sort by token string so outputs are reproducible.


Per‑state priors (optional, small).
