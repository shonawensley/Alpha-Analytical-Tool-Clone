C) V‑TRAC straight definition (what to detect)

Given the winner (e.g., 894), compute its V‑TRAC class triple (e.g., 3 4 4 conceptually; exact mapping comes from modules.vtrac_reference).
A V‑TRAC straight in the 4‑digit strings is an AABB or BBAA run where A and B are the two distinct V‑TRAC digits from the winner’s class triple.

Strict: contiguous runs: A{2,}B{2,} or B{2,}A{2,} (examples you circled like 3344).

Value‑blocked (dashed): allow exactly one intervening run (≥2 of the same foreign digit) between the two pair‑runs:

A{2,}[c]{2,}B{2,} or B{2,}[c]{2,}A{2,}, where c ∉ {A,B} and the middle group is one run (e.g., 336644 → 33 + 66 + 44).

Why this shape? The strings in R2/R4/R6/R8 are made of runs of the same digit. Treating “value‑blocked” as one foreign run between the two required pair‑runs matches your “remove the double gap digit” intuition and avoids over‑matching.

Implementation tip (robust and simple):
Work on run‑length encoded cells (list of (digit, length)):

def rle(s: str):
    out = []
    last = None; k = 0
    for ch in s:
        if ch == last: k += 1
        else:
            if last is not None: out.append((last, k))
            last = ch; k = 1
    if last is not None: out.append((last, k))
    return out


Strict VT‑straight hit if any consecutive pair in RLE equals (A, ≥2), (B, ≥2) or (B, ≥2), (A, ≥2).

Value‑blocked VT‑straight if any triple equals (A, ≥2), (c, ≥2), (B, ≥2) with c∉{A,B}, or the symmetric case.
