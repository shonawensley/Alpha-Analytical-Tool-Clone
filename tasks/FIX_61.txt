✅ Pivots (add these into pivot.py)

All pivots should return dicts/Series keyed by the same item identity you already use (state, area, section, set, draw, col, method, mode). You can compute them with a DataFrame over the per‑item records for the same state.

Cross‑section (Midday / Evening / Combined) consensus

sec.consensus_any: any agreement on final.value across the 3 sections for the same (area,set,draw,col,method,mode).

sec.consensus_strong: ≥2 sections agree.

sec.pairwise_jaccard: mean Jaccard over the 3 pairs (treat finals as sets of digits).

Own ↔ Combined (per method/location)

mode.agree_core: final.value same between mode="own" and mode="combined".

mode.time_to3_delta_abs: abs(time_to_3_own - time_to_3_combined).

mode.len_delta_abs: abs(terminal_len_own - terminal_len_combined).

Across methods (A–E,T) for a location/mode

methods.core_agreement: count of methods sharing the same final.value.

method.agree_flag: 1 if ≥ thresholds.method_agree_k, else 0.

method.agree_count: the raw count.

Set memory / carry (Set3→2→1, same area/section/draw/col/method/mode)

set.memory_strength: 1 if the Set2/Set1 final appears in Set3 chain, else 0.

set.repeat_new_box: 1 if a new set repeats a previous set’s final in this location.

set.linger: boolean or small count for consecutive sets keeping same final.

Cross‑column agreement

For LS1 use cols 7/6/5; for LS2 use 3/1.

xcol.agree_count: number of other columns in the same area/section/set/draw/method/mode with the same final.

Stability/permutation (per item)

stability.order_cue: reuse your Part‑1 tail order signal.

stability.horiz_persist: fraction of tail steps repeating the same final.

perm.density: keep your normalized 0..1 proxy from Part‑1.

These names match what your score_3.py already expects, so the scorer can be a pure sum of weighted features + penalties.

from typing import Dict, Any

def score_row(r: Dict[str, Any],
              W: Dict[str, float],
              P: Dict[str, float],
              C: Dict[str, float]) -> float:
    s = 0.0

    # tails / terminal quality
    s += W.get("tail.exact_len3",0.0)       * float(r.get("tail.exact_len3",0))
    s += W.get("tail.unique2",0.0)          * float(r.get("tail.unique2",0))
    s += W.get("tail.final_len_is1",0.0)    * float(r.get("final.len_is1",0))
    s += W.get("tail.final_len_is2",0.0)    * float(r.get("final.len_is2",0))
    s += W.get("tail.final_len_is3",0.0)    * float(r.get("final.len_is3",0))

    # trajectory
    s += W.get("traj.early_terminal",0.0)   * float(r.get("traj.early_terminal",0))
    s += W.get("traj.reduction_slope",0.0)  * float(r.get("traj.reduction_slope",0.0))

    # pre-reduction
    s += W.get("pre.mirror_pair",0.0)       * float(r.get("pre.mirror_pair",0))
    s += W.get("pre.core3_hint",0.0)        * float(r.get("pre.core3_hint",0))

    # cross-section
    s += W.get("sec.consensus_any",0.0)     * float(r.get("sec.consensus_any",0))
    s += W.get("sec.consensus_strong",0.0)  * float(r.get("sec.consensus_strong",0))
    s += W.get("sec.pairwise_jaccard",0.0)  * float(r.get("sec.pairwise_jaccard",0.0))

    # own vs combined
    s += W.get("mode.agree_core",0.0)       * float(r.get("mode.agree_core",0))
    s += W.get("mode.time_to3_delta_abs",0) * float(r.get("mode.time_to3_delta_abs",0))
    s += W.get("mode.len_delta_abs",0)      * float(r.get("mode.len_delta_abs",0))

    # across methods / sets / columns
    s += W.get("methods.core_agreement",0.0)* float(r.get("methods.core_agreement",0.0))
    s += W.get("methods.early_fraction",0.0)* float(r.get("methods.early_fraction",0.0))
    s += W.get("method.agree_flag",0.0)     * float(r.get("method.agree_flag",0))
    s += W.get("method.agree_count",0.0)    * float(r.get("method.agree_count",0))
    s += W.get("set.memory_strength",0.0)   * float(r.get("set.memory_strength",0.0))
    s += W.get("set.repeat_new_box",0.0)    * float(r.get("set.repeat_new_box",0))
    s += W.get("xcol.agree_count",0.0)      * float(r.get("xcol.agree_count",0))

    # stability / perms
    s += W.get("stability.order_cue",0.0)   * float(r.get("stability.order_cue",0.0))
    s += W.get("stability.horiz_persist",0.0)* float(r.get("stability.horiz_persist",0.0))
    s += W.get("perm.density",0.0)          * float(r.get("perm.density",0.0))
    s += W.get("stability.survival_frac3",0.0)* float(r.get("stability.survival_frac3",0.0))

    # penalties
    s += P.get("degenerate.empty",0.0)      * (1.0 if r.get("final.value","")=="" else 0.0)
    s += P.get("pen.tail_wobble",0.0)       * float(r.get("pen.tail_wobble",0.0))
    s += P.get("mode.only_one",0.0)         * float(r.get("mode.only_one",0.0))

    # optional V‑TRAC synergy (internal mapping only)
    s += W.get("vtrac.hot_index",0.0)       * float(r.get("v_hot",0))

    lo = C.get("score_min",0.0); hi = C.get("score_max",100.0)
    return max(lo, min(hi, s*10.0))  # scale ~0..100
