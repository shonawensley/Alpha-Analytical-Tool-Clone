Your architecture doc still says Aux/BA read data/cleaned/*_draws.csv (top‑level, no /draws subfolder). In practice, your app and pipeline now place them in data/cleaned/draws/…. That mismatch is the root of the “no files” banner.

A small scoping bug is killing Aux before it renders.
The “Rescue boot path active. main() did not render. main() raised: cannot access local variable PAIRS_WINDOW…” message is a textbook Python UnboundLocalError: somewhere in the Aux page code a function references PAIRS_WINDOW before assigning to a local with the same name. That crash happens before any data load, so it cascades into “no files” UI and the V‑TRAC box table not rendering.

The “all blue doubles / no reds” was a side‑effect.
When the page crashes before binding the long window, the code falls back to the short window, so the ≥1000‑draw tier never gets populated. Everything then skews blue. (Your validation logs do show reds once the long window exists—so math is fine; the UI kept crashing first.)

Python path is normal.
Seeing python: C:\Users\User\AppData\Local\Programs\Python\Python313\python.exe in Dev Health is expected. That’s just the interpreter location, not a project path. Not a problem.

Staged vs canonical imports added fragility.
The wrapper that tries to load staged Aux modules (scripts/auxiliary/working/...) is brittle. When those files aren’t present (or their relative imports change), the wrapper path fails, and Aux enters the “Rescue boot” branch. We can remove this fragility by vendoring the final Aux modules into modules/ and always importing those canonically.

Side note (for BA): BA’s own doc says it loads draws via a robust loader and should never touch string tables—so once the draws path is fixed, BA’s panel is fine.

2) Harden the draws loader (tolerant resolution + clear errors)

modules/aux_loaders.py — make the loader tolerant and explicit:

from pathlib import Path
import csv
from utils.path_handler import get_cleaned_draws_dir

def _aliases(state: str):
    # "Connecticut4" → ["Connecticut4","Connecticut"]
    base = state.rstrip("4")
    # normalize separators; add a compact alias (optional)
    norm = base.replace(" ", "_").replace("-", "_")
    return [norm, base]

def resolve_draw_csv(state: str, variant: str | None) -> Path | None:
    draws_dir = get_cleaned_draws_dir()
    candidates: list[Path] = []
    for s in _aliases(state):
        if variant and variant.lower() in ("midday", "evening"):
            candidates.append(draws_dir / f"{s}_{variant.capitalize()}_draws.csv")
        candidates.append(draws_dir / f"{s}_draws.csv")

    # final fallback: legacy top‑level (older layout)
    legacy = Path("data/cleaned")
    for s in _aliases(state):
        if variant and variant.lower() in ("midday", "evening"):
            candidates.append(legacy / f"{s}_{variant.capitalize()}_draws.csv")
        candidates.append(legacy / f"{s}_draws.csv")

    for p in candidates:
        if p.exists():
            return p
    return None

def load_state_draws(state: str, variant: str = "combined"):
    csv_path = resolve_draw_csv(state, None if variant == "combined" else variant)
    if not csv_path:
        return [], "(not found)"
    draws: list[str] = []
    with open(csv_path, newline="", encoding="utf-8") as f:
        for row in csv.reader(f):
            if not row:
                continue
            s = row[0].strip()
            if len(s) == 3 and s.isdigit():
                draws.append(s)
    # newest‑first expected; reverse here if your CSVs are oldest‑first
    return draws, str(csv_path)


Why: This guarantees that Connecticut4 resolves to Connecticut files, variants resolve correctly, we prefer data/cleaned/draws but gracefully accept legacy top‑level if it exists, and we return a clear “(not found)” when empty.
