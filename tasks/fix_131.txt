The new pre‑commit guard checks Stable row/family contracts, but not that winners CSV/JSON exports include the minimum evidence fields.

Booleans in enriched output

After merges, some booleans (progression_flag, last_remaining_3v, any_doubles_support, hidden3v) may arrive as pandas NA/object.

Fix: coerce to nullable Boolean dtype ('boolean') before display/export so UI and downstream code see consistent truthiness.
