What’s going on (why the error keeps moving)

From the log you shared:

Multiple attempts wrote the expander with literal \n text in the source (not a newline), so the line literally began with the characters \n with st.expander(...). Python treats the preceding backslash as a line‑continuation and then chokes on the next character.

Other passes introduced smart quotes / en‑dash in strings, e.g. — batch and “curly quotes” around strings. That’s fine if the file is UTF‑8 and the previous line is complete—but several edits also left dangling backslashes or unclosed parentheses directly above the expander, which again makes the next char “unexpected”.

Some replacement commands duplicated lines (two “Mirrored stamp” lines) or partially truncated src/app.py, then tried to paste sanitized blocks back, which is why you saw “file overwritten and truncated” messages later in the log.

In at least one overlay helper, I see quoting artifacts such as:

if len(canon) "'!= 3:


which is just a shell‑escape scar; it should be if len(canon) != 3:.

Bottom line: shell‑driven text surgery on Python f‑strings is fragile on Windows because backticks, quotes, and Unicode punctuation all interact with PowerShell’s parser. That’s why the errors keep moving.

2) Do not paste the big expander block into app.py again

# alpha_analytical/digit_reduction/analyzer_v2/ui_dev.py
from pathlib import Path
import streamlit as st

from utils.path_handler import get_analysis_output_dir
from .winners_overlay import run_winner_overlay_batch

def render_dr_winner_overlay_dev(state: str) -> None:
    """Small, dev-only panel to build DR winners overlays & stamps."""
    with st.expander("Analyzer V2 Winners overlay (DEV) - batch", expanded=False):
        st.caption("Build overlays, flags, and winner stamps for any variants you populate below.")

        base_analysis_dir = Path(get_analysis_output_dir())
        combined = st.text_input("Combined winner", value="", max_chars=3)
        midday   = st.text_input("Midday winner",   value="", max_chars=3)
        evening  = st.text_input("Evening winner",  value="", max_chars=3)
        mirror   = st.checkbox("Mirror stamp into Winners logger", value=True)

        if st.button(f"Build winners overlays for {state}"):
            winners = {k: v.strip() for k, v in {
                "Combined": combined,
                "Midday":   midday,
                "Evening":  evening,
            }.items() if v and v.strip()}

            if not winners:
                st.warning("Enter at least one winner before running the overlay batch.")
                return

            try:
                out = run_winner_overlay_batch(
                    state,
                    winners,
                    analysis_root=base_analysis_dir,
                    when=None,
                    mirror_to_winners=mirror,
                )
            except Exception as exc:
                st.error(f"Winners overlay batch failed: {exc}")
                return

            st.success("Digit Reduction winners overlays completed.")
            for variant, payload in (out.get("results") or {}).items():
                winner = payload.get("winner", "")
                counts = (payload.get("counts") or {})
                hits   = int(counts.get("items_exact_any", 0))
                st.markdown(f"**{variant}** — winner `{winner}` (hits={hits})")

                paths = payload.get("paths") or {}
                if paths.get("overlay_html"):
                    st.markdown(f"- [Annotated overlay]({paths['overlay_html']})")

                st.markdown("- [Winner map JSON]({}) — [Hits CSV]({}) — [Flags CSV]({})".format(
                    paths.get("winner_map_json", ""),
                    paths.get("winner_hits_csv",  ""),
                    paths.get("winner_flags_csv", ""),
                ))

                stamp_url = payload.get("stamp_json_winners")
                if stamp_url:
                    st.markdown(f"- Mirrored stamp: `{stamp_url}`")


Now add two tiny lines in src/app.py where you want the panel to show (any existing DR dev section is fine, right after you have state available):

Guardrails to avoid a repeat

Never patch Python via shell string replaces when the content contains quotes/backticks or Unicode punctuation. Edit the file directly or add a small imported module like we did.

Run python -m py_compile on any file you touch before launching the app. It catches these issues instantly.

Watch the line before a new block—trailing \ or an unclosed ( will make Python treat the next line as a continuation and blow up.

Keep UI text ASCII‑only in code (use - not —), and if you really want em‑dashes in the UI, inject them as data, not in source.
