Codex Brief — Positional Tracker outage, quick repair, and guardrails
TL;DR (1‑page)

Primary break: the app’s dynamic loader for the positional tool didn’t register the module in sys.modules before executing it. Downstream code/tests look up the tool by name; because the entry was missing, lookups returned None, which bubbled up as:
Positional module unavailable: 'NoneType' object has no attribute 'dict'.

Good news: the positional engine itself is healthy. When imported normally it produces full grids; the Streamlit block already renders the 3×(P1|P2|P3) tracker once a real report object exists.

Secondary friction we found and tuned alongside:

Pairs analysis was still scanning the last 100 draws in one call-site, making RED (≥107) impossible to reach. We standardized a 360 window and kept thresholds intact.

Threshold naming in one UI helper swapped RED/BLUE labels (values were right, names confusing). Add clear aliases to prevent future regressions.

V‑TRAC mini table could show a truncated set if a variant loader faulted and a cached frame was reused. After the positional fix, re‑read joins and show all 35 indices.

In src/app.py, the helper that imports project modules must register in sys.modules before exec_module:

# src/app.py  (loader helper)
import importlib.util as _ilu, sys as _sys, pathlib as _pl

def _load_project_module(dotted: str, path: str):
    p = _pl.Path(path)
    spec = _ilu.spec_from_file_location(dotted, p)
    if spec is None or spec.loader is None:
        raise ImportError(f"spec failed for {dotted} at {p}")
    mod = _ilu.module_from_spec(spec)
    _sys.modules[dotted] = mod          # <-- critical line (missing before)
    spec.loader.exec_module(mod)        # executes dataclasses against a real module
    return mod

“Why did this happen?” (one‑liner for the record)

A refactor during mojibake cleanup dropped the dynamic module’s sys.modules registration. That left the positional tool without a module identity during class initialization, which percolated up as the 'NoneType' has no attribute 'dict' failure. The fix is to register then execute; guard it with smokes; and keep staging explicit.
