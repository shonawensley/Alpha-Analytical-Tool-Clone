2) Evidence the scorer will read (what we measure)
This mirrors how you actually read the charts: vertical box checks (inside R2/R4/R6/R8), horizontal progression (Columns 7?1), and crosssection agreement (Midday/Evening/Combined). We’ll compute perindex features plus order/permutation features for straights.
2.1 Ring/column presence & progression
For each section (Midday/Evening/Combined), set (Set3 older ? Set1 newest), ring (R2, R4, R6, R8), and column (7?1):
* Presence: does any boxed combo from the index (Singles or Doubles) appear as a contiguous 3digit in that cell’s string?
* Persistence: how many consecutive columns (rightward) did that index survive?
* Firsthit depth: rightmost column where the index first appears (1=best).
* Ring emphasis: weight R2 a bit higher (longer strings frequently carry the most stable “spine” of the pattern). 
Why: your guides emphasize the rightmost columns and the “Set1 Draw 4..7 hot zones” as the strongest tells; R2 carries a lot of the persistent backbone. We’ll encode both. 
2.2 Hotzone intensity
From your rules:
* Draw1: last 5 items = hot (last 3 = superhot)
* Draw2: last 4 (last 2 = superhot)
* Draw3: last 3 (last 2 = superhot)
* Draw4–5: last 2 (both superhot)
We translate that to perpresence multipliers (+h, +H). 
2.3 Crosssection consensus
Count how many sections (Midday/Evening/Combined) confirm the same index in the last k columns (default k=3). Weight Combined slightly higher because it’s a synthesis panel, but do not let it swamp the independent Midday/Evening evidence. (Combined weight +15% is a good starting point.) 
2.4 Set survival (recency)
Give Set1 (today’s context) full weight, Set2 ~0.6, Set3 ~0.4. This bakes in the “progression through days” you use: Set3 ? Set2 ? Set1, with more credit for signals that persist into Set1. 
2.5 Straightorder (permutation) clues
For each index, we track order evidence for each straight permutation of its digits:
* Contiguous 3digit matches (e.g., 241, 641, 9221 ? order clues: 241; 641; 9221).
* Subsequence order matches (digits appear in order with ?1 gap).
We count these per ring/column, with the same hotzone, set, and section weights. This yields a Permutation Score for each of the 6 straights (for singles) or the relevant orderings for doubles. Your examples (e.g., 241 / 9221 / 6411 pointing to 691 straight) are exactly this kind of evidence, and we will let the scorer prefer the sameorder VTRAC straights when the charts echo them. 
2.6 Mirror & digitreduction assists (optional gates)
Two safe assists that amplify alreadypresent evidence:
* Transitdigit reduction: remove the previous draw’s transit/mirror digit(s) from long strings before scanning; rescan to see if a threevalue spine emerges (you do this by hand today). We record a boolean “reductionsurvives” flag per index if the index persists after this reduction. 
* Mirror check: mirror transforms that convert e.g., hidden 554008 into …408… variants will set an “mconfirm” bit on the index when they reinforce the same 3value spine across rings. (We log the before/after examples in the analysis CSV for audit.) 
These two are not used to invent signals—only to strengthen patterns you already see.
2.7 Doubles affinity
For indices whose boxed set is doublesheavy (e.g., 1, 10, 13, 15, 16, 23, 25, 26, 29, 31, 32, 33, 34, 35), track:
* Doublepair silhouette (e.g., ..44.., ..99..) in hotzone cells,
* Twovalue spines (like 5445), and
* Whether the doubled digit also appears as a float/mirror in recent context (light +w).
This lets VTRAC pivot cleanly when the day favors doubles (you also maintain doubles logs separately). (BA uses floats/mirror as triggers on drawsonly; we reapply a narrow variant here as a minor weight, keeping VTRAC stringcentric.) 

3) Scoring function (clear, tunable, and conservative)
We keep it explicit (sum of weighted evidence). Let an IndexScore be:
IndexScore(i) =
  ?_sections ?_sets ?_rings ?_cols [
     Presence(i, s, set, ring, col)
     × w_ring(ring) × w_col(col) × w_set(set) × w_section(section)
     × (1 + h_hot + h_superhot)             # hot-zone boosts
  ]
  + ? * CrossSectionConsensus(i)            # same index confirmed across sections in last k cols
  + ? * FirstHitBonus(i)                    # first hits that occur at col?{1,2}
  + ? * PersistenceBonus(i)                 # survived across ?m consecutive cols
  + ? * ReductionSurvives(i)                # optional gate boost if post-reduction survives
  + ? * DoublesAffinity(i)                  # only for doubles-heavy indices
Defaults (can be in a YAML config):
* w_ring: R2=1.25, R4=1.10, R6=1.0, R8=1.0.
* w_col: col1=1.00, col2=0.85, col3=0.70, col4=0.55, col5=0.40, col6=0.25, col7=0.15.
* w_set: Set1=1.00, Set2=0.60, Set3=0.40.
* w_section: Combined=1.15, Midday=1.00, Evening=1.00.
* h_hot=+0.10, h_superhot=+0.20.
* ?=+0.50, ?=+0.40, ?=+0.40, ?=+0.25, ?=+0.25.
Rationale: These constants encode what your Hit Guides already show—rightmost, Set1, R2 and hotzone matter more; agreement across panels matters; and reduction/mirror are supportive nudges, not kingmakers. The plan also honors the “Columns 1–2 focus” you documented. 

4) Straighthunt module (permutation ranking)
For each top index i, compute PermutationScore over its valid straights (6 for allunique, fewer for doubles). Use the same structure as IndexScore but counting order evidence only:
PermutationScore(i, perm) =
  ?_sections ?_sets ?_rings ?_cols [
     OrderEvidence(perm, s, set, ring, col)   # contiguous or near-subsequence hit
     × w_ring × w_col × w_set × w_section
     × (1 + h_hot + h_superhot)
  ]
  + ? * SameOrderEcho(perm)                   # appears in ?2 rings or ?2 sections at col?2
  + ? * TailAnchor(perm)                      # perm’s last digit seen at col1 repeatedly
Defaults: ?=+0.30, ?=+0.20. Output a probability distribution per index by softnormalizing the scores. Straight candidates are then (index, perm) pairs prioritized by IndexScore × PermutationProb. (This is how we capture the “241 / 9221 / 6411” ? 691 straight effect you highlighted.) 
Remember: a VTRAC cluster always yields 8 boxable combos (the “VTRAC straights” table). We’re simply prioritizing the orders most echoed by your strings to chase straight payouts opportunistically without exploding cost.

@dataclass

MIRROR_MAP = str.maketrans({"0":"5","1":"6","2":"7","3":"8","4":"9","5":"0","6":"1","7":"2","8":"3","9":"4"})

def slide_triad_windows(s: str) -> List[str]:
    """Unique triads seen when sliding 3 over a string like '5592441338'."""
    out = []
    for i in range(len(s)-2):
        triad = s[i:i+3]
        # ignore triples like '000','111' etc (VTRAC returns None)
        if len(set(triad)) == 1:
            continue
        out.append(triad)
    return out

def triads_to_indices(triads: Iterable[str]) -> List[Tuple[str, Optional[int]]]:
    out = []
    for t in triads:
        idx = get_vtrac_index(t)
        out.append((t, idx))
    return out

def mirror_string(s: str) -> str:
    return s.translate(MIRROR_MAP)

def count_survival_across_columns(columns: List[str]) -> Dict[str, int]:
    """
    For a sequence of columns (left?right), count how many distinct columns
    a triad appears in. Reward triads that survive toward the right.
    """
    seen_by_triad = defaultdict(set)
    for c_idx, col in enumerate(columns):
        for tri in set(slide_triad_windows(col)):
            seen_by_triad[tri].add(c_idx)
    return {tri: len(cols) for tri, cols in seen_by_triad.items()}

def straight_chain_strength(col: str, winner: Optional[str]) -> Dict[str, int]:
    """
    Reward adjacent overlapping triads that both belong to winner straights.
    Returns triad -> chain length indicator (0/1/2...).
    """
    if not winner:
        return {}
    straights = get_index_straights(winner)  # set of 6 perms
    tris = slide_triad_windows(col)
    strength = defaultdict(int)
    for i in range(len(tris)-1):
        if tris[i] in straights and tris[i+1] in straights:
            # overlapping chain found, reward both ends
            strength[tris[i]] += 1
            strength[tris[i+1]] += 1
    return strength

def index_frequency(triad_idx_pairs: Iterable[Tuple[str, Optional[int]]]) -> Dict[int, int]:
    c = defaultdict(int)
    for t, idx in triad_idx_pairs:
        if idx is not None:
            c[idx] += 1
    return dict(c)

def combos_for_index(index: int) -> List[str]:
    """Return all boxed 3digit combos (singles + doubles) for an index."""
    return sorted(get_index_set(index))

def _add_ev(acc: Dict[str, List[Evidence]], feat: str, ev: Evidence, emit: bool):
    if not emit: return
    acc.setdefault(feat, []).append(ev)

def score_vtrac_indices(inp: EngineInput, cfg: EnhancedVtracConfig) -> Dict[int, IndexScore]:
    """
    Core scoring over R2/R4/R6/R8 pattern strings across sections.
    """
    scores: Dict[int, IndexScore] = {}
    # Precompute winner straights (if known) for straight clues/chains
    w_tris = set()
    if inp.winner_hint:
        w_tris = get_index_straights(inp.winner_hint)

    # pass 1: raw presence + column weights + section weights + survival + straight clues
    section_seen: Dict[int, set] = defaultdict(set)  # index -> set(section)
    for sec in inp.sections:
        sec_w = cfg.section_weights.get(sec.section, 1.0)
        # group columns per r_key
        by_r = sec.patterns.by_r
        for r_key, cells in by_r.items():
            # Guarantee 7 columns weighting; if fewer, align from the right
            cols = [c.digits for c in cells]
            col_weights = cfg.col_weights.get(r_key, [1.0]*len(cols))
            # align right
            if len(col_weights) != len(cols):
                if len(cols) < len(col_weights):
                    col_weights = col_weights[-len(cols):]
                else:
                    # if more columns than weights, extend by the last weight
                    col_weights = col_weights + [col_weights[-1]]*(len(cols)-len(col_weights))

            # survival map for this r_key
            survival_map = count_survival_across_columns(cols)
            for c_idx, cell in enumerate(cells):
                cw = col_weights[c_idx] * sec_w
                # straight chains in this single column
                chain = straight_chain_strength(cell.digits, inp.winner_hint)

                triads = slide_triad_windows(cell.digits)
                for triad, idx in triads_to_indices(triads):
                    if idx is None: 
                        continue
                    sc = scores.setdefault(idx, IndexScore(index=idx))
                    # base presence
                    sc.score += cfg.w_index_presence * cw
                    _add_ev(sc.ev, "presence", Evidence("presence", {
                        "section": sec.section, "r": r_key, "col": c_idx, "triad": triad, "cw": cw
                    }), cfg.emit_evidence)
                    # survival
                    surv = survival_map.get(triad, 1)
                    if surv > 1:
                        sc.score += cfg.w_column_survival * (surv-1) * cw
                        _add_ev(sc.ev, "survival", Evidence("survival", {
                            "triad": triad, "cols": surv, "r": r_key, "col": c_idx, "cw": cw
                        }), cfg.emit_evidence)
                    # straight clue
                    if inp.winner_hint and triad in w_tris:
                        sc.score += cfg.w_straight_clue * cw
                        _add_ev(sc.ev, "straight_clue", Evidence("straight_clue", {
                            "triad": triad, "r": r_key, "col": c_idx, "cw": cw
                        }), cfg.emit_evidence)
                    # straight chain
                    ch = chain.get(triad, 0)
                    if ch > 0:
                        sc.score += cfg.w_straight_chain * ch * cw
                        _add_ev(sc.ev, "straight_chain", Evidence("straight_chain", {
                            "triad": triad, "links": ch, "r": r_key, "col": c_idx, "cw": cw
                        }), cfg.emit_evidence)

                    section_seen[idx].add(sec.section)

                # hot zone bonus
                if cell.hot:
                    for triad, idx in triads_to_indices(triads):
                        if idx is None: 
                            continue
                        sc = scores.setdefault(idx, IndexScore(index=idx))
                        sc.score += cfg.w_hotzone * cw
                        _add_ev(sc.ev, "hotzone", Evidence("hotzone", {
                            "section": sec.section, "r": r_key, "col": c_idx, "cw": cw
                        }), cfg.emit_evidence)

    # pass 2: crosssection consensus
    for idx, secs in section_seen.items():
        if len(secs) >= 2:
            sc = scores.setdefault(idx, IndexScore(index=idx))
            sc.score += cfg.w_cross_section * (len(secs) - 1)
            _add_ev(sc.ev, "cross_section", Evidence("cross_section", {
                "sections": sorted(secs)
            }), cfg.emit_evidence)

    # pass 3: mirror/reduction overlay using last draw (optional)
    if inp.last_draw:
        last = normalize_draw(inp.last_draw)
        if last:
            mirrored = mirror_string("".join(last))
            # treat mirrored last as a short “string column” hint
            for triad, idx in triads_to_indices(slide_triad_windows(mirrored)):
                if idx is None: 
                    continue
                sc = scores.setdefault(idx, IndexScore(index=idx))
                sc.score += cfg.w_digit_mirror_overlay
                _add_ev(sc.ev, "mirror_overlay", Evidence("mirror_overlay", {
                    "from_last": last, "triad": triad
                }), cfg.emit_evidence)

    # pass 4: doubles context
    if inp.doubles_context:
        for idx in list(scores.keys()):
            if idx in cfg.doubles_lean_indices:
                scores[idx].score += cfg.w_double_bias
                _add_ev(scores[idx].ev, "doubles_bias", Evidence("doubles_bias", {
                    "reason": "targeting doubles", "index": idx
                }), cfg.emit_evidence)

    # soft decay to reduce runaway from huge strings
    for sc in scores.values():
        sc.score *= cfg.w_index_frequency_decay

    return scores

def select_top_indices(scores: Dict[int, IndexScore], k: int = 8) -> List[IndexScore]:
    return sorted(scores.values(), key=lambda x: x.score, reverse=True)[:k]

def rank_index_combos(top_idx: List[IndexScore], winner_hint: Optional[str], cfg: EnhancedVtracConfig) -> Dict[int, List[ComboScore]]:
    """
    Within each top index, emit a list of straightleaning combos first,
    then boxed support, tagged for UI.
    """
    out: Dict[int, List[ComboScore]] = {}
    w_perms = set()
    if winner_hint:
        w_perms = {winner_hint} | set()  # normalize in caller if needed

    for sc in top_idx:
        combos = combos_for_index(sc.index)
        # heuristics: prefer singles combos first (len(set)==3); then doubles
        singles = [c for c in combos if len(set(c)) == 3]
        doubles = [c for c in combos if len(set(c)) == 2]

        ranked: List[ComboScore] = []

        # Straight “lane” preference: award small bonus if combo itself equals any triad
        # seen among straight clues in evidence
        straight_triads = set()
        for evs in sc.ev.values():
            for ev in evs:
                if ev.feature in ("straight_clue", "straight_chain"):
                    t = ev.details.get("triad")
                    if isinstance(t, str) and len(t) == 3:
                        straight_triads.add(t)

        def _score_combo(c: str) -> float:
            base = 0.0
            if c in straight_triads:
                base += 0.6
            # small nudge for more frequent digit variety
            if len(set(c)) == 3:
                base += 0.2
            return base

        # rank singles then doubles by the heuristic
        singles_ranked = sorted(singles, key=_score_combo, reverse=True)[:cfg.per_index_top_straights]
        doubles_ranked = sorted(doubles, key=_score_combo, reverse=True)[:cfg.per_index_top_boxed]

        for c in singles_ranked + doubles_ranked:
            cs = ComboScore(index=sc.index, combo=c, score=sc.score * 0.05, tags=[])
            if c in straight_triads:
                cs.tags.append("STRAIGHTCLUE")
            if len(set(c)) == 2:
                cs.tags.append("DOUBLE")
            ranked.append(cs)

        out[sc.index] = ranked

    return out

def load_from_training_json(d: Dict) -> EngineInput:
    """
    Adapter for the JSON example you provided in the message.
    """
    sections: List[SectionPatterns] = []
    for section_name, section_body in d.get("sections", {}).items():
        for set_name, set_body in section_body.get("sets", {}).items():
            # We will take Draw1..Draw7 under this set and build columns per R2/R4/R6/R8
            # The example structure: pattern_variations -> R2: [col0, col1, ...]
            draw_map = set_body.get("draws", {})
            # The 'progression' is Draw1 (7 cols) ? … ? Draw7 (1 col)
            # We will read ONLY Draw1 here (it carries all columns).
            if "Draw1" not in draw_map:
                # fall back to any draw that exists
                if not draw_map:
                    continue
                first = sorted(draw_map.keys())[0]
                draw = draw_map[first]
            else:
                draw = draw_map["Draw1"]
            pvar = draw.get("pattern_variations", {})
            by_r = {}
            for r_key, cols in pvar.items():
                cells = []
                for c_idx, col_str in enumerate(cols):
                    cells.append(PatternCell(
                        r_key=r_key, column_idx=c_idx, digits=col_str,
                        hot=bool(draw.get("metadata", {}).get("is_hot_zone", False)),
                        section=section_name
                    ))
                by_r[r_key] = cells
            sections.append(SectionPatterns(section=section_name, patterns=PatternSet(by_r=by_r)))
    last_draw = None
    winner = None
    if "analysis_guide" in d:
        # Optional enrichment if present elsewhere
        pass
    return EngineInput(sections=sections, last_draw=last_draw, winner_hint=winner, doubles_context=False)

_MIRROR = { '0':'5','1':'6','2':'7','3':'8','4':'9','5':'0','6':'1','7':'2','8':'3','9':'4' }

def mirror_digit(d: str) -> str:
    return _MIRROR.get(d, d)

def transit_blocklist(last_draw: Optional[str]) -> Set[str]:
    """
    Transit elimination: block the latest combined draw's digits and their mirrors.
    Example: last_draw '898' ? block {'8','3'}.
    """
    block: Set[str] = set()
    s = normalize_draw(last_draw) if last_draw else None
    if s:
        for ch in set(s):
            block.add(ch)
            block.add(mirror_digit(ch))
    return block

_RE_NUM = re.compile(r"\d+")

def _clip(s: str, maxlen: int) -> str:
    return s if len(s) <= maxlen else s[:maxlen]

def extract_numeric_runs(cell_text: str, cfg: AnalyzerConfig) -> List[str]:
    """
    Pull digit runs from a cell, clip to a sane size to prevent runaway permutations.
    Returns runs of length >= cfg.min_token_len.
    """
    out: List[str] = []
    for m in _RE_NUM.finditer(str(cell_text)):
        t = _clip(m.group(0), cfg.max_token_len)
        if len(t) >= cfg.min_token_len:
            out.append(t)
    return out

def slide_windows(s: str, k: int) -> Iterable[str]:
    for i in range(0, max(0, len(s) - k + 1)):
        yield s[i:i+k]

def combos_of_k(s: str, choose: int) -> Iterable[str]:
    unique = set()
    for tup in itertools.combinations(s, choose):
        c = "".join(tup)
        if c not in unique:
            unique.add(c)
            yield c

# Canonicalize a 3digit into the “boxed label” (e.g., '650'?index 2, boxed '056')
def boxed_label(s: str) -> Optional[str]:
    s = normalize_draw(s)
    if not s or len(set(s)) == 1:  # suppress triples
        return None
    # map any perm back to its canonical boxed label if known
    return BOXED_LABEL_LOOKUP.get(s) or BOXED_LABEL_LOOKUP.get("".join(sorted(s)))

def _score_hit(base: float,
               section: str,
               colpos: int,
               rowtype: str,
               is_hot: bool,
               cfg: AnalyzerConfig,
               section_weights: Dict[str, float]) -> float:
    cw = cfg.column_weights.get(colpos, 1.0)
    rw = cfg.rowtype_weights.get(rowtype, 1.0)
    sw = section_weights.get(section, 1.0)
    hz = (cfg.hot_zone_bonus if is_hot else 0.0)
    return base * cw * rw * sw + hz

def _ensure_index(evd: Dict[int, IndexEvidence], idx: int) -> IndexEvidence:
    if idx not in evd:
        evd[idx] = IndexEvidence()
    return evd[idx]

def _ensure_straight(evd: Dict[str, StraightEvidence], s: str) -> StraightEvidence:
    if s not in evd:
        evd[s] = StraightEvidence()
    return evd[s]

def _score_straight_token(token3: str,
                          section: str,
                          colpos: int,
                          cfg: AnalyzerConfig,
                          straights: Dict[str, StraightEvidence]) -> None:
    se = _ensure_straight(straights, token3)
    se.appearances += 1
    se.right_cols.add(colpos)
    se.sections.add(section)
    se.score += cfg.straight_presence_weight + \
                (cfg.straight_right_bias if colpos <= 3 else 0.0)

def _apply_transit_penalty(digits: Set[str], blocklist: Set[str]) -> bool:
    return any(d in blocklist for d in digits)

def analyze_sections(sections: List[SectionInput], cfg: Optional[AnalyzerConfig] = None) -> AnalyzerResult:
    cfg = cfg or AnalyzerConfig()
    res = AnalyzerResult(config=cfg)
    indices = res.indices
    straights = res.straights

    # Pre-compute transit blocklists per section (commonly use Combined's last draw)
    # If only Combined has a last_draw, we will still honor section-level ones.
    combined_last = next((s.last_draw for s in sections if s.name.lower().startswith("combined")), None)

    for sec in sections:
        section = sec.name
        section_weights = dict(cfg.section_weights)
        # allow per-section override
        if sec.col_weights:
            for k, v in sec.col_weights.items(): cfg.column_weights[k] = v
        if sec.rowtype_weights:
            for k, v in sec.rowtype_weights.items(): cfg.rowtype_weights[k] = v
        if sec.hot_zone_bonus is not None:
            cfg.hot_zone_bonus = sec.hot_zone_bonus

        block = transit_blocklist(sec.last_draw or combined_last)

        for cell in sec.cells:
            # Extract raw digit runs (e.g., "55994011386")
            runs = extract_numeric_runs(cell.text, cfg)
            if not runs:
                continue

            # Per-cell de-dup of boxed labels to prevent runaway
            seen_boxed: Set[Tuple[int, str]] = set()
            seen_straights: Set[str] = set()

            for r in runs:
                r = r.strip()
                if not r: 
                    continue
                # 1) Sliding 3digit windows ? direct index hits + straight hints
                for tok3 in slide_windows(r, 3):
                    boxed = boxed_label(tok3)
                    if not boxed:
                        continue
                    idx = get_vtrac_index(tok3)
                    if idx is None:
                        continue

                    # Evidence unit
                    key = (idx, boxed if cfg.per_cell_presence_only else boxed+tok3)
                    if key not in seen_boxed:
                        seen_boxed.add(key)

                        # Base hit
                        inc = _score_hit(1.0, section, cell.colpos, cell.rowtype, cell.is_hot_zone,
                                         cfg, section_weights)

                        # Transit penalty
                        if _apply_transit_penalty(set(tok3), block):
                            inc -= cfg.transit_penalty

                        ie = _ensure_index(indices, idx)
                        ie.score += inc
                        ie.sections_present.add(section)
                        ie.hits_by_col[cell.colpos] = ie.hits_by_col.get(cell.colpos, 0) + 1
                        ie.hits_by_rowtype[cell.rowtype] = ie.hits_by_rowtype.get(cell.rowtype, 0) + 1
                        if cell.is_hot_zone:
                            ie.hot_zone_hits += 1
                        if cell.colpos <= 3:
                            ie.end_survival_cols.add(cell.colpos)

                    # Straight discovery (ordered token appearances)
                    if tok3 not in seen_straights:
                        seen_straights.add(tok3)
                        _score_straight_token(tok3, section, cell.colpos, cfg, straights)
                        # Also link straight to its owning index evidence for explain
                        idx2 = get_vtrac_index(tok3)
                        if idx2 is not None:
                            ie2 = _ensure_index(indices, idx2)
                            ie2.straight_tokens[tok3] = ie2.straight_tokens.get(tok3, 0) + 1
                            rs = ie2.straight_right_cols.setdefault(tok3, set())
                            if cell.colpos <= 3:
                                rs.add(cell.colpos)

                # 2) Hiddenbehinddigit: 3of4 or 3of5 selections from clusters
                if len(r) >= 4:
                    for pick3 in combos_of_k(r, 3):
                        boxed = boxed_label(pick3)
                        if not boxed:
                            continue
                        idx = get_vtrac_index(pick3)
                        if idx is None:
                            continue
                        # Count as a hidden triplet if the 3ofk was NOT also a sliding adjacent window
                        # (i.e., uncovered only via combination)
                        if pick3 not in seen_straights:
                            inc = _score_hit(cfg.hidden_triplet_bonus, section, cell.colpos,
                                             cell.rowtype, cell.is_hot_zone, cfg, section_weights)
                            # Transit penalty if necessary
                            if _apply_transit_penalty(set(pick3), block):
                                inc -= cfg.transit_penalty

                            ie = _ensure_index(indices, idx)
                            ie.score += inc
                            ie.hidden_hits += 1
                            ie.hits_by_col[cell.colpos] = ie.hits_by_col.get(cell.colpos, 0) + 1
                            ie.hits_by_rowtype[cell.rowtype] = ie.hits_by_rowtype.get(cell.rowtype, 0) + 1
                            ie.sections_present.add(section)
                            if cell.colpos <= 3:
                                ie.end_survival_cols.add(cell.colpos)

                # 3) Digitshift exposure: remove transit digits and rescore newly exposed 3windows
                if block:
                    cleaned = "".join(ch for ch in r if ch not in block)
                    if cleaned and cleaned != r and len(cleaned) >= 3:
                        for tok3 in slide_windows(cleaned, 3):
                            boxed = boxed_label(tok3)
                            if not boxed:
                                continue
                            idx = get_vtrac_index(tok3)
                            if idx is None:
                                continue
                            key = (idx, "SHIFT:"+boxed) if cfg.per_cell_presence_only else (idx, "SHIFT:"+tok3)
                            if key not in seen_boxed:
                                seen_boxed.add(key)
                                inc = _score_hit(cfg.shift_bonus, section, cell.colpos, cell.rowtype,
                                                 cell.is_hot_zone, cfg, section_weights)
                                ie = _ensure_index(indices, idx)
                                ie.score += inc
                                ie.shift_hits += 1
                                ie.sections_present.add(section)
                                ie.hits_by_col[cell.colpos] = ie.hits_by_col.get(cell.colpos, 0) + 1
                                ie.hits_by_rowtype[cell.rowtype] = ie.hits_by_rowtype.get(cell.rowtype, 0) + 1
                                if cell.colpos <= 3:
                                    ie.end_survival_cols.add(cell.colpos)

    # Crosssection bonus for straights that appear in >1 section
    for s, ev in straights.items():
        if len(ev.sections) > 1:
            ev.score += cfg.straight_cross_section_bonus

    # Rank outputs
    res.top_indices = sorted(((i, ev.score) for i, ev in indices.items()),
                             key=lambda x: x[1], reverse=True)
    res.top_straights = sorted(((s, ev.score) for s, ev in straights.items()),
                               key=lambda x: x[1], reverse=True)

    return res

def from_jsonlike_section(name: str, data: Dict, *, is_hot_zone: Optional[bool] = None) -> SectionInput:
    """
    Build a SectionInput from the JSON-like example you provided.
    We expect structure:
      { sets: { Set1: { draws: { Draw1: { draw_data: [...],
                                         pattern_variations: { R2: [col7..1], R4: [...], R6: [...], R8: [...] },
                                         metadata: { is_hot_zone: bool }}, Draw2: {...}, ... } }, Set2: {...}, Set3: {...} } }
    """
    cells: List[StringCell] = []
    last_draw = None

    sets = (data or {}).get("sets", {})
    for set_name, set_obj in sets.items():
        draws = (set_obj or {}).get("draws", {})
        # Track "Draw1" of Set1 as "current day" hot zone unless metadata overrides
        for draw_name, d in draws.items():
            pv = (d or {}).get("pattern_variations", {})
            meta = (d or {}).get("metadata", {})
            is_hot = bool(meta.get("is_hot_zone", False))
            if is_hot_zone is not None:
                is_hot = is_hot_zone
            # The "draw_data" tail most item often represents the latest draw for that progression
            dd = d.get("draw_data", [])
            if dd:
                last_draw = dd[-1]  # keep the last entry as potential section.last_draw

            for rowtype in ("R2", "R4", "R6", "R8"):
                cols = pv.get(rowtype, [])
                # Annotate colpos from left to right: 7..1
                for offset, text in enumerate(cols, start=0):
                    colpos = 7 - offset
                    if colpos < 1 or colpos > 7:
                        continue
                    cells.append(StringCell(section=name, rowtype=rowtype, colpos=colpos,
                                            text=str(text), is_hot_zone=is_hot,
                                            set_label=set_name, draw_label=draw_name))

    return SectionInput(name=name, cells=cells, last_draw=normalize_draw(last_draw))

def write_run_artifacts(state: str,
                        result: AnalyzerResult,
                        run_root: Path,
                        *,
                        draw_context: Optional[Dict]=None,
                        top_k: int = 8) -> Path:
    """
    Persist a compact JSON under runs/YYYYMMDD/<run_id>/vtrac_enhanced.json
    aligned with your Winner Logging plan so it’s easy to crossanalyze later.  :contentReference[oaicite:4]{index=4}
    """
    day = datetime.now().strftime("%Y-%m-%d")
    run_id = datetime.now().strftime("%H%M%S")
    out_dir = run_root / day / run_id
    out_dir.mkdir(parents=True, exist_ok=True)

    payload = {
        "tool": "VTRAC_ENHANCED",
        "state": state,
        "timestamp": datetime.now().isoformat(timespec='seconds'),
        "top_indices": [{"index": i, "score": round(s, 3)} for i, s in result.top_indices[:top_k]],
        "top_straights": [{"straight": s, "score": round(sc, 3)} for s, sc in result.top_straights[:top_k]],
        "explain": {
            str(i): {
                "score": round(ev.score, 3),
                "hits_by_col": ev.hits_by_col,
                "hits_by_rowtype": ev.hits_by_rowtype,
                "end_survival_cols": sorted(ev.end_survival_cols),
                "hot_zone_hits": ev.hot_zone_hits,
                "hidden_hits": ev.hidden_hits,
                "shift_hits": ev.shift_hits,
                "transit_penalties": ev.transit_penalties,
                "sections": sorted(list(ev.sections_present)),
                "top_straights": sorted(
                    [{"straight": s, "count": c, "right_cols": sorted(list(result.indices[i].straight_right_cols.get(s, set())))} 
                     for s, c in ev.straight_tokens.items()],
                    key=lambda x: (-x["count"], x["straight"])
                )[:top_k]
            }
            for i, ev in result.indices.items()
        },
        "draw_context": draw_context or {}
    }
    fp = out_dir / "vtrac_enhanced.json"
    fp.write_text(json.dumps(payload, indent=2))
    return fp

3.2 HiddenDigit Unmasker (fast & general)
This is the “pattern hidden behind a digit” detector you described. It temporarily removes a target digit from a column string and rescans 3windows, attributing any new VTRAC indices discovered to that digit. (We’ll use those signals both for ranking and for the “why it ranked” audit.) The unmasker is pure and fast; it runs per column, per digit.
# src/core/vtrac_ng_unmask.py
from __future__ import annotations
from typing import Dict, Set, Tuple
from modules.vtrac_reference import get_vtrac_index  # shipped in your repo

def scan_indices(s: str, window: int = 3) -> Set[int]:
    """Scan all 3-char windows in s, map to V-TRAC indices."""
    found: Set[int] = set()
    for i in range(0, max(0, len(s) - window + 1)):
        sub = s[i:i+window]
        ix = get_vtrac_index(sub)
        if ix is not None:
            found.add(ix)
    return found

def hidden_digit_diff(s: str, digits: Tuple[int, ...], window: int = 3) -> Dict[int, Set[int]]:
    """
    For each digit d, remove all occurrences of d and record indices
    that appear after removal but not in the original.
    """
    base = scan_indices(s, window)
    out: Dict[int, Set[int]] = {}
    for d in digits:
        rep = s.replace(str(d), "")
        if rep == s or len(rep) < window:
            continue
        alt = scan_indices(rep, window)
        newly = alt.difference(base)
        if newly:
            out[d] = newly
    return out

def build_grid_evidence(
    state: str,
    cfg: NGConfig = DEFAULT_CFG
) -> GridEvidence:
    boxes = cfg.boxes
    raw = _load_state_tables(state)
    hot = _load_hot_zones(state)
    ge = GridEvidence()
    for box in boxes:

        ge.hot_columns[box] = hot.get(box, [False]*len(cols))
        # capture right-tail windows for straights mining (last 2 columns per box)
        ge.tail_windows[box] = cols[-2:] if len(cols) >= 2 else cols[-1:]
        seen: Set[int] = set()
        for c, s in enumerate(cols):
            ce = ColumnEvidence()

            for ix in scan_indices(s, window=cfg.window):
                ce.index_counts[ix] += 1

            # 2) hidden-digit unmasker

            for d, ixset in hidden.items():

                    seen.add(ix)
            ge.by_box[box].append(ce)
        ge.observed_indices[box] = seen
    return ge

# ---------- Scoring ----------
def score_indices(
    ge: GridEvidence,
    cfg: NGConfig = DEFAULT_CFG,
    w: ScoreWeights = DEFAULT_WEIGHTS
) -> List[IndexScore]:
    per_ix_score: Dict[int, IndexScore] = {}
    # progression + hot zones
    for box, cols in ge.by_box.items():
        for ci, ce in enumerate(cols):
            col_w = w.column_weights[ci] if ci < len(w.column_weights) else w.column_weights[-1]
            hot_bonus = w.hot_zone_bonus if ge.hot_columns.get(box, [False]*len(cols))[ci] else 0.0
            for ix, cnt in ce.index_counts.items():
                add = (cnt * col_w) + hot_bonus
                item = per_ix_score.get(ix, IndexScore(ix, 0.0, []))
                item.raw += add
                if hot_bonus:
                    item.reasons.append(f"{box}@{ci+1}:hot")
                if cnt > 0:
                    item.reasons.append(f"{box}@{ci+1}:x{cnt}")
                per_ix_score[ix] = item
            # hidden-digit boosts
            for d, ixset in ce.hidden_by_digit.items():
                for ix in ixset:
                    item = per_ix_score.get(ix, IndexScore(ix, 0.0, []))
                    item.raw += w.hidden_digit_bonus
                    item.reasons.append(f"{box}@{ci+1}:hidden{d}")
                    per_ix_score[ix] = item
        # last-column bonus if an index survives to last col
        if cols:
            last_ixs = set(cols[-1].index_counts.keys()) if hasattr(cols[-1], "index_counts") else set()
            for ix in last_ixs:
                item = per_ix_score.get(ix, IndexScore(ix, 0.0, []))
                item.raw += w.last_col_bonus
                item.reasons.append(f"{box}@last")
                per_ix_score[ix] = item

    # cross-box persistence
    boxes_with_ix: Dict[int, int] = Counter()
    for box, ixset in ge.observed_indices.items():
        for ix in ixset:
            boxes_with_ix[ix] += 1
    for ix, count in boxes_with_ix.items():
        if count >= 2:
            item = per_ix_score.get(ix, IndexScore(ix, 0.0, []))
            item.raw += w.cross_box_bonus
            item.reasons.append(f"cross:{count}boxes")
            per_ix_score[ix] = item

    # (Optional) straight-order signal bonus added later when straights are mined
    ranked = sorted(per_ix_score.values(), key=lambda x: (-x.raw, x.index))
    return ranked[: cfg.top_k_indices]

# ---------- Straights mining ----------
def mine_straights(
    ge: GridEvidence,
    top_indices: List[IndexScore],
    cfg: NGConfig = DEFAULT_CFG,
    w: ScoreWeights = DEFAULT_WEIGHTS,
    last_draw: Optional[str] = None
) -> List[StraightPick]:
    """
    Use tail windows to capture permutation clues; emit straights for top indices
    and boost those matching evident order continuity.
    """
    picks: List[StraightPick] = []
    top_ix_set = {t.index for t in top_indices}
    # Collect tail-character trigrams (last 2 cols per box) to bias order
    order_clues: Set[str] = set()
    for box, tails in ge.tail_windows.items():
        for s in tails:
            for i in range(0, max(0, len(s) - 3 + 1)):
                order_clues.add(s[i:i+3])

    for ix in top_ix_set:
        boxed = list(get_index_set(ix))  # canonical singles/doubles strings
        # straights = union of straight perms across the boxed set
        candidate_straights: Set[str] = set()
        for b in boxed:
            for st in get_index_straights(b):
                candidate_straights.add(st)
        # score straights by presence of its 3-char order inside any order_clue string
        for st in candidate_straights:
            base = 1.0
            reason = []
            if st in order_clues:
                base += w.straight_signal_bonus
                reason.append("order-clue")
            if last_draw:
                # light digit-reduction hook: avoid repeating exact last draw by default
                if st == last_draw:
                    continue
            picks.append(StraightPick(straight=st, index=ix, score=base, reasons=reason))

    # rank straights; de-duplicate by straight with max score
    best: Dict[str, StraightPick] = {}
    for p in picks:
        if (p.straight not in best) or (p.score > best[p.straight].score):
            best[p.straight] = p
    ranked = sorted(best.values(), key=lambda x: (-x.score, x.straight))
    return ranked[: cfg.top_k_straights]

MIRROR_MAP = str.maketrans("01234", "56789")  # 0?5,1?6,2?7,3?8,4?9; we apply forward (mirror pair happens if any digit maps onto companion)
REV_MIRROR_MAP = str.maketrans("56789", "01234")

def digital_root(n: int) -> int:
    if n == 0:
        return 0
    r = n % 9
    return 9 if r == 0 else r

def root_sum3(draw: str) -> Optional[int]:
    s = normalize_draw(draw)
    if s is None: return None
    return digital_root(sum(int(c) for c in s))

def sum3(draw: str) -> Optional[int]:
    s = normalize_draw(draw)
    if s is None: return None
    return sum(int(c) for c in s)

def has_mirror_pair(draw: str) -> bool:
    s = normalize_draw(draw)
    if s is None: return False
    # mirror event if any pair (a,b) equals mirror of other: practical proxy—if any digit mirrors onto another present
    t = s.translate(MIRROR_MAP)
    return any(ch in s for ch in t)

def floating_digits(draws: List[str], window: int = 5) -> set[int]:
    recent = draws[:window] if len(draws) >= window else draws[:]
    seen = set(int(d) for s in recent for d in normalize_draw(s) or "")
    return set(range(10)) - seen

def extract_index_features(
    state: str,
    base_index_stats: Dict[int, dict],
    *,
    recent_draws: Optional[List[str]] = None,
    cross_section_presence: Optional[Dict[int, set]] = None,  # {index: {"Midday","Evening","Combined"}}
    hot_zone_map: Optional[Dict[int, int]] = None,            # {index: count}
    rightmost_survival_map: Optional[Dict[int, int]] = None,  # {index: score}
    reduction_agreement_map: Optional[Dict[int, int]] = None  # {index: 0/1 or small int}
) -> List[IndexFeatures]:
    """
    Build feature rows for each index present in base_index_stats.
    - base_index_stats: the dict your module_c_vtrac.analyze_all_indexes(...) returns per index (counts per R2/R4/R6/R8, etc.)
    - recent_draws: newest-first; if None, we try to load via modules.aux_loaders (CSV-only).
    """
    # Try loading draws if not provided (safe; Aux/BA use CSV-only)
    if recent_draws is None and load_state_draws is not None:
        try:
            recent_draws, _ = load_state_draws(state)  # newest-first
        except Exception:
            recent_draws = None

    # Root-due context
    rs_due_set: set[int] = set()
    mirror_flag = 0
    float_set: set[int] = set()

    if recent_draws:
        # compute longest-out digital root(s)
        gaps_by_rs: Dict[int, int] = {r: 10**9 for r in range(1,10)}
        last_seen = {r: None for r in range(1,10)}
        for i, d in enumerate(recent_draws):
            rs = root_sum3(d)
            if rs and last_seen[rs] is None:
                last_seen[rs] = i
        # distance since last seen = gap
        for r in range(1,10):
            if last_seen[r] is not None:
                gaps_by_rs[r] = last_seen[r]
        max_gap = max(gaps_by_rs.values())
        rs_due_set = {r for r,g in gaps_by_rs.items() if g == max_gap}

        mirror_flag = 1 if has_mirror_pair(recent_draws[0]) else 0
        float_set = floating_digits(recent_draws, window=5)

    rows: List[IndexFeatures] = []
    for idx, payload in base_index_stats.items():
        f = IndexFeatures(index=idx)

        # Parse base counts safely
        counts = payload.get("counts", {})  # convention: {"R2":int,"R4":int,"R6":int,"R8":int}
        f.r2_hits = int(counts.get("R2", 0))
        f.r4_hits = int(counts.get("R4", 0))
        f.r6_hits = int(counts.get("R6", 0))
        f.r8_hits = int(counts.get("R8", 0))
        f.total_hits = f.r2_hits + f.r4_hits + f.r6_hits + f.r8_hits

        if rightmost_survival_map:
            f.rightmost_survival = int(rightmost_survival_map.get(idx, 0))
        if hot_zone_map:
            f.hot_zone_hits = int(hot_zone_map.get(idx, 0))
        if cross_section_presence:
            f.cross_section_hits = len(cross_section_presence.get(idx, set()))

        # RS due match: if any straight of this index has RS in rs_due_set, count it once
        if rs_due_set:
            # proxy: if any boxed combo in index has RS due, give 1
            rs_hit = 0
            for combo in get_index_set(idx):
                rs = root_sum3(combo)
                if rs and rs in rs_due_set:
                    rs_hit = 1
                    break
            f.rs_due_match = rs_hit

        # Mirror & Float pressure (coarse but helpful)
        if mirror_flag:
            f.mirror_pressure = 1
        if float_set:
            # proxy: if any boxed combo in index uses at least one floating digit, boost
            uses_float = 0
            for combo in get_index_set(idx):
                if any(int(ch) in float_set for ch in combo):
                    uses_float = 1
                    break
            f.float_pressure = uses_float

        # Straights order echoes (rightmost bias + same-order proxy)
        # We use a heuristic: if rightmost survival is strong and f.r8_hits>0, give extra "end_sequence_bias".
        if f.rightmost_survival > 0 and f.r8_hits > 0:
            f.end_sequence_bias = 1

        # "Same-order echo" proxy: if any straight equals the last draw (order-equal VTRAC), nudge
        if recent_draws:
            last = recent_draws[0]
            straights = get_index_straights(last)
            # If the last draw’s perm set belongs to this index, reflect a weak echo (do not overfit)
            if straights:
                # map any perm to V-index and compare
                # We don’t import get_vtrac_index here to keep this module pure on references;
                # a soft echo is okay: if the last draw’s digit *set* appears among this index’s boxed combos
                last_set = set(normalize_draw(last))
                f.same_order_echo = 1 if any(set(c) == last_set for c in get_index_set(idx)) else 0

        if reduction_agreement_map:
            f.reduction_agreement = int(reduction_agreement_map.get(idx, 0))

        rows.append(f)

    return rows

def load_weights(yaml_path: Optional[str]) -> Tuple[Dict[str, float], Dict[str, float]]:
    if not yaml_path or not os.path.isfile(yaml_path):
        return DEFAULT_WEIGHTS, DEFAULT_BONUS

    try:

def score_indices(features: List[IndexFeatures], *, weights: Dict[str, float]) -> List[dict]:
    rows = []
    for f in features:
        score = 0.0
        for k, w in weights.items():
            score += getattr(f, k, 0) * w
        r = f.as_row()
        r["adv_score"] = round(score, 6)
        rows.append(r)
    # stable sort by adv_score desc then index asc
    rows.sort(key=lambda r: (-r["adv_score"], r["index"]))
    return rows

def compute_369_stack_label(recent_roots_longest_out: Optional[set], mirror_flag: bool, float_set: set[int]) -> Optional[str]:
    if not recent_roots_longest_out:
        return None
    if not ({3,6,9} & recent_roots_longest_out):
        return None
    # co-signal: mirror OR any float includes 3/6/9
    if mirror_flag or ({3,6,9} & float_set):
        return "369-Stack"
    return None

def rank_straights_for_index(
    index: int,
    *,
    candidate_bonus: float = 0.2,
    end_sequence_bias: int = 0,
    same_order_echo: int = 0,
    rs_due_set: Optional[set[int]] = None
) -> List[Tuple[str, float, List[str]]]:
    """
    Return straight candidates (perm) with small, explainable boosts:
    - bonus if perm's RS in rs_due_set
    - bonus if same-order echo flagged
    - bonus if end-sequence bias flagged
    """
    perms: set[str] = set()
    # Build from representative boxed combos — any is fine (8 perms per VTRAC family)
    for combo in get_index_set(index):
        perms |= get_index_straights(combo)

    out: List[Tuple[str, float, List[str]]] = []
    for p in perms:
        s = 0.0
        tags: List[str] = []
        if rs_due_set:
            rs = sum(int(c) for c in p)
            # digital root without importing helper (small duplication to keep module self-contained)
            dr = 9 if rs % 9 == 0 and rs != 0 else (rs % 9)
            if dr in rs_due_set:
                s += candidate_bonus
                tags.append(f"RS{dr}")
        if same_order_echo:
            s += 0.1; tags.append("ECHO")
        if end_sequence_bias:
            s += 0.1; tags.append("R8-BIAS")
        out.append((p, round(s, 6), tags))

    out.sort(key=lambda t: (-t[1], t[0]))
    return out

# modules/vtrac_evidence.py
from __future__ import annotations
from dataclasses import dataclass, field
from typing import Dict, List, Tuple, Set, Optional
import re
import json
from pathlib import Path

# We depend only on your canonical reference helpers.
# These exist today and are imported by other tools in your app. (No refactor.)
#   - modules.vtrac_reference: BOXED_VTRAC_REFERENCE, get_vtrac_index, get_index_set, get_index_straights
from modules.vtrac_reference import get_vtrac_index, get_index_set, get_index_straights

# --------------------------
# Types the existing page can fill easily
# --------------------------
# We keep this adapter light so you can pass what you already compute today in module_c_vtrac.
#
# "columns" are left->right strings from each R2/R4/R6/R8 box. The more to the right, the closer to "now".
# We accept pre-extracted column text blocks (any cleaned string). If you have richer structures,
# adapt upstream and keep this signature stable.
SectionName = str   # "Midday" | "Evening" | "Combined"
RingName = str      # "R2" | "R4" | "R6" | "R8"

@dataclass
class GridInputs:
    # For each section/ring, provide a list of columns as text. Index 0 = leftmost, last = rightmost.
    columns_by_section_ring: Dict[SectionName, Dict[RingName, List[str]]]
    # Optional "hot zones" hint per section/ring -> list of right-column indices considered hot
    hot_zone_cols: Dict[SectionName, Dict[RingName, Set[int]]] = field(default_factory=dict)
    # Optional latest draws digits to support masking / digit-reduction hints
    latest_draw_digits: List[str] = field(default_factory=list)  # e.g., ["6","9","1"]

# --------------------------
# Weights / knobs (safe defaults)
# --------------------------
@dataclass
class EvidenceWeights:
    # column weights escalate to the right (latest columns carry more signal)
    # You can pass per-ring custom arrays; if None we auto-build linear ramps.
    col_weights: Dict[RingName, List[float]] = field(default_factory=dict)
    # ring multipliers: R8 > R6 > R4 > R2 by default (more compressed strings, sharper evidence)
    ring_gain: Dict[RingName, float] = field(default_factory=lambda: {"R2":1.0,"R4":1.15,"R6":1.3,"R8":1.45})
    # section multipliers: allow small boost to Combined (often most stable)
    section_gain: Dict[SectionName, float] = field(default_factory=lambda: {"Midday":1.0,"Evening":1.0,"Combined":1.1})
    # stability / survival bonuses
    survive_right_bonus: float = 0.6     # survives into last col of any ring
    multi_section_bonus: float = 0.5     # appears in >=2 sections (same ring or across rings)
    repetition_chain_bonus: float = 0.3  # consecutive rightward hits within a ring
    hot_zone_bonus: float = 0.35         # ring/col marked as "hot" by the UI logic

    # Straights layer (pass B)
    straight_base: float = 1.0           # base value when a straight clue is detected
    straight_same_order_bonus: float = 0.6  # “same-order” VTRAC straight clue
    straight_cross_section_bonus: float = 0.35
    straight_hot_zone_bonus: float = 0.35
    # Optional digit masking (“hidden-behind-a-digit”) – if a clue appears only after masking a digit, small boost
    mask_boost: float = 0.2

def _auto_weights_for(cols: int) -> List[float]:
    # simple linear ramp 1..(1+0.1*(cols-1)) -> e.g., 7 cols => [1.0,1.1,1.2,1.3,1.4,1.5,1.6]
    return [1.0 + 0.1*i for i in range(max(cols,1))]

# --------------------------
# Core evidence scan helpers
# --------------------------
_digit_re = re.compile(r"[0-9]")

def _contains_any_token(hay: str, token_set: Set[str]) -> bool:
    # token_set are canonical 3-char combos for an index (e.g., {"056","015","..."}).
    # We scan haystack text “as-is”; upstream should have done any normalization.
    return any(tok in hay for tok in token_set)

def _same_order_straight_seen(hay: str, winner_perm_set: Set[str]) -> bool:
    # If ANY straight perm appears, we consider it “straight clue”.
    return any(p in hay for p in winner_perm_set)

def _masked(text: str, digits_to_remove: Set[str]) -> str:
    if not digits_to_remove:
        return text
    return "".join(ch for ch in text if ch not in digits_to_remove)

# --------------------------
# Public API: compute index scores and straight clues
# --------------------------
@dataclass
class IndexEvidence:
    index: int
    score: float
    ring_hits: Dict[str, List[int]]              # e.g., "Midday.R4" -> [0,0,1,1,0,1,1] hit flags by column
    features: Dict[str, float]                   # named feature contributions
    notes: List[str]

@dataclass
class StraightCandidate:
    index: int
    straight: str
    score: float
    features: Dict[str, float]
    notes: List[str]

@dataclass
class EvidenceBundle:
    indices: List[IndexEvidence]
    straights: List[StraightCandidate]

def compute_evidence(
    grid: GridInputs,
    weights: Optional[EvidenceWeights] = None,
    *,
    digits_to_mask: Optional[Set[str]] = None,
) -> EvidenceBundle:
    """
    Two-pass extractor:
      Pass A: index evidence from R2/R4/R6/R8 progressions with right-column emphasis, hot-zones, stability.
      Pass B: straight clues from order-sensitive hits across sections, with optional masking-support.
    """
    weights = weights or EvidenceWeights()
    digits_to_mask = digits_to_mask or set()

    # Build per-index column hit flags
    index_hits: Dict[int, Dict[str, List[int]]] = {}   # index -> key -> [0/1,...]
    feature_acc: Dict[int, Dict[str, float]] = {}
    notes_acc: Dict[int, List[str]] = {}

    # Prepare column weights per ring
    colw: Dict[str, List[float]] = {}
    for section, rings in grid.columns_by_section_ring.items():
        for ring, cols in rings.items():
            key = ring
            if key not in colw:
                colw[key] = weights.col_weights.get(ring) or _auto_weights_for(len(cols))

    # PASS A — scan for index presence per column
    for section, rings in grid.columns_by_section_ring.items():
        for ring, columns in rings.items():
            ring_key = f"{section}.{ring}"
            wcols = colw[ring]
            for idx in range(1, 36):  # VTRAC indexes 1..35
                canon_set = get_index_set(idx)  # all boxed strings of this index
                # column-wise hits
                hits = []
                for ci, col_text in enumerate(columns):
                    # base check
                    base_hit = 1 if _contains_any_token(col_text, canon_set) else 0
                    # “hiddenbehindadigit” masked check (optional)
                    masked_hit = 0
                    if base_hit == 0 and digits_to_mask:
                        if _contains_any_token(_masked(col_text, digits_to_mask), canon_set):
                            masked_hit = 1
                    hits.append(1 if (base_hit or masked_hit) else 0)

                    # bootstrap notes/features
                    if masked_hit:
                        notes_acc.setdefault(idx, []).append(
                            f"{ring_key} col {ci}: maskedhit via digits {sorted(digits_to_mask)}"
                        )
                        feature_acc.setdefault(idx, {}).setdefault("mask_hits", 0.0)
                        feature_acc[idx]["mask_hits"] += weights.mask_boost

                if any(hits):
                    index_hits.setdefault(idx, {})[ring_key] = hits

                    # feature: weighted column sum
                    s = 0.0
                    for ci, h in enumerate(hits):
                        if h:
                            s += wcols[ci] * weights.ring_gain[ring] * weights.section_gain.get(section, 1.0)
                            # hot-zone bonus
                            if ci in grid.hot_zone_cols.get(section, {}).get(ring, set()):
                                s += weights.hot_zone_bonus
                    feature_acc.setdefault(idx, {}).setdefault("col_weighted_hits", 0.0)
                    feature_acc[idx]["col_weighted_hits"] += s

                    # survival in the last col of this ring?
                    if hits and hits[-1] == 1:
                        feature_acc[idx]["survive_right"] = feature_acc[idx].get("survive_right", 0.0) + weights.survive_right_bonus

                    # repetition chain bonus within this ring (rightward consecutive)
                    chain = 0; max_chain = 0
                    for h in hits:
                        if h: chain += 1; max_chain = max(max_chain, chain)
                        else: chain = 0
                    if max_chain >= 2:
                        feature_acc[idx]["repetition_chain"] = feature_acc[idx].get("repetition_chain", 0.0) + weights.repetition_chain_bonus

    # multi-section stability bonus
    for idx, rings in index_hits.items():
        seen_sections = set(k.split(".")[0] for k in rings.keys())
        if len(seen_sections) >= 2:
            feature_acc.setdefault(idx, {}).setdefault("multi_section", 0.0)
            feature_acc[idx]["multi_section"] += weights.multi_section_bonus

    # accumulate index scores
    index_ev: List[IndexEvidence] = []
    for idx, rings in index_hits.items():
        f = feature_acc.get(idx, {})
        score = sum(f.values())
        index_ev.append(IndexEvidence(index=idx, score=score, ring_hits=rings, features=f, notes=notes_acc.get(idx, [])))

    index_ev.sort(key=lambda x: x.score, reverse=True)

    # PASS B — VTRAC straights clues for top N indices
    straight_ev: List[StraightCandidate] = []
    top_for_straights = index_ev[:12]  # small cap
    for ev in top_for_straights:
        # union of columns by section for order-sensitive clues
        union_by_section: Dict[str, str] = {}
        for key, hits in ev.ring_hits.items():
            section, ring = key.split(".")
            # text blob for this section = concatenate all columns (right has more weight via features already)
            cols = grid.columns_by_section_ring[section][ring]
            union_by_section.setdefault(section, "")
            union_by_section[section] += " || ".join(cols)

        # each boxed combo in this index has 6 straight perms (fewer for doubles)
        # We score straights when the exact order appears in any section blob, with bonuses.
        # Winner perms proxy = perms of each boxed; we aggregate by perm so we don’t duplicate.
        seen_perms: Set[str] = set()
        for boxed in get_index_set(ev.index):
            perms = get_index_straights(boxed)  # unique perms inc. leading zeros
            for p in perms:
                if p in seen_perms:
                    continue
                seen_perms.add(p)

                base = 0.0
                feat: Dict[str, float] = {}
                notes: List[str] = []

                # unmasked and masked checks per section
                hit_any = False
                hit_sections = 0
                for section, blob in union_by_section.items():
                    unmasked = _same_order_straight_seen(blob, {p})
                    masked_ok = False
                    if not unmasked and digits_to_mask:
                        masked_ok = _same_order_straight_seen(_masked(blob, digits_to_mask), {p})

                    if unmasked or masked_ok:
                        hit_any = True
                        hit_sections += 1
                        val = weights.straight_base + (weights.straight_same_order_bonus)
                        feat["hit_"+section] = val
                        base += val
                        if section in grid.hot_zone_cols:
                            feat["hot_"+section] = feat.get("hot_"+section, 0.0) + weights.straight_hot_zone_bonus
                            base += weights.straight_hot_zone_bonus
                        if masked_ok:
                            feat["mask_"+section] = feat.get("mask_"+section, 0.0) + weights.mask_boost
                            base += weights.mask_boost

                if hit_any:
                    if hit_sections >= 2:
                        feat["cross_section"] = weights.straight_cross_section_bonus
                        base += weights.straight_cross_section_bonus
                    straight_ev.append(StraightCandidate(index=ev.index, straight=p, score=base, features=feat, notes=notes))

    straight_ev.sort(key=lambda x: x.score, reverse=True)
    return EvidenceBundle(indices=index_ev, straights=straight_ev)

def load_priors(

    analysis_winners = repo_root / "data" / "outputs" / "analysis" / "winners" / state

    counts_idx: Dict[int, int] = {}

        for day in days:

                    if m:
                        idx = int(m.group(1))
                        counts_idx[idx] = counts_idx.get(idx, 0) + 1
                    # try pick straights listed in logs (simple 3-digit tokens)
                    for tok in re.findall(r"\b\d{3}\b", text):
                        counts_st[tok] = counts_st.get(tok, 0) + 1

    if analysis_winners.exists():
        for f in analysis_winners.rglob("*.json"):
            try:
                obj = json.loads(f.read_text(encoding="utf-8", errors="ignore"))
            except Exception:
                continue
            idx = obj.get("vtrac_index")
            if isinstance(idx, int):
                counts_idx[idx] = counts_idx.get(idx, 0) + 1
            straight = obj.get("winner") or obj.get("straight")
            if isinstance(straight, str) and straight.isdigit() and len(straight) == 3:
                counts_st[straight] = counts_st.get(straight, 0) + 1

    # Convert counts to soft multipliers
    idx_mul = {i: (1.0 + base_boost * c) for i, c in counts_idx.items()}
    st_mul = {s: (1.0 + straight_boost * c) for s, c in counts_st.items()}

    return Priors(index_mul=idx_mul, straight_mul=st_mul)
Why this is safe: It only reads if those folders exist (your roadmap puts the winners JSONs there), returns neutral weights otherwise, and never writes. 

3A3) modules/vtrac_predictor.py — combine evidence + priors; select top candidates
# modules/vtrac_predictor.py
from __future__ import annotations
from dataclasses import dataclass
from typing import List, Dict, Tuple
from pathlib import Path

from modules.vtrac_evidence import EvidenceBundle, IndexEvidence, StraightCandidate
from modules.vtrac_priors import Priors

@dataclass
class PredictionResult:
    indices_ranked: List[IndexEvidence]
    straights_ranked: List[StraightCandidate]

def apply_priors(bundle: EvidenceBundle, priors: Priors) -> PredictionResult:
    # Copy and scale scores
    # Index multipliers
    idx_scaled: List[IndexEvidence] = []
    for ev in bundle.indices:
        mul = priors.index_mul.get(ev.index, 1.0)
        ev_scaled = IndexEvidence(
            index=ev.index,
            score=ev.score * mul,
            ring_hits=ev.ring_hits,
            features={**ev.features, "prior_mul": mul},
            notes=list(ev.notes),
        )
        idx_scaled.append(ev_scaled)
    idx_scaled.sort(key=lambda x: x.score, reverse=True)

    # Straight multipliers
    st_scaled: List[StraightCandidate] = []
    for sc in bundle.straights:
        mul = priors.straight_mul.get(sc.straight, 1.0)
        st_scaled.append(StraightCandidate(
            index=sc.index,
            straight=sc.straight,
            score=sc.score * mul,
            features={**sc.features, "prior_mul": mul},
            notes=list(sc.notes),
        ))
    st_scaled.sort(key=lambda x: x.score, reverse=True)

    return PredictionResult(indices_ranked=idx_scaled, straights_ranked=st_scaled)

def topk(pred: PredictionResult, k_idx: int = 12, k_straights: int = 24) -> PredictionResult:
    return PredictionResult(
        indices_ranked=pred.indices_ranked[:k_idx],
        straights_ranked=pred.straights_ranked[:k_straights],
    )
