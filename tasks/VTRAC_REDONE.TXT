One de‑duplicated, “all parts in one” system (clear mapping)
Below is the consolidated mapping from everything you collected (RESEARCH, REDESIGN, DEEP RESEARCH, FINAL) into a single, non‑overlapping design. It keeps the advanced methods we agreed on and protects the Winners Logger add‑ons (hidden‑behind‑a‑digit clusters, straight identifiers, etc.):

A. Data contracts (modules/vtrac_enhanced/types.py)

Cell { digits: str, hot: bool, superhot: bool }

PatternsGrid { by_r: Dict["R2"|"R4"|"R6"|"R8", List[List[Cell]]] } (7→1 columns, rightmost = most recent)

SectionData { section: "Midday"|"Evening"|"Combined", set_name: "Set1"|"Set2"|"Set3", patterns: PatternsGrid }

EngineInput { sections: List[SectionData], recent_draws: List[str], winner_hint: Optional[int] }

IndexScore { index: int, score: float, reasons: List[str], straights: List[str] }

EngineOutput { ranked: List[IndexScore], telemetry: Dict[str, Any] }

B. Shared signals (modules/vtrac_enhanced/signals.py)

Feature extractors used by both Analyzer and Winners Logger:

Right‑survival: did a (boxed) index’s patterns persist to columns 3/2/1?

Hot/Superhot: boost cells in hot zones; carry this boost into scoring.

Cross‑section echoes: occurrences across Midday/Evening/Combined within nearby columns.

Masked (hidden) clusters: detect 3‑value patterns hidden inside 4‑value clusters (your “behind a digit” aid). This is pulled from your logger upgrade and generalized.

Mirror/matrix touches: classic mirror family adjacency you’ve documented.

Permutation cues: signs that a straight order is favored (e.g., “241→…→916” style alignments).

Recency signal: soft penalty for indices that just hit; soft bonus for neighbors (family group) that often rotate in.

Volatility: if strings are turbulent (many changes left→right), reduce reliance on early columns.

C. Scoring (modules/vtrac_enhanced/scoring.py)

Composable, explainable, and weight‑tunable:

base_frequency(index) – counts across R2/R4/R6/R8 & sections.

late_column_weight(index) – exponential boost to columns 3/2/1, with superhot bonus.

cross_section_cohesion(index) – coherence across sections (Midday/Evening/Combined).

masked_cluster_bonus(index) – add points if the index is present as a masked/hidden 3‑value within 4‑value clusters.

straight_order_bias(index) – increase when straight cues appear consistently.

recency_rotation(index) – discourage immediate repeats, encourage family rotation.

Combine via:
S(index) = w_ffreq + w_llate + w_ccohesion + w_mmasked + w_sstraight + w_rrecency + …

All weights live in a single dict so you can tune without code edits.

D. Straights (modules/vtrac_enhanced/straights.py)

Pulls from modules/vtrac_reference.py / vtrac_straight_map.py.

Given a top index and permutation signals, return up to 8 V‑TRAC straights ordered by likelihood.

E. Engine (modules/vtrac_enhanced/engine.py)

Orchestrates: build index→evidence map from signals, score in scoring, and attach straights.

Emits: top‑N indexes + explanations.

Exposes one function: run_analysis(input) -> output.

F. UI wiring (keep file, small diff) (src/core/module_c_vtrac.py)
