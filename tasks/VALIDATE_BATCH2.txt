4. On “cache” / Streamlit warnings

Those “No runtime found, using MemoryCacheStorageManager” warnings from Streamlit during CLI runs are per‑process memory caches. You’re invoking the scripts via python3 ... each time, so:

Each run is a fresh Python process.

Any in‑memory cache is discarded at process exit.

There is no persistent cache to “clear” between dates.

So as long as you:

Activate the correct workbook, and

Run the CLI scripts in that order,

you’re not carrying stale data across runs.
