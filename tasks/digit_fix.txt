Implement a “nested persistence index” = count of how many reduction levels a pattern cluster survives (A → E → T).

3. V-Trac Synergy Boost

Create a vtrac_confluence_score:
Measure when multiple digits from one R2 cluster belong to the same V-Trac family.
Use: add as a feature in top_candidates.csv to surface “family-reinforced” patterns.

Add a cross_variant_reinforcement_flag:
If the same cluster occurs in both Midday and Evening reductions (even different boxes), boost its score slightly.

Replace linear weighting with a tanh-normalized scoring curve.
Why: prevents runaway scores for overly repetitive patterns but still rewards stability.

Add bonus gating:

weight if earliest_vtrac_step ≤ 2

weight if cluster_persistence_score ≥ 3

Add penalty gating:

− weight if a pattern appears in > 4 different methods (noise saturation)
