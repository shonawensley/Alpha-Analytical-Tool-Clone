A. Add a dedicated draws loader (CSV‑first, with safe XLSX fallback)

Create: modules/aux_loaders.py

# modules/aux_loaders.py
from pathlib import Path
import pandas as pd

# Optional alias map if UI labels don't match filenames exactly
ALIASES = {
    "OntarioCanada4": "OntarioCanada4",
    "OntarioCanada": "OntarioCanada",
    "Connecticut4": "Connecticut",
    "Connecticut": "Connecticut",
    # add more if your menu label differs from filename stem
}

def _stem(label: str) -> str:
    s = (label or "").strip()
    return ALIASES.get(s, s)

def load_state_draws(state_label: str, base: Path | None = None, max_n: int = 1000) -> list[str]:
    """
    Returns newest-first draws like ['531','890','861',...].
    Preferred source: data/cleaned/<stem>_draws.csv
    Fallback: derive from <stem>_cleaned.xlsx if CSV missing.
    """
    base = base or Path("data") / "cleaned"
    stem = _stem(state_label)

    # 1) CSV candidates (with/without '4' suffix tolerance)
    candidates = [
        base / f"{stem}_draws.csv",
        base / f"{stem.replace('4','')}_draws.csv" if "4" in stem else base / f"{stem}4_draws.csv",
    ]
    for p in candidates:
        if p.exists():
            df = pd.read_csv(p)
            col = df.columns[0]
            return (
                df[col]
                .astype(str)
                .str.replace(r"\D", "", regex=True)
                .str.zfill(3)
                .tolist()
            )[:max_n]

    # 2) XLSX fallback (not preferred, but prevents crashes)
    xlsx_candidates = [
        base / f"{stem}_cleaned.xlsx",
        base / f"{stem.replace('4','')}_cleaned.xlsx" if "4" in stem else base / f"{stem}4_cleaned.xlsx",
    ]
    for p in xlsx_candidates:
        if p.exists():
            df = pd.read_excel(p, engine="openpyxl")
            for cand in ("Draw", "draw", "Number", "numbers", "draws"):
                if cand in df.columns:
                    return (
                        df[cand]
                        .astype(str).str.replace(r"\D", "", regex=True)
                        .str.zfill(3).tolist()
                    )[:max_n]
    return []


Why: Blackapple’s analyzer takes only a draw list, nothing else. For correctness and simplicity, we explicitly prefer *_draws.csv. If it’s missing, we try to mine draws from the Excel so the UI never hard‑crashes, but CSV is the intended source for BA.

Why this solves your symptom

The BA analyzer computes a few simple draw‑based triggers (mirror event, longest‑out root sum, spike/trough gaps, floating digits, and a 27–29 remaining‑pairs foundation). It expects only the last N draws for the state; if we hand it the wrong file (combined XLSX), it sees no draws and the panel stays empty. By forcing a CSV‑first loader, we remove that entire class of failures.

The Combined page error was import hygiene: on some launches/hot‑reloads Streamlit wasn’t seeing the repo root on sys.path, so modules.blackapple wasn’t importable. Making modules a package, bootstrapping sys.path once at app entry, and retrying the import where it’s used removes this brittleness.

(Optional) One more safety net

If your state labels sometimes differ (e.g., menu shows “OntarioCanada” but the CSV is OntarioCanada4_draws.csv), add one line per mismatch in the ALIASES dict in aux_loaders.py. That will keep BA robust even if labels and filenames drift.
