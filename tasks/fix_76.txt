🔧 Minimal, robust footer I recommend

Drop this at the very bottom of src/app.py (beneath all code). It covers entrypoint + a safe “rescue boot” so you’re never blind again:

# ---------------------- BOOTSTRAP (keep at end) ----------------------
def _rescue_boot():
    import streamlit as st
    st.set_page_config(page_title="Alpha-Final Analytical Tool", layout="wide")
    st.title("Alpha-Final Analytical Tool")
    st.write("✅ App booted via rescue path. If you see this, main() wasn’t called or raised.")

try:
    # Optional: dev overlay import stays non-fatal at import time
    try:
        from alpha_analytical.digit_reduction.analyzer_v2.ui_dev import render_dr_winner_overlay_dev
    except Exception as _import_exc:
        render_dr_winner_overlay_dev = None
        DEV_OVERLAY_IMPORT_ERROR = _import_exc

    # Normal entry
    if __name__ == "__main__":
        try:
            main()   # or show_app()/run_app() – whichever is your router
        except Exception as e:
            _rescue_boot()
            import streamlit as st
            st.error(f"main() raised: {e}")
except Exception as boot_exc:
    # Absolute last resort: still show a page
    _rescue_boot()
    import streamlit as st
    st.error(f"boot error: {boot_exc}")

⚠️ Two easy pitfalls to avoid

Don’t put st.* calls at top-level (i.e., at import time). Keep all UI calls inside page functions or main().

Stay ASCII in code for UI labels (e.g., " - " instead of an em-dash " — ") to avoid shell/encoding surprises later.

If you add the footer above and keep the optional import pattern, the blank page should disappear—and you’ll have a guard if anyone ever breaks the entrypoint again.
