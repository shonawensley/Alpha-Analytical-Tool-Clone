You’re right to be cautious—this was a small change hidden in a haystack. The short version is: the September cleanup archived the legacy V‑TRAC reference that Aux still depends on, and Aux sometimes ends up importing the canonical (slimmed) modules.vtrac_reference instead of the staged/legacy one. That’s why you see cannot import name 'VTRAC_DISPLAY' / missing BOXED_LABEL_LOOKUP and why Aux falls back to “empty” results (e.g., “No state data files found”). This matches Codex’s diagnosis and lines up with the app wiring described in your AAT9 docs (Aux runs from staged modules and draws CSVs; non‑Aux pages use the canonical API and the combined tables) .

Below is an execution plan that fixes Aux immediately without breaking Winners Full / V‑TRAC / Digit Reduction—and adds guardrails so this doesn’t happen again.

0) What broke & why it was hard to spot

Two V‑TRAC surfaces exist by design:

Canonical API at modules/vtrac_reference.py used by non‑Aux pages (Winners Full, etc.). During cleanup it was slimmed and no longer exports VTRAC_DISPLAY / BOXED_LABEL_LOOKUP. This is intentional. Winners Full still works with it.

Aux staged stack under scripts/auxiliary/working/modules/... still expects the richer legacy reference (with the boxed constants). Some imports inside Aux (e.g., late imports inside analyze_pairs) slipped to the canonical one at runtime or couldn’t find the legacy one after it was archived, producing the errors you’re seeing. Aux is the only page affected.

Path/data was a red herring. Aux and Control Center consume data/cleaned/*_draws.csv (or data/cleaned/draws/* if you moved them), while V‑TRAC/Stable/DR consume the combined tables. That split is documented, and Dev Health was added exactly to make these issues visible (cwd, python path, module __file__, and CSV locations). The “draws vs cleaned” confusion isn’t the root cause here.

1) Decision you should make (copy vs link)

We have two clean options to restore Aux:

Option A — Restore a copy of the legacy vtrac_reference.py back to the tree where Aux expects it (the pre‑cleanup core_legacy/legacy_modules_backup path). Fastest, least risky. Keeps Aux self‑contained; minimal changes to code.

Option B — Keep archive, adjust bootstrap so Aux imports the legacy reference from archived/vtrac_refs/…. Avoids duplication, but requires a small bootstrap change and careful path handling.

Given you want the safest path and you’re in checkpoint mode, I recommend Option A now, then do Option B later when things are calm.

A2. Make Aux bootstrap resilient (so future cleanups can’t break it)

Open modules/module_d_auxiliary_tools/refactored/bootstrap_imports.py (or the helper your refactored Aux code uses to load legacy bits) and replace its “legacy import” block with this dual‑path resolver:

# modules/module_d_auxiliary_tools/refactored/bootstrap_imports.py
from pathlib import Path
import sys, importlib

def import_legacy_vtrac_reference():
    repo = Path(__file__).resolve().parents[3]  # <repo>/modules/module_d_auxiliary_tools/refactored/...
    # 1) Preferred: core_legacy/legacy_modules_backup (staged copy restored by Option A)
    core_legacy = repo / 'module_d_auxiliary_tools' / 'core_legacy' / 'legacy_modules_backup'
    # 2) Fallback: archived/vtrac_refs (post‑cleanup archives)
    archived = repo.parents[2] / 'archived' / 'vtrac_refs'  # <repo>/archived/vtrac_refs

    # Try both locations without leaking them globally
    for base in (core_legacy, archived):
        vr = base / 'vtrac_reference.py'
        if vr.exists():
            sys.path.insert(0, str(base))
            try:
                mod = importlib.import_module('vtrac_reference')
                return mod  # has VTRAC_DISPLAY, BOXED_LABEL_LOOKUP, etc.
            finally:
                # remove the temp path so we don't affect other pages
                try: sys.path.remove(str(base))
                except ValueError: pass

    raise ImportError("Legacy vtrac_reference.py not found in core_legacy or archived/vtrac_refs")


…and in refactored/boxed_vtrac.py (or the site that uses the boxed data):

from .bootstrap_imports import import_legacy_vtrac_reference

# Safely obtain the legacy reference (boxed constants)
_legacy_vr = import_legacy_vtrac_reference()
VTRAC_DISPLAY       = getattr(_legacy_vr, 'VTRAC_DISPLAY')
BOXED_LABEL_LOOKUP  = getattr(_legacy_vr, 'BOXED_LABEL_LOOKUP')
get_vtrac_index     = getattr(_legacy_vr, 'get_vtrac_index', None)


This keeps Aux aligned with the legacy boxed constants regardless of future archiving.
