6) The “Stacked view” toggle blanks the page

That checkbox renders the big HTML report (*_digit_reduction_report_stacked.html). A blank after clicking usually means an exception during HTML load, and Streamlit quietly re-runs the page (so you jump back up).

Most common causes:

The HTML path is wrong or file missing (case differences, state string).

Encoding/escape issue on st.components.v1.html(...).

An exception is swallowed by a broad except: pass around the render.

Fix pattern (wrap & log):

import streamlit as st
from pathlib import Path
from streamlit import components

if st.checkbox("Stacked view (show all methods)", value=False):
    try:
        p = Path("data/outputs/analysis/digit_reduction") / state / f"{state}_digit_reduction_report_stacked.html"
        html = p.read_text(encoding="utf-8")
        components.v1.html(html, height=1200, scrolling=True)
    except FileNotFoundError:
        st.error(f"Stacked HTML not found: {p}")
    except Exception as e:
        st.exception(e)  # don't swallow: show the error so we can fix fast


If you still bounce back to the top, this will show the actual error instead of a silent re-run.
