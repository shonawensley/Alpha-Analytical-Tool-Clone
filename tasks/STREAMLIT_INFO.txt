Short answer on the app issue:
What you’re seeing in the screenshot is just a small URL typo / address mismatch between what Streamlit is actually serving and what your browser is trying to open. The good news is: your app is running; the browser is just pointed at the wrong address string.

Let me walk through both pieces you raised:

1. Why http://0.0.0.0:8501 “can’t be reached”

From your screenshots:

The command window shows:

Starting Streamlit on http://localhost:8501 ...
URL: http://0.0.0.0:8501


Chrome is trying to open http://0.0.0.0:8501/ and gives ERR_ADDRESS_INVALID.

This is expected: 0.0.0.0 is a bind address, not a real host you browse to on Windows. On WSL/Streamlit side it means “listen on all interfaces”.

On your Windows browser you should always use:

http://localhost:8501

or

http://127.0.0.1:8501

So, with your current setup:

Run the app (from Windows CMD or PowerShell in the repo root):

run_streamlit.bat


In Chrome, manually type (or update the existing tab URL to):

http://localhost:8501


If you see the purple 0.0.0.0:8501 in the URL bar again, just overwrite it with localhost.

That’s all — nothing special about Chrome vs Edge; any browser is fine as long as the host is localhost, not 0.0.0.0.

2. That run_streamlit.bat file and how to use it

Codex created this BAT in the repo root:

@echo off
REM Launch the Streamlit app from the repo root.
REM Uses explicit pushd to avoid CWD mistakes.

pushd "%~dp0"

set PORT=8501
set STREAMLIT_BROWSER=none

echo Starting Streamlit on http://localhost:%PORT% ...
streamlit run src\app.py --server.address 0.0.0.0 --server.port %PORT%

popd

How to run it

From Windows Explorer

Double-click run_streamlit.bat in the repo root.

A CMD window will open and show something like:

Starting Streamlit on http://localhost:8501 ...
You can now view your Streamlit app in your browser.


Then open http://localhost:8501 in your browser.

From CMD / PowerShell

cd \\wsl.localhost\Ubuntu\home\ser\code\Alpha-Analytical-Tool-Clone
run_streamlit.bat

How to stop it

If you started it via the BAT: just close that CMD window.

If you started it in WSL directly: run in WSL:

pkill -f "streamlit run src/app.py"
