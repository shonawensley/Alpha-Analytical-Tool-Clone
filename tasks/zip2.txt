“SharePack v1” — a simple, dependable packaging spec
Name
<tool>_<state>_<workbookdate>_pack1.zip
Example: stable_CT_2025-06-23_pack1.zip. (Dates tie to your history/results pairing.)

Daily workbook dates pair to the next day’s results file under data/results/YYYY-MM-DD.txt. (user: Data Validation Workflow, “Pick3 workbook history & results mapping,” bullets 1–3)

Layout (at the archive root; no wrapper folder):
README.txt
manifest.json
stable/           # tool outputs (CSV, compact JSON; minimal HTML if needed)
winners/          # any winners overlays/flags used for the review
config/           # the YAML/JSON weights used for the run (if applicable)

Do not include: any training_sets/… duplicates or large diagnostics unless explicitly requested.

Exact commands Codex can run to build SharePacks (no placeholders)

Rule of thumb: run the archive command from inside the run folder you want to share, so the archive root contains the files directly.

Windows PowerShell

Set-Location "C:\path\to\Alpha-Analytical-Tool-Clone\reports\stable\2025-06-23_CT_packet1"

Repository script (drop‑in) — builds both archives + manifest
Save as scripts/tools/build_sharepack.py and run as shown below.
#!/usr/bin/env python3
import argparse, hashlib, json, os, tarfile, zipfile, time
from pathlib import Path

def sha256_file(p: Path) -> str:
    h = hashlib.sha256()
    with p.open('rb') as f:
        for chunk in iter(lambda: f.read(1 << 20), b''):
            h.update(chunk)
    return h.hexdigest()

def build_zip(src_dir: Path, out_zip: Path):
    with zipfile.ZipFile(out_zip, 'w', compression=zipfile.ZIP_DEFLATED) as z:
        for p in src_dir.rglob('*'):
            if p.is_file():
                z.write(p, p.relative_to(src_dir))

def build_targz(src_dir: Path, out_tgz: Path):
    with tarfile.open(out_tgz, 'w:gz') as t:
        t.add(src_dir, arcname='.')

def write_manifest(src_dir: Path, dest: Path, meta: dict):
    files = []
    for p in sorted(src_dir.rglob('*')):
        if p.is_file():
            files.append({"path": str(p.relative_to(src_dir)).replace("\\","/"),
                          "sha256": sha256_file(p)})
    meta = {**meta,
            "created_utc": time.strftime('%Y-%m-%dT%H:%M:%SZ', time.gmtime()),
            "files": files}
    dest.write_text(json.dumps(meta, indent=2))

def main():
    ap = argparse.ArgumentParser()
    ap.add_argument('--run-dir', required=True, help='Folder to package (cd into this in the archives)')
    ap.add_argument('--out-stem', required=True, help='Output stem, e.g., artifacts/stable_CT_2025-06-23_pack1')
    ap.add_argument('--tool', required=True)
    ap.add_argument('--state', required=True)
    ap.add_argument('--workbook-date', required=True)
    ap.add_argument('--results-date', required=True)
    args = ap.parse_args()

    run_dir = Path(args.run_dir).resolve()
    run_dir_exists = run_dir.exists()
    if not run_dir_exists:
        raise SystemExit(f"Run dir not found: {run_dir}")

    # optional: prune duplicates
    dup = run_dir / 'training_sets'
    if dup.exists():
        for root, dirs, files in os.walk(dup, topdown=False):
            for name in files: Path(root, name).unlink()
            for name in dirs: Path(root, name).rmdir()
        dup.rmdir()

    out_zip = Path(args.out_stem + '.zip').resolve()
    out_tgz = Path(args.out_stem + '.tar.gz').resolve()
    build_zip(run_dir, out_zip)
    build_targz(run_dir, out_tgz)

    manifest = {
      "tool": args.tool,
      "state": args.state,
      "workbook_date": args.workbook_date,
      "results_date": args.results_date
    }
    write_manifest(run_dir, Path(args.out_stem + '.manifest.json'), manifest)
    print(f"wrote: {out_zip}\n      {out_tgz}\n      {args.out_stem+'.manifest.json'}")

if __name__ == '__main__':
    main()
