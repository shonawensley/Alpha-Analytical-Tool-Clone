6) The real fix (once you confirm CRLF churn): .gitattributes

If you confirm line-ending churn, the clean solution is to enforce LF at repo level.

Create or update .gitattributes at repo root:

*.py  text eol=lf
*.md  text eol=lf
*.txt text eol=lf
*.json text eol=lf
*.csv text eol=lf


Then renormalize (start small to avoid a massive commit):

git add --renormalize briefings docs .codex
git status -sb


If that looks good, commit it. If it explodes into thousands of changes, stop and we’ll narrow it further. (Unverified; depends on current repo state)
