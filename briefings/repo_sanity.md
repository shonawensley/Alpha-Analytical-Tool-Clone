# Repo Sanity (operator + Codex)

Codex:
- Print:
  - git status -s
  - git branch -vv
  - git remote -v
- Confirm origin is exactly:
  https://github.com/shonawensley/Alpha-Analytical-Tool-Clone.git
- If not, STOP and tell the operator.

Operator (Desktop):
- If remote is wrong: Repository → Repository settings → Remote → set to the Clone URL.
- All commits/pushes are done via GitHub Desktop.
