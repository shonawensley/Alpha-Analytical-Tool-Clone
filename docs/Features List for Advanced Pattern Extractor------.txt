Below is a summary of the “features” that our comprehensive pattern extractor module produces (and could be extended with additional helper functions), along with a brief description of each and how they integrate into the overall system (including feeding into the ML module). This summary also highlights additional optional functions that could further enrich the feature set.

Extracted Feature List from the Pattern Extractor

Vertical Cluster Stability (VCS)

Definition: Measures how many of the R‑rows (R2, R4, R6, R8) contain the candidate pattern.
Purpose: A high VCS indicates that the candidate is “stable” vertically across different reduction levels, suggesting a strong underlying structure.
ML Use: Acts as a numerical feature indicating the consistency of the pattern across vertical segments.

Vertical Straight Repeat (VSTR)

Definition: A bonus score given when the candidate appears in exactly the same order in multiple vertical positions.
Purpose: Reinforces that a pattern is not only present but repeated identically, which is a very strong signal.
ML Use: Provides a binary/numeric indicator that the pattern is “straight” vertically.

Horizontal Straight Repeat (HSR)

Definition: Counts the number of columns (from left to right in a given row) where the candidate appears in exactly the same order.
Purpose: Confirms that the candidate is repeated in a consistent order across adjacent columns.
ML Use: As a feature, a higher HSR score increases the confidence that the candidate is significant.

Horizontal Boxed Repeat (HBR)

Definition: Measures if the candidate appears in adjacent columns in different orders (the digits are the same, but the order varies).
Purpose: Captures “boxed” repeats, where the order might change but the digit set is preserved.
ML Use: Acts as a secondary indicator, adding value when the candidate is found in multiple “boxed” forms.

Special 3‑Value (S3V) Bonus

Definition: An additional bonus applied when a candidate is the sole surviving 3‑value cluster (i.e. the only candidate in a “hot zone” area of the chart).
Purpose: Highlights patterns that stand alone in key “hot” areas, suggesting they are not diluted by noise.
ML Use: This bonus boosts the overall score for candidates that dominate in critical areas, making them more likely to be chosen.

Consensus C1-2 Bonus (CC)

Definition: A bonus if the candidate appears in the consensus columns (the final two columns of the combined chart).
Purpose: Since consensus in these columns is a strong predictive indicator, candidates that appear here get extra weight.
ML Use: Provides a direct signal of high confidence based on consensus across the chart.

Permutation Bonus (PB)

Definition: A bonus for candidates whose sorted (i.e. “boxed”) version is found repeatedly across the R‑rows, even if the order varies.
Purpose: Captures additional stability through permutation; it shows that even if the candidate is re-ordered, its core digit set remains.
ML Use: Adds an extra numeric value to the feature vector, highlighting the candidate’s robustness.

Raw Candidate Pattern (RCP)

Definition: The candidate substring extracted from the input strings (after cleaning markers like [V], [W], or * are removed).
Purpose: This is the baseline pattern that all features are built upon.
ML Use: Can be encoded (e.g., via one-hot or embedding) to feed into the model as part of the raw input.

VTrac Transformation (VT)

Definition: The candidate pattern transformed via a VTrac mapping (e.g., 1↔6, 2↔7, etc.).
Purpose: Helps the system recognize equivalent patterns that might appear different at first glance.
ML Use: Either used directly as a separate feature or compared with the original candidate to capture mirror relationships.



Additional Optional Helper Features

Hot & Cold Digit Counts:

• Hot Digits: Frequencies of digits that appear frequently in the candidate patterns (e.g., 4, 6, 8 in many of your examples).
• Cold Digits: Digits that rarely appear.
Purpose: These can help adjust the candidate’s score based on whether its digits are “hot” or “cold.”
Integration: Can be added to the ML feature vector as additional numerical features.

Positional Analysis:

• Tracks the positions of key digits within each candidate (e.g., if the candidate’s core digits always appear at the rightmost positions of the box).
Purpose: Positional consistency may correlate with predictive strength.
Integration: Numerical values indicating average positions, which are fed to the ML model.

Frequency and Delay Metrics:

• How often does a candidate (or its variations) appear over historical draws, and what is the “delay” since its last appearance.
Purpose: Indicates if a candidate is “due” based on historical frequency.
Integration: As features that can help the ML module adjust probabilities.

Due Pairs / Grouping Counters:

• Tracks whether certain candidate clusters (or pairs) are “due” for a hit.
Purpose: To capture cyclical or repetitive behavior in the draw data.
Integration: Can be used as time-series features within the ML model.

Feeding Into the ML Module

Feature Vector Construction:
The output of the pattern extractor is a DataFrame where each row represents a candidate pattern along with its computed features (VCS, VSTR, HSR, HBR, S3V, CC, PB, etc.).
This DataFrame is then used to build a feature vector for each candidate.
Categorical features (e.g., raw candidate pattern) may be encoded via one-hot encoding or embeddings, while numerical features (e.g., VCS score) remain as is.

Model Training:

Historical draw data (with known outcomes) is used to label candidate patterns as “hit” or “miss.”
The ML module (e.g., a Random Forest or Gradient Boosting model) is then trained on the feature vectors to learn which combinations of features correlate with hits.

Continuous Learning:

As new draws occur, the system updates the historical database, recalculates feature vectors, and retrains or incrementally updates the model.
Adaptive feedback loops can adjust feature weights based on the model’s performance over time.

How the System Extracts 3-Value Clusters

Sliding Window Extraction:
The extractor scans each string (from columns 7 through 1) using a sliding window to identify all contiguous substrings of length three or more.

Stability Check:
It then checks these candidate substrings for “stability” – that is, whether they consistently appear across multiple rows (R2, R4, R6, R8) or across multiple boxes (horizontally).
A candidate that persists in several areas (e.g., it appears in R2 and R4 and is repeated horizontally) gets a higher base score.

Transformation and Matching:
The candidate is also transformed using the VTrac mapping. If its transformed (mirrored) version appears, that increases the candidate’s score because it indicates a hidden match.

Aggregation:
All these factors are summed into a total score for the candidate. This score reflects how “stable” and “promising” the candidate is as a predictor.

It combines multiple perspectives: vertical consistency, horizontal repetition (both exact and boxed), VTrac transformations, and consensus information.
This multi-angle approach is designed to capture subtle signals that might be missed by simpler extractors.

The system is built in clearly defined modules (pattern extraction, digit reduction, etc.), making it easier to adjust, test, and optimize each component independently.

Adaptive and Learnable:
By generating a rich feature vector from the extracted patterns, the system provides the ML module with detailed information from which it can learn and adapt over time.
This means that as more draw data accumulates, the ML model can adjust the weights of these features to improve predictive accuracy.

Integration of Advanced Concepts:
The system leverages VTrac/mirror relationships and consensus patterns, concepts that are known to be strong indicators in lottery analysis, thereby giving it an edge over simpler methods.

Diversification and Profitability Focus:
The extractor does not only count a candidate’s occurrence—it also differentiates between straight repeats and boxed repeats, identifies “special” patterns in hot zones, and aggregates multiple scoring dimensions.
This means it’s not overfitting to one type of pattern but rather providing a diversified set of candidate features for profitable combination formation.

Summary
The pattern extractor module produces a comprehensive set of features including vertical stability, horizontal repeats (both straight and boxed), special cluster bonuses, consensus column bonuses, permutation bonuses, and VTrac transformations.
These features are designed to capture both the stability and variability of 3‑value clusters across different parts of the combined table.
The output (a feature-rich DataFrame) feeds into the ML module where each candidate pattern is labeled based on historical hit/miss outcomes.
Additional helper functions (hot & cold digits, positional analysis, frequency/delay, due pairs) can be integrated later to enrich the feature vector.
This system is improved because it incorporates multiple analytical dimensions, is modular, and is designed to learn adaptively—ultimately leading to a more robust, profitable, and data-driven prediction model.
