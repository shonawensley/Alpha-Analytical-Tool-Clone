# Module A: Stable Pattern Extractor

**Purpose**  
This module scans the **R2/R4/R6/R8** structures in the combined CSV tables (Midday, Evening, Combined) to find stable 3–6 digit patterns. It awards "stability" points for:

- **Vertical coverage** (appearing in multiple row types at once),
- **Horizontal coverage** (persisting across columns 7..1),
- **Mirror elimination** (optionally ignoring digits used in the prior row's data),
- **Consensus columns** (where R2=R4=R6=R8 are all identical).

**Inputs**  
- The CSV tables generated by `generate_tables_pipeline.bat`, typically in `data/outputs/tables/[STATE]/Midday_combined.csv` or `Evening_combined.csv`.
- Python environment with Pandas.

**Outputs**  
- A dictionary or JSON like:
  ```json
  {
    "695": {
      "canonical": "569",
      "vtrac": "2??",
      "locations": [("R2", 7), ("R4", 7)],
      "score": 27,
      "score_breakdown": {
        "vertical_coverage_col7": 4,
        "mirror_elimination": 2,
        "consensus_col7": 5
      },
      "stable_after_reduction": false,
      "lingers_across_boxes": true
    },
    "8132": {
      "canonical": "1238",
      "vtrac": "1234",
      "locations": [("R2",5),("R2",4),("R6",5)],
      "score": 18,
      "score_breakdown": {},
      "stable_after_reduction": false,
      "lingers_across_boxes": false
    }
  }
  ```
You can store it as `stable_patterns.json` or a Python dictionary.

### Stable Pattern Detection

- Parse R2, R4, R6, R8 from each row in columns 7..1.
- Identify 3-value or 3–6 digit combos that appear repeatedly.
- Optionally, detect "mirror elimination" (omitting digits from the prior row).
- Score them with:
  - `vertical_coverage` (+2 points per row repeated),
  - `horizontal_adjacency` (+2 points if same pattern appears across adjacent columns),
  - `consensus_col` (if all four row types match, +5),
  - plus any extra weighting.

### Scoring & Output

Summarize each discovered pattern, record:
- `score`
- `score_breakdown`
- `locations`
- `canonical`
- optional: `stable_after_reduction = False` (since we haven't done digit removal).

Store results in a dict or JSON file.

## CLI Usage
If you wrap this in a script `stable_pattern_extractor.py`, you might run:

```bash
python stable_pattern_extractor.py --state=Florida4 --output=stable_patterns.json
```
Or via a Streamlit UI. Final file goes in `data/outputs/analysis/stable_extractor/`.

## Configuration Knobs

- `vertical_repeat_bonus`: how many points to give per repeated row type.
- `horizontal_adj_bonus`: synergy if a pattern crosses multiple columns.
- `mirror_elimination_bonus`: for patterns disjoint from prior row's digits.
- `consensus_col_bonus`: if R2/R4/R6/R8 are identical in that column.

## Sample Score Table

| Factor                 | Default Points        |
|------------------------|-----------------------|
| Vertical coverage      | 2 per row repeat      |
| Horizontal adjacency   | 2 per adjacent col    |
| Mirror elimination     | 2                     |
| Consensus col          | 5                     |
| Extended length (≥4)   | 1 per extra digit     |
