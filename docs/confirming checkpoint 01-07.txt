Key Updates
1.	Stable Pattern Extractor v1.0.0 (Frozen) – The Stable Pattern logic is now consolidated and versioned as a frozen module. The authoritative extractor code (previously in various older scripts) has been packaged under alpha_analytical.stableGitHub. 2.	Unified Streamlit App – We now have a single front-end (src/app.py) that provides a sidebar with five tabsGitHub: V-TRAC Analyzer, Stable Pattern Extractor, Digit Reduction, Hot Zones, and Control Center. All core modules run inside this app, leveraging one shared data pipeline. The app sets the page config once (at startup) to avoid conflictsGitHub, and uses lazy-loading imports for each tab to prevent any module from executing out of turnGitHubGitHub. The V-TRAC Analyzer tab retains the full functionality of the enhanced Streamlit analyzer (with table generation, top-3 predictions, bulk winner logging, JSON outputs, etc.), now embedded in the unified app. The Digit Reduction tab wraps the long-string reduction methods A–E & T with the same results as the prior standalone version. V-TRAC continues to output JSON prediction files (capped at top-3 results) to data/outputs/predictions/ and daily winner logs to data/outputs/winners_json/ and bundle files to data/outputs/bundles/ (unchanged behavior from earlier version). 5.	Minor Feature Enhancements – In the course of final integration, a few analytical tweaks were introduced to improve prediction quality and consistency:
o	Hot-Zone Decay: Incorporated logic to handle “hot” markers (* and **) with a decay factor so that older hot-zone hits contribute less weight. This prevents stale hot patterns from skewing results over time.
o	Stricter Single-Digit Rule: Adjusted the Stable Pattern scoring to enforce the “single_left” rule more strictly (patterns that reduce to a single digit are handled according to the latest spec, preventing misclassification).
o	3-Value V-TRAC Check: The V-TRAC analyzer now ensures that any suggested combo covers at least 3 distinct digit values (filtering out trivial or overly narrow predictions). This adds a safety check to the V-TRAC top picks.
o	Straight Tie-Break Adjustment: Improved the tie-break logic for straight predictions in cases where scores are equal, using an additional criterion (e.g. sequence order or occurrence recency) to decide which straight pick to favor.
