Pattern Recognition
the pattern you are looking for inlcude:
-3 unique digit patterns (ex. 567, 123, 471 etc.)
-2 unique digit pattern that form doubles (ex. 244, 566, 133 etc.)
-3 unique digit patterns that might include the digits extending (ex. instead of just 316 also 331116, or 5663, 47788)
-related stable vtrac patterns in string r2/r4/r6/r8 (ex. 590, 045, 54455 = same vtrac)
-vtrac stable patterns are very important and very strong indicator for upcoming winning pattern.
-3 value patterns that survive until  the end of string groupings of r2/r4/r6/r8 so column 3/2/1 are string indicators and should be tracked, are there 3 digit patterns that survive as the only remaining 3 value pattern in these final columns?
- does the same 3 value patterns repeat in the next r2/r4/r6/r8 groupings/structures (ex. from set3 draw to set2 draw 1)  near the end of strings? this is what i mean by "3 digit repeat"

-we look for stable pattern straight/exact order (ex. 613, 613,613) that persist and repeat in addition to boxed any order (816,618,186 etc.).

- we look for stable patterns in ORDER that have vtrac relations somtimes called v-trac STRAIGHT (ex. 781 and 286 are same order v-trac = v-trac straight)

- we evaluate if these patterns are stable vertically within r2/r4/r6/r8 boxes and how they progress and persist horizontally across columns to the right as digits are eliminated. Each column progressively to the right involves more digits being eliminated and represents a new box of r2/r4/r6/r8 string patterns to evaluate vertically within the box.
- we look for repeating patterns, stable patterns, persisting patterns, vtrac patterns
-we look for strong patterns that relate across Midday/evening/combined usually v-trac is a very strong indicator, the more patterns that connect across tables the better
- we look for repeating, stable, persistent patterns in hot zones and that relate across Midday, Evening, Combined

the r2 table
- represents r2 strings taken form r2/r4/r6/r8 boxes/columns that are further to the left /outer columns which are longer and represent an alternative pattern cateogry/choice to extract the upcoming winning patterns.
-the winning patterns can usually be found via patterns progression of r2/r4/r6/r8 or through the longer strings. The idea being to diversify pattern selections as both methods are very effective.
- the r2 table contains a collection of these longer string area's and should be evaluated for persistant patterns and v-trac patterns.
- we also pair this with digit reduction by eliminating past draw digits and their mirrors (ex. previous winning combination is 814 and vtrac is 369 therefore we consider removing past draw digits either alll or one transit digit at a time to see which patterns persist in the r2 table)
