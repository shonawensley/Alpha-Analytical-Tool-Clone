Positional Due Index (PDI) — core features

For each variant (M/E/C) and position (P1–P3), compute:

Draws‑Since (DS) for digits 0–9 at that position, ranked (Top‑3 surfaced).

Rank Pressure (RP): points for being rank #1/#2/#3, scaled by DS gaps (a #1 that’s far ahead of #2 gets extra weight).

Cross‑Variant Boost (CVB): if the same digit is Top‑k in the same position across two variants (e.g., P2 in Midday and Combined), add weight. If it’s Top‑k in all three, add a small multiplicative bump (“Golden Rule” compounding).

Recent‑Heat Brake (RHB): if a Top‑k digit just hit in the last X draws anywhere at that position (e.g., ≤2–3 draws), smoothly taper its weight to avoid over‑chasing fresh hits.

V‑Trac Synergy (VTS): convert each candidate’s digit to its V‑Trac class (0/5, 1/6, 2/7, 3/8, 4/9). Favor candidates whose position‑Vtrac pattern aligns with the current “hot band” (see item E for vTrac‑sum hot bands).

Score sketch (per position & variant):
PDI = w1*RP + w2*DS_norm + w3*CVB - w4*RHB + w5*VTS

Weights are small and additive; synergy multipliers (CVB/VTS) are capped so no single effect dominates.

From positional scores to straight candidates

Build a position basket: for each position, take Top‑2 (sometimes Top‑3) digits after the PDI score.

Make the Cartesian product → straight list, then filter/weight by other Aux signals you already run (Pairs, Sums, V‑Trac Index), letting the user pick tight / standard / wide coverage.

Tag each candidate with why it’s here (e.g., P1:ds#1, P2:cvb, P3:vtrac-hot, Pairs-OK, Sum-due), so compounding evidence is explicit—your “Golden Rule.”

3) Positional Pressure Score (per digit, per position)

For each Top‑K digit at each position, compute:

pps[p,d] = w_gap * gap_q[p,d]
         + w_variant * (same-digit-at-same-position-in-other-variants ? 1 : 0)
         + w_mirror * (mirror pair corroboration ? 1 : 0)
         + w_vtrac * (vtrac class agrees across positions ? 1 : 0)


Default weights (safe starters):
w_gap=1.0, w_variant=0.5, w_mirror=0.2, w_vtrac=0.3.

Scoring blueprint (conceptual)

Let v ∈ {C, M, E}. For each digit d and position p:

DS(d,p,v) = draws since last time digit d appeared at position p in variant v.

rank(d,p,v) within {0..9} by DS (1 = most due).

P(d,p,v) = base * zscore(DS) + rTop1 + rTop2 + rTop3 (tiny thresholds so Top‑1/2/3 get small step‑ups).

Consensus bonus (same digit, same position across variants)

+B2 if d is Top‑3 at (p) in any 2 of {C,M,E}; +B3 if in all 3.

Anchor detection

If Top‑1 pressure at (p) exceeds Top‑2 by δ (or zscore > τ), set Anchor(Pp=d) and lock K=1 for that position.

PPA(abc) =
