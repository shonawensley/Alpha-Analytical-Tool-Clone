# AAT9 Analysis Arena Window Deep Analysis Report — Spec

Purpose: produce the broader Codex-style end-of-window review for an Analysis
Arena window, combining the strongest cross-state, tracker, decay, and
validation lessons into one comprehensive learning artifact.

This report is the narrative/analytical companion to the quantitative
Performance / Opportunity Gap report.

## Scope

Use this after a completed canonical window under:

- `docs/AAT9_KIT/FINAL VALIDATION/RUNS_2/WINDOW_<...>/`

## Primary Inputs

- Brain 2 Master Validation reports
- daily day-synthesis reports
- daily Control Center reports
- board scoreboard / bundle / overlay / shadow DPL
- translation sandbox day manifests
- per-state Master Validation run reports
- doubles / mirror-doubles deep-dive materials
- results truth files

## Output Files

- Markdown report
- JSON companion payload summarizing the main findings

Recommended names:

- `WINDOW_<...>__ANALYSIS_ARENA__DEEP_ANALYSIS__CODEX.md`
- `WINDOW_<...>__ANALYSIS_ARENA__DEEP_ANALYSIS__CODEX.json`

## Required Sections

### 1. Window Overview

- dates
- states
- draw count
- main environment class

### 2. Board-Level Truth Read

- strongest host states
- strongest echo / shoulder states
- where Brain 2 saw the right structure
- where the board misread or over-compressed the day

### 3. Shared Complexes / Carryover / Decay

- major repeated complexes across states
- carryover across days
- where decay mattered
- where the same pressure actualized in different states across the window

### 4. Tracker Families

Window-level review of:

- profit alerts
- compound events
- Blackapple
- due doubles / mirror doubles
- positional tracker
- survivor context
- `R-Consensus`

### 5. Translational Pressure

- strongest repeated boxed themes
- strongest repeated straight themes
- strongest VT-box themes
- where the arena repeatedly pointed toward structures the control arm did not express well

### 6. Best Findings / Worst Misses

- best predictive states
- most meaningful misses
- where the arena was clearly right but downstream was weak
- where the arena itself appears to have been wrong or noisy

### 7. Promotion Ledger

Explicitly list:

- what should be promoted
- what should remain under observation
- what should be demoted
- what should feed the next translator/budget research cycle

## Style

- synthesis-first
- evidence-dense
- do not devolve into file inventory
- tie observations back to repeated patterns, not isolated anecdotes

## Relationship To Other Reports

- Per-state Master Validation explains state-level truth
- Brain 2 Master Validation explains daily board truth
- Performance / Opportunity Gap quantifies the analytical vs downstream gap
- This report explains the full window in human terms
