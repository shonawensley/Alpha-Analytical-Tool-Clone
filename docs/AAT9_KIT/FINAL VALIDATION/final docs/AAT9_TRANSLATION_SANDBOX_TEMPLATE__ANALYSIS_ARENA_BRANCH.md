# AAT9 Translation Sandbox Template — Analysis Arena Branch

Date: `2026-03-25`

## Purpose

This companion exists to capture near-final translator-learning intelligence
without pretending the branch already has active arena-native combination
forming.

Use it when you want to collect:

- dominant cluster geometry
- shortlist carry-through
- survivor / `R-Consensus` influence
- control-arm kept vs cut behavior
- provisional boxed / straight / vt-box theses

This is:

- a research / collection layer
- downstream of Brain 1, Brain 2, and shadow DPL
- upstream of later translator design

This is not:

- live combination forming
- final budgeting
- a replacement for Part H or Part I

## Main Inputs

- aggregated analysis arena
- board scoreboard
- shadow decision policy
- Candidate Universe
- Play Card
- translation sandbox seed artifact

## Review Posture

The sandbox should answer:

1. what cluster geometry is repeatedly surfacing?
2. what did the arena/runtime preserve that the control arm cut?
3. what looks more boxed than straight?
4. what looks more lane/index than literal?
5. what deserves later translator study?

It should not answer:

- what to wager
- what final budget to use
- what active translator rule to promote after one case
