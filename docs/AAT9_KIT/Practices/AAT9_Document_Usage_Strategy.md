# AAT9 — Document Usage Strategy (Agents)

## Reading Model
- Default context: KIT docs + Architecture + Quickstart; keep it lean.
- On‑demand: Link older AAT9_DOCS checkpoints only when relevant to the task.
- Explicit links: Add doc links in the task plan so agents load only what’s needed.

## Update Model
- KIT is the living source; update KIT first when behavior/structure changes.
- Older AAT9_DOCS can reference the KIT via small banners or addenda.

## Token Efficiency
- Prefer short, focused docs; embed diagrams as Mermaid code blocks.
- Summarize in planning; link to sections rather than pasting entire documents.
